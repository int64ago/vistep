# Centrifugal governor — sensing speed is only one part of the feedback loop

Owner: `/root/hundred_mechanisms`. Original 3D equal-link Watt-type mechanism: rotating spindle, paired flyballs, upper and lower links, rotating sleeve inside a nonrotating collector collar, linked translating gate valve shown in cutaway. A rigid offset linkage raises the gate as sleeve rises, reducing actual open port area. In the open-loop comparison the bridge linkage is visibly disconnected and the gate stays fixed; no stretching connection fakes independent motion.

Misconception: the balls directly brake the engine, a feedback governor is the same as a flywheel, or stabilizing necessarily restores the original speed. Prior knowledge: faster/slower and a valve opening. Adds sensing→actuation→engine response, residual proportional error and lag beyond the upcoming flywheel's energy buffering.

Equal-link/unloaded h=g/ω² is independently derived from vertical weight and centripetal-force balance. Do not present the empirical transient model below as Maxwell's exact equations.

Six causal chapters: name the actual connected sensor and valve at equilibrium; externally driven speed sweep; add load with feedback; same load with linkage disconnected and valve held; inspect final droop relative to the old 72 rpm; compare slow versus fast governor response. State and comparison plots reconstruct history from t=0, with the load step at t=2 s. Explicitly slow the rendered shaft rotation without changing displayed physical speed.

Model: links .25 m, massless sleeve and negligible valve actuation load. Equal upper/lower links: sleeve rise z=2(L−h), radius²+h²=L². Mechanical stops at 12° and 65° prevent ball/spindle overlap and unbounded travel. Static h=g/ω² within those limits. Engine J=3 kg m², drag .2 N m s, full-open torque 12 N m. Initial 72 rpm with load 5 N m sets valve bias. Load increases to 7 N m. q=clamp(q0−4(z−z0),0,1). Engine Jω'=12q−load−.2ω, with a nonreversing stall limit. Sensor τz'=zeq(ω)−z is a disclosed first-order approximation, not a force-accurate flyball transient. Default τ=.4 s; slow comparison 3 s. RK4 dt=.01 s, with proper left-limit handling at the load step.
