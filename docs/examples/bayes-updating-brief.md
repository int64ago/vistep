# Bayes updating — author brief

Misconception: P(star|blue) equals P(blue|star), and a strong likelihood can ignore the base rate. Prerequisite: compare part-to-whole fractions. Distinction: Bloom filter explains how shared bits generate false positives; this scene exposes the denominator after evidence and dependence between observations. No medical, financial or diagnostic application.

Art direction: a woven probability cloth, split into muted blue and ochre populations. Width is base rate; conditional evidence removes a vertical fraction of each color. The surviving areas become a compact normalized strip. Natural counts remain outside narrow regions, so the 1% example does not require tiny labels. Phone uses the same mathematical area decomposition but a shallower cloth and compact HTML frequency pairs; no global SVG scaling and no slider sidebar. A 10×10 background grid is explicitly an area guide, never individual tickets.
