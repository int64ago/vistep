# Current transformer — the turns ratio is a result of magnetic balance

Owner hundred_mechanisms. Misconceptions: a CT scales current exactly regardless of its circuit; a higher burden only changes a meter reading; an open secondary is harmless because current is zero; steady DC can be measured by an ordinary induction CT. Distinct from voltage transformer: prescribed primary current and burden-driven secondary voltage, not prescribed primary voltage.

Primary sources checked2026-10-18: SEL Selecting CTs to Optimize Relay Performance (excitation current subtracts from ratio current, burden, volt-time integral and saturation); SEL Determine Current Transformer Suitability (nonlinear magnetic model and omitted parasitics); Schneider FA125574 (energized CT secondaries must not be opened, actual voltages can be hazardous).
