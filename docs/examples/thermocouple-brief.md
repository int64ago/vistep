# Thermocouple — the reference end changes the answer

Misconceptions: the weld generates an absolute temperature voltage; cold junction must be cold; compensation means adding temperatures; an inserted metal always corrupts a reading; moving a thermal gradient changes an ideal homogeneous wire's endpoint voltage.
