Misconceptions: every extra point makes the answer closer; one seed's error is the standard error; all successes imply certainty; confidence is probability that a fixed constant changes; more N cures nonuniform sampling. Different from Markov: independent uniform area sampling rather than conditional state propagation. Different from upcoming central-limit theorem: explicit geometric estimator, error budget and sampling bias rather than a general limit distribution.
