# Stellar parallax — author brief

Misconceptions: six-month motion is p rather than2p; smaller parallax uniquely means more distance without knowing baseline; every annual trace is circular; proper motion equals parallax; zero baseline yields a finite distance. Different from telescope: geometric astrometry and its inference conditions, not aperture resolution or magnification.

Art direction: enlarged angular observation plate with fixed slate reference crosses and an ochre target track. A small separate-scale orbit inset controls actual observer phase. Native16px labels, axis values and21px phone measurements; no semantic SVG text. Both sky axes use exactly the same scale, so β90° remains near circular rather than a decorative ellipse. All shots and Explore keep the same ±3 arcsecond scale; the UI restricts D≥.5pc, B≤1AU and |motion|≤.35arcsec/year so the entire two-year trace stays visible. The independent model has wider tested bounds. Max540px desktop,360:260 aspect, about183px high at320. Full-player740px target pending actual review.

Primary references: [NASA stellar parallax](https://science.nasa.gov/asset/hubble/stellar-parallax/), geometric baseline principle; [ESA parallax/proper motion](https://www.esa.int/ESA_Multimedia/Videos/2018/04/Parallax_and_proper_motion/%28lang%29), separating periodic and secular components; [IAU Working Group, IAU 2015 Resolution B2](https://arxiv.org/abs/1510.06262), exact pc=648000/πAU in the resolution on bolometric magnitude zero points. Actual sight vectors project onto a fixed tangent basis, then use atan2; familiar d≈B/p is stated as a small-angle approximation. Fixed proper motion is an added angular teaching term, not radial/full space velocity. No fitting, noise, aberration, atmosphere, companions or finite reference-star parallaxes.

Six shots, planned141s: opposite half-year views show2p; distance1→2pc halvesp; baseline1→.5AU changesp but preserves inferred distance; β0/45/90 yields line/ellipse/circle; .35arcsec/year drift separates one-year positions; B1→0 removes distance information. Every manual parameter changes visible track, position or measurement; epoch always moves the model observer and target. Shared progress only, no clock/resources.
