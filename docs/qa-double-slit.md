The scientific reference is the **current single-slit central intensity** I₀: one slit has central intensity 1 and two coherent identical slits have central intensity 4. Width changes compare normalized shapes. The phase uses the far-field approximation d sinθ; finite slit width remains in the diffraction envelope. The model is an ideal scalar far-field approximation, not an exact near-field solution. Classical fields and ideal single-photon detection statistics are distinguished, and no photon trajectories are assigned.
