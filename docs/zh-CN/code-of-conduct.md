# 行为准则

[English](../../CODE_OF_CONDUCT.md) · [中文文档](README.md)

欢迎不同背景、能力、语言和经验的贡献者。相互尊重，针对具体想法和作品提出可操作反馈，允许学习和不同意见。

使用体谅他人的语言、建设性反馈，尊重隐私和署名。不接受骚扰、歧视性辱骂、威胁、性骚扰、冒充或未经许可发布他人私人信息。

本政策适用于仓库 Issue、PR、讨论及代表项目的其他空间。维护者可编辑或移除有害内容、限制参与或封禁账号，处理应与严重程度和重复情况相称，受影响者可以申请复议。

私下联系 **int64ago@gmail.com**，提供链接和足够上下文，不在公开 Issue 发布个人信息。报告会谨慎处理，仅为回应所需而分享。项目由志愿维护者维护，没有保证的响应时间。
