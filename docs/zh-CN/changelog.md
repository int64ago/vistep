# 更新记录

[English](../../CHANGELOG.md) · [中文文档](README.md)

这里记录重要变化，细节以 Git 历史为准。package 版本不意味着已发布带标签的稳定版本。

## 持续上线更新 — 2026 年 9 月

这些变化通过 `main` 的部署流程上线，没有发布带标签的软件包版本。下文的历史测量只适用于各自修订。

- 重做第 63 篇挖掘机：20 吨级车身、鹅颈动臂与 H 形铲斗连杆，近侧动臂缸原位剖开并显示油流，投影标注，机器旁的活油路面板（油箱、泵、溢流阀、阀芯一联和操作杆），泵活塞与动臂活塞的帕斯卡对比，带 37.3 MPa 溢流区的压力表，4:05 双语影片，以及静态载荷、操作杆、力臂和卡斗举升的自由探索。
- 双语合集从 12 篇扩展到 62 篇；[扩展记录](expansion-50.md)区分正式发布与尚未完成的视觉、试听及真机审看。
- 自行车变速与激光打印机封面改用对应机构几何，目录与分享图同步更新。

- 首页由 3.2 MB 降到 0.8 MB 以内：栅格封面改为 PNG，过采样的封面几何精简，输出坐标取整。
- 中文页面不再下载英文词典，实验公共代码块由 572 KB 降到 165 KB。
- 站点顶栏新增 GitHub 链接。
- 自动播放被拒绝时，舞台上出现醒目的开启讲解提示，取代原来不起眼的一行状态。
- 新增浏览器支持检测：不支持的浏览器只显示一条列出缺失能力的提示，不做降级。基线为 Chrome 108、Edge 108、Firefox 121、Safari 15.4；替换了 `color-mix()`、容器查询与 `toReversed`，保住 iPhone 6s/7 一代。
- 配音录音整段历史迁入 Git LFS，仓库由 429 MB 缩到约 40 MB；CI 缓存 LFS 对象。
- 用基于项目模型独立制作的动图替换 README 截图，并保留静态替代。
- 语音讲解默认开启，保存手动选择，并兼容浏览器自动播放限制。
- 补齐场景技能的要求覆盖清单、首页与宣传素材流程以及最新声音策略。
- 首页移除放大的品牌块，改为进入时自动播放、最终融入导航字标的文字开场。

- 最初 12 篇改为 2–5 分钟章节演示，新增局部观察和受控对照。
- 替换不可理解的中文录音，重新生成双语音轨，按实测窗口编排，不拉伸时间。
- 新增章节定位、确定性模拟回放和 Transformer 内部观察。
- 默认语言采用多因子判断，手动选择保存在本地。
- 从内容生成结构化数据、分段讲解、分享 PNG 和多语言 sitemap。
- 品牌动画融入首页主标题，文档改为英文默认及完整中文版本。

## 生产基础 — 2026-09-05

完整双语站点部署至 vistep.ai 与 www.vistep.ai，保留旧品牌站回滚版本，完成 Search Console DNS 验证和地图提交。新增制作手册、复盘、场景技能、未发布草稿工具、登记与产物审计，以及独立 noindex 预览。

仓库加入 MIT、双语 README、贡献与安全政策、素材许可、Issue / PR 模板和 CI；main 检查后自动部署。
