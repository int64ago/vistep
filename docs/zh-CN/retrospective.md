# 制作复盘：把完成度放在完成数量之前

[English](../retrospective.md) · [中文文档](README.md)

早期记录依据本次项目对话中的需求与反馈，以及截至 2026-09-05 的五次实现提交；后续经验按具体复核补充。这里只把 Git 可核对的内容归入相应提交；早期被否定的页面形态来自用户反馈，不假设它们全部保存在当前历史中。

历史提交号保留记录当时的源码引用。Git LFS 与署名改写改变了提交历史，这些提交号不保证能在新克隆中解析。检查记录中对应的 Actions 运行和 Worker 版本继续作为历史发布来源；旧版审看结果不认证当前源码。

## 目标如何变得明确

最初目标是用可视化解释生活和工作中的机制，首批 12 篇，保留域名的完整命名过程。用户随后明确指出：大块品牌展示、煽情字母文案、统一实验模板、不精细的几何、锋利的界面都不符合期望。之后进一步要求演示自动推进，减少操作和文字，补上双语与自然、同步的声音。

这不是“再美化一下”的问题。产品需要先让人看懂，再让人探索；对象、镜头与因果关系才是主角。第一轮用专题数量和控件丰富度判断进度，偏离了这一目标。

## 品牌作为进入页面的过程

后续首页反馈暴露了同一个问题：放大字标、叠加拆字公式，仍然把名字当成独立展品。动画应当承担进入首页的过渡，完整审看起始、提取、合并和最终落位，包含首次加载与再次进入。初始化时的尺寸事件可能提前取消一段本来正确的动画，重播成功不能证明自动进入正常。详见[首页开场审看](qa-home-opening.md)。

## 制造细节与网格正确性 — 2026-09-12

机械键盘复核表明，部件相连、行程正确，仍不足以让物体精细。矩形外墙、平键帽和等宽金属带保留了机制，却丢失了制造特征。应实际查看参考帧，重建成型斜肩、薄壁、卡扣窗口、导槽和冲压折弯；随意加螺丝、刻字或纹理噪声不能替代这些结构。[修订简报](examples/keyboard-switch-brief.md)记录了参考来源与型号边界。

渲染问题又放大了几何粗糙。凹多边形不能一律从首顶点作扇形剖分：茶轴轮廓的一面曾生成重叠三角形，面积比原面多约 28%。三角化应留在多边形内，保持绕序和开口，并核对面积与覆盖边界。不能仅因相邻面共用位置，就跨硬棱平均法线；平面需要一致法线，真正的曲面才应有受控平滑。

阴影范围还必须匹配实体坐标尺度和完整运动。共用光源的默认视锥遗漏了采样的键盘部件，即使主镜头取景正确也不会自动补全阴影；须独立调整并检查光源覆盖。这些发现确定了修订要求，不代表新版画面、性能或发布已经通过。

## 可复用的实现经验

**模型先于渲染。** 闭合链条不能靠把最后一个点吸到第一个点来补。自行车用共同节距、偶数链节与求解后的轴距；打印机用共同模数、渐开线齿形与闭合皮带。渲染参数必须能追溯到模型，尤其是在齿比或速度改变时。

**同一条时间线。** `Showcase` 提供时间、章节、播放模式和重播计数；场景决定如何表达这些状态。配音启用时以音频时间为准，等待、离屏和后台都要暂停推进。不能让独立动画计时器与声音各自前进。

**提前给双语留空间。** 英文长度和中文断句不同。字幕区域按所有章节预留高度，避免切换时整页跳动。两种语言共享科学模型和镜头节点，使用各自的说明与口语稿；不要只换导航文字。

**生成接口需要实测。** 语音接口返回的内容不能只根据扩展名或文档猜测编码。制作脚本实际解码、统一响度、保留停顿，不进行时间拉伸。网络失败可重试，生成结果和清单要一起提交；正常构建无需供应商凭据。

**开发页与构建产物分别验证。** 曾遇到开发缓存导致重复 React 的运行错误；开发服务器恢复并不能证明线上静态产物正确，构建成功也不能证明浏览器能播放。复测应指向确切 URL 和版本，避免旧缓存造成错误结论。

**不要把构建目录直接混用。** 生产产物在 `dist/`，预览在 `dist-preview/`。预览使用响应头禁止收录，并允许爬虫读取这个头；生产 sitemap 与规范网址必须指向真正可访问的正式页面。

## 长演示与语音纠正

后续发现中文音轨虽然能解码和播放，内容却不可理解。旧检查只能证明传输与同步，不能证明语言质量。新流程明确指定中英文神经语音，按实测长度分配章节，不变速；使用不带语言提示或参考稿的独立转写核对每段实际声音。转写仍不能认证语气与感染力。

每篇调整为 2–5 分钟，推荐 2–3 分钟。新增时长必须对应新的可见因果步骤、局部观察或对照实验，不能在短循环上加长旁白。模型使用章节相对时间，跳转必须重建对应状态，包括模拟历史与训练进度。首页把品牌演变放进主标题排版，完整释义持续可见。

文档以英文为默认入口，配完整中文版本、真实状态徽章与项目自有画面；历史汇报放入检查记录。搜索信息从专题登记自动生成，不维护另一套容易过期的目录。

## 仍需要诚实保留的边界

已有 [机械与自动演示记录](qa-automatic-demos.md) 和 [双语配音记录](qa-bilingual-narration.md) 说明了各自的覆盖范围。桌面浏览器模拟手机宽度不等于真机性能；播放解码成功不等于声音有感染力；旧版每篇 30–42 秒只记录当时状态，新版 2–5 分钟仍不代表已测量每位读者的理解效果。

“大师级”是审稿要求，不能由测试数量自动认证。下一篇应先做出一段完整、可信、值得看的核心过程，再扩展内容。执行方法见 [场景制作手册](creating-a-scene.md)。

## 导出配图需要单独检查字体

浏览器中的文字正常，导出的文档图片却把箭头和角度符号显示成了缺字方块。导出流程禁用系统字体，因此随仓库提供的字体必须覆盖用到的每个符号。保留许可，直接检查生成的 PNG，同时看文字和数学符号。构建成功不能证明没有缺字。

README 首图现改为根据网站模型独立制作的动图。把页面截图压缩成宣传图，不能直接传递产品最有特点的机制与想法。检查对象还必须包括编码后的 GIF：本次有损优化引入了源帧中没有的颗粒，最终改用无损优化。保留静态替代和制作源文件，让宣传素材能够随产品一起维护。

## 默认行为也是需要维护的产品决定

语音讲解改为默认开启，替代此前的默认静音策略。播放器、偏好存储、项目要求、双语文档和技能要同步更新。浏览器禁止自动播放不等于用户主动静音，不能把这种失败保存为关闭偏好；用户明确选择则必须保留。实验纯音仍需单独主动开启。

## 检查实际渲染的坐标系

月相的首版手机图继承桌面 SVG viewBox，标为 21 px 的文字在屏幕上实际只有约 9 px。需要重新安排图形坐标与控件，并测量实际字形边界。固定演示高度还需要限制宽屏 SVG 的高度，否则桌面变宽会把署名推到字幕区，哪怕手机没有溢出。每章都要比较子元素边界与舞台边界。

两个手机读数只比可用 flex 宽度多出不到 1 像素，就各自换了一行。必须共用基线的信息采用明确网格列，并在最窄支持宽度下审看。范围控件显示的舍入值应与手动状态一致；自动科学模型仍保留更精确的常数。

模型的名义宽高不能保证透视构图完整。电动机和锁芯底座的近端角点在中心边界看似合适时仍超出画布。应按实际相机宽高比检查近端角点、移动部件与支撑的投影，并留下可见余量；明确区分有提示的局部特写和意外裁切。材质高光也要放进最终灯光中审看，按专题调整曝光可保留线圈与支架的分离感，无需改变所有渲染器的默认效果。

颜色图例属于计算解释的一部分。通用 SVG 文字规则曾覆盖机翼压力图例的颜色。应保留显式的语义配色，让图例与对象使用同一个映射函数，并检查最终渲染。数值正确不代表视觉编码也正确。

## 并行所有权与手机构图

每个 worker 负责完整独立专题，主任务统一负责登记、译文和录音，才能让并行制作有效提速。临时交付包消费到正式数据源后删除，避免重复维护。配音按所选专题进入同一个有限并发池，不能同时启动多个会覆盖公共清单的进程。两篇缓存回归已验证批量选择保持既有音轨与清单逐字节不变。

没有横向溢出不代表手机影片构图合格。首批并行内容把桌面区块纵向叠放，出现 1200–1360 px 的自动演示区。应检查总高度、重复标签，以及当前因果动作与字幕的距离。按章节选择需要的仪器，完整状态留在探索模式，保留 16 px 文字，不能缩小整篇。范围输入必须显式关联 label 与 input：隐式 label 内的 output 可能抢走滑块的标签关联。

### 独立审看目录使用独立依赖

一次审看目录曾与制作工作区共享 `node_modules`。包管理器校验时为不同根目录重写可执行入口，另一个进程运行期间因此出现短暂的文件不存在警告。各审看目录应分别执行离线、锁文件固定的依赖安装。验证源码和发布资产保持不可变；不要把仍在重建的目录作为上传源。

### 合成成功，还要检查是否说完

水锤一段英文返回了有效 MP3，却只包含前三句。整体转录相似度 0.6652，超过旧的 0.64 阈值，但结尾实际缺失。针对这一段重合成后，声音从 13.06 秒恢复为 23.32 秒，并重新测量了中英文共用时间线。转录检查新增末尾覆盖门槛：规范化脚本最后五分之一（至少 24 字符）的匹配比例至少 40%。实际截断样本得分为零，批次中其余 95 个样本通过这一附加检查。修复后重新检查最终音轨。此规则用于发现结尾缺失，不证明咬字或自然度。

三维渲染器应随当前可见构图创建，并在切换视图时释放。锁芯与缝纫机曾在 CSS 隐藏容器内提前创建渲染器，手机直接进入局部章节时可能出现空白画布。按可见视图挂载修复了首次深链接显示，也避免保留闲置 WebGL 上下文。验证必须包含直接刷新到对应章节；从已经显示过的模型切换过去，属于另一种证据。

### 检查完整播放器与局部因果

实验本体缩短后，最长英文字幕仍可能在控件上方预留多行空间，使手机页面过高。逐章测量两种语言下的完整播放器。字幕只说明当前可见变化，完整配音与展开内容承担上下文。只改字幕时同步两个字幕来源和翻译字典，不改变录音。

整流器审看发现：电容浪涌电流正确，却让负载电流为零的导线一起发光。显示电路应在真实支路节点处分开，各支路由自己的电流驱动，使用同一套已说明的视觉亮度标尺。标签与焦点标记也应绑定它们实际描述的对象或支路。

名义针距下放得进画面的两个线迹样本，在长针距送布时发生裁切。包围范围应覆盖全部比较样本的完整行程，并保持共同的固定投影；不能每帧自动缩放，也不能拉长一个样本代替另一个。说明标签随几何缩小后不足字号要求时，应移出缩放区域。

### 并行制作持续到验收

写完源代码不代表并行任务结束。冻结交付后，子任务立即接具体修复或未审组，主任务并行整合、检查和发布已有授权的预览。作者身份、发现、修复归属与证据缺口分别记录。正常速度运行加抽样停帧少于连续视觉观察，也不能代替原生试听或实体设备性能证据；发布记录应保留这些区别。

### 手机构图也会改变口语指向

桌面图表改成手机局部视图后，旧录音仍可能说“看右边”，或讲解已经不显示的时序表。录音前逐一确认每种构图里的真实对象；指令编号、信号名称和仪表名称通常比屏幕方位更稳妥。解释机制的物理方向仍然保留。改稿后重新测量录音，字数相近不代表时长不变。
