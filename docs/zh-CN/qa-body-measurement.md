# 身体测量专题审看

[English](../qa-body-measurement.md) · [文档目录](README.md)

本记录对应体脂秤（#81）与耳温枪（#82），从 `66dad86` 源码基线开始于 2026-10-05 制作。两篇各有独立作者，第三位 agent 核查技术来源与科学模型；集成人员实际审看构图，并独占登记、翻译和录音写入。作者自检与独立复核分别注明。

## 科学范围

体脂秤区分应变片称重与四电极生物电阻抗测量。阻抗、相位及等效组织电路进入明确未标定的教学估算。水分比较保留相同脂肪和干燥去脂组织质量，总质量随水分改变。本篇不估算读者个人的身体成分。

耳温枪跟踪组织被动发出的热辐射到达探测器。几何接受模型为每条加权射线选择首先相交的表面；有限波段的理想普朗克积分、传感器参考温度和标定共同得到显示的辐射温度。解剖、响应和标定属于教学选择，不是厂商临床算法，也不预测核心体温。

发现分类将体脂秤归入「电与磁」，建议从 12 岁开始；耳温枪归入「光与波动」，建议从 10 岁开始。年龄是编辑建议。两篇均有双语日常与技术搜索别名。

## 实际目录审看

独立 reviewer 用 Chrome 在 320×844 操作中英真实构建目录，名称搜索均找到对应专题。「电与磁＋12–13 岁＋3 分钟以内」保留体脂秤（共两项）；「光与波动＋10–11 岁＋3–5 分钟」保留耳温枪（共三项）。反向时长筛选正确排除对应专题。两张新卡宽 280px，卡片/画图圆角分别 20px/18px，器物完整、播放覆盖层可见，页面宽度仍为 320px。1280×900 中点击 Discover more 显示 24/82，两个新卡同一行完整可见，每张宽 368px。主线程实际查看保存的浏览器截图。静态链接覆盖由源码/构建审计检查；这一轮未手动禁用 JavaScript，也不宣称真实手机触摸或 hover 动画测量。reviewer 已清除筛选、恢复视口并关闭唯一临时标签。

## 完整播放与手机构图

2026-10-05/06，主线程在 IAB 以正常速率自然播放体脂秤中英完整两轨；独立 reviewer 在 Chrome 以正常速率自然播放耳温枪中英完整两轨。均未用跳转或倍速缩短播放。各片在实测终点 170.5 秒或 185.5 秒停止并暂停，声音与画面时钟相差不超过 0.1 秒；重播、暂停跳转和章节停帧另行检查。体脂秤记录自然播放的抽样画面，并另外审看七章停帧；耳温枪 reviewer 在两次自然播放中实际查看全部 14 个章节画面。这是播放与同步证据，不是完整原轨听审。

主线程对两语七章分别测量完整正常播放器，包含当前解释、播放控件与收起的章节行；声音加载正常，未包含资源错误提示。最大高度四舍五入如下：

| 场景/语言  | 320px 视口 | 390px 视口 |
| ---------- | ---------: | ---------: |
| 体脂秤中文 |      777px |      777px |
| 体脂秤英文 |      811px |      773px |
| 耳温枪中文 |      756px |      729px |
| 耳温枪英文 |      793px |      767px |

均无页面横向溢出，主要播放操作至少 44px；SVG 教学标签检查实际缩放后字号，不只读取源码字号。上述是浏览器视口测量，不是真机结果。

实际体脂秤探索覆盖 UI 频率两端（2、200 kHz）、回到 50 kHz、接触断开及二维视图。其他频率显示当前电阻而不显示身体组成估计；开路移除两条测量路径，并更新电流图例。最后的二维停帧发现视图切换按钮挡住 I−，现放在器物下方独立位置；三个器物视图在 320px、1280px 下，按钮与完整 SVG 保持 4.5–6.5px 间距，按钮高 45.5–47.5px，无横向溢出。正常演示不显示切换按钮，已测全片高度保持原样。耳温枪真实离屏检查中，将完整播放器滚出视口后，声音暂停在 43.711495 秒，画面停在 43.7 秒；下一次观察均未推进，返回后继续播放。后台、减少动态与释放资源的证据来自组件 harness，不冒称浏览器手工性能测量。

独立 reviewer 在另一服务器上访问真实构建，并只让录音 URL 返回 HTTP 404；Chrome 中检查体脂秤中文与耳温枪英文，均出现明确重试提示，重试失败后静音播放、暂停、跳转与探索仍可用，模型状态正确。失败媒体 readyState 为 0；Chrome 只读接口未暴露 audio.error，因此不宣称具体错误代码。启动能力拒绝与可读静态内容，和 renderer 运行时失败后的二维路径分开记录。
