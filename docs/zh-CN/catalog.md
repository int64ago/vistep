# 专题目录

[English](../catalog.md) · [文档首页](README.md)

当前合集登记 80 个专题，每篇均有中英文文章、自动影片和同步录音。最新六篇（75–80）为 CPU、GPU、NPU、eSIM、儿童近视防控镜片、单反与无反、拍立得和水母；[审看记录](qa-six-explorations.md)分别记载模型检查、浏览器观察和剩余证据缺口。正式站通过 `main` 部署流程发布。逐篇完整观看、双语试听和真机审看仍未全部覆盖；发布不代表已全部验收。较早的移动通信专题见其[审看记录](qa-mobile-networks.md)，部署历史见[扩展记录](expansion-50.md)。

分类按主线讲解归属。热传递与流体单列，地球与天文只收行星及天体现象；水母按排水、涡环与推力主线列在“热学与流体”。武器题材集中在“武器与安全”。跨领域关联通过相关专题与中英文检索词保留。
