# 专题目录

[English](../catalog.md) · [文档首页](README.md)

下表对应已登记专题和实测片长。正式专题包含中英文文章、自动影片和静态录音；验收分别记录数值检查、浏览器观察、独立转写及剩余审看缺口。此前工作见[二十篇审看记录](qa-twenty-explorations.md)、[身体测量审看](qa-body-measurement.md)及[合集扩展记录](expansion-50.md)。本地审看记录不等于正式发布记录。

分类按主线讲解归属。热传递与流体单列，地球与天文只收行星及天体现象；水母按排水、涡环与推力主线列在“热学与流体”。武器题材集中在“武器与安全”。跨领域关联通过相关专题与中英文检索词保留。

### 建议学习路径

这些可选路径跨越主分类；网站为每一步说明接续理由与起步需要的概念。年龄仅表示理解门槛参考，不是内容适宜性评级。下表片长向上取整到秒，与三分钟筛选边界一致。

- **一张照片怎样产生** — 先知道：光会传播，照片由像素组成。 [镜头成像](../../src/content/camera-lens.mdx) → [光圈与景深](../../src/content/aperture.mdx) → [拜耳传感器](../../src/content/bayer-sensor.mdx) → [卷帘快门](../../src/content/rolling-shutter.mdx) → [JPEG 压缩](../../src/content/jpeg.mdx)。
- **同一条波形的不同看法** — 先知道：周期、振幅与频率的含义。 [波的干涉](../../src/content/wave-interference.mdx) → [拍频](../../src/content/beats.mdx) → [驻波](../../src/content/standing-wave.mdx) → [采样混叠](../../src/content/sampling-aliasing.mdx) → [傅里叶分解](../../src/content/fourier-transform.mdx)。
- **一个网页怎样到达手机** — 先知道：网络中有发送方、接收方与中间节点。 [网页加载](../../src/content/network.mdx) → [网络分组路由](../../src/content/packet-routing.mdx) → [TCP 可靠传输](../../src/content/tcp-reliability.mdx) → [拥塞控制](../../src/content/congestion-control.mdx)。
- **电能怎样被转换和送达** — 先知道：电压、电流与储存能量的区别。 [发电机](../../src/content/electric-generator.mdx) → [变压器](../../src/content/transformer-electric.mdx) → [整流器](../../src/content/rectifier.mdx) → [降压变换器](../../src/content/buck-converter.mdx)。
