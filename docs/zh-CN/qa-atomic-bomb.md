# 原子弹审看 — 2026-09-12

[English](../qa-atomic-bomb.md) · [制作说明](examples/atomic-bomb-brief.md) · [检查索引](README.md#检查记录)

本记录是原子弹（裂变链式反应）场景的发布前审看，与氢弹场景同批基于父提交 `84d3ab8` 制作。记录检查了什么、由谁检查、哪些尚未检查；不声称部署成功或已核查发布站点。

本篇只讲教材级核物理：核的形变与断裂、结合能曲线、逐代增殖、以平均自由程度量的球体中泄漏与产生的竞争、通过缓发中子对比反应堆与炸弹、以及膨胀导致的自行停止。不含任何以公斤计的临界质量、反射层／惰层、组装方式或实际尺寸；所有长度以平均自由程计，碰撞比例声明为示意。独立审查者逐文件检索了此类内容，未发现。

## 证据限制

- 两条完整录音均未经母语试听，两部影片均未被连续观看。ASR 不能证明发音、自然度或词级同步。
- 未测量真机性能；行走章节每帧重绘 2D canvas，低端手机的帧率未知。
- 减少动态、浏览器后台隐藏、离屏暂停、自动播放被拒后的恢复与音频资源失败依赖共享播放器，本篇未重新逐项验证，只在无头运行中看到自动播放提示出现。
- 本篇使用 2D canvas 与 SVG，不用 WebGL 与 Worker，运行时 WebGL 回退不适用。
- 本记录止于发布之前。推送 `main` 触发 CI 部署；CI 结果与线上站点行为不在本证据范围内。
