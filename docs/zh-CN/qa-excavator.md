# 挖掘机审看 — 2026-09-06（重做，增补油路与操作杆）

[English](../qa-excavator.md) · [制作说明](examples/excavator-brief.md) · [检查索引](README.md#检查记录)

第一版挖掘机被判定不够可信：车身像玩具、材质发白、销轴悬空、脱离机器的教科书油路图，以及裁掉机身的近景。本篇整体重做。本记录分开列出模型检查、浏览器停帧、全程播放、转写和仍缺失的证据。这是发布前审看，不是部署记录。

## 本次改动

- 新的 20 吨级平面模型：鹅颈箱形动臂、变截面斗杆、由定长杆解出的 H 形铲斗四连杆、两支动臂缸、一支斗杆缸和一支铲斗缸。缸径、杆径、37.3 MPa 工作装置溢流和泵流量参照 Komatsu PC200-8 手册；质量和臂长是教学取值。
- 近侧动臂缸用裁剪平面原位剖开：缸筒、活塞、镀铬杆、随压力增亮的琥珀色无杆腔油、浅色有杆腔油、带流动油粒的软管，以及分配块处的溢流回油。远侧缸、斗杆缸和铲斗缸保持完整。
- 标注由模型销轴投影到 CSS 像素并带引线，在舞台内翻转和限位。舞台下方是带溢流区的压力表和三组排版读数；手机观看时只显示本章相关的读数。
- 机器旁新增活油路面板：油箱、发动机驱动的泵、主溢流阀、带 P/T/A/B 口的主控制阀动臂一联、动臂缸和右操作杆。操作杆行程推动阀芯，阀口露出宽度和流动虚线跟随计量流量，同一状态同时驱动三维机器。桌面上覆盖舞台左侧（镜头把油缸滑到剩余宽度），手机上堆叠在舞台上方。
- 每章的流量和阀状态都由操作杆行程推导（满杆 = 130 L/min 教学流量）；下降用同一速度律、符号相反。压力章节增加帕斯卡对比：Ø20 mm 泵活塞与 Ø120 mm 动臂活塞在同一压力下面积比与推力比都是 36。
- 八章按实测 245.5 秒录音重排：挖掘、剖开油缸、闭合油路、压力与帕斯卡、推杆与速度、力臂、铲斗四连杆、溢流与松开。
- 镜头取景按机器极值点（含铲斗整个扫掠范围）的投影求解，不再用名义宽度；手机有单独的方位角和俯角。
- 二维运行时后备图、目录封面和分享图都从同一姿态模型绘制；后备图隐藏投影标注。
