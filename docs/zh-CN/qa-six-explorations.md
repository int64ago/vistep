# 六篇专题制作与审看记录

[English](../qa-six-explorations.md) · [文档首页](README.md)

2026-10-05 从已发布的 `b5dd6bfe` 开始，在 `codex/six-explorations` 制作 CPU/GPU/NPU、eSIM、儿童近视防控镜片、单反与无反、积分式拍立得相纸、月水母游动六篇。四位作者按有界队列并行推进，主 agent 负责共享登记、翻译、录音、集成与实际验收；冻结交接不是视觉或听觉验收证据。

## 各篇表达与边界

| 专题        | 跟踪对象与关键变化                                    | 模型边界                                                     |
| ----------- | ----------------------------------------------------- | ------------------------------------------------------------ |
| CPU/GPU/NPU | 相同4×4输入、64个有身份的乘加，在三种调度下执行       | 教学事件，不是硬件周期或速度/能耗排名；只展示一种脉动阵列NPU |
| eSIM        | 同一运营商profile进入保护芯片；绑定A的同一包在B上失败 | 消费者RSP、单启用端口；协议状态校验，不实现实际密码学        |
| 近视镜片    | 同一物点的矫正与获准微透镜光束，然后看独立临床组数据  | 近轴等效眼与径向剖面；不预测眼轴，不作处方；以DIMS为例       |
| 单反与无反  | 镜子/屏/棱镜光路，或传感器/读出/显示器信号；另看帘幕  | 代表性传统机构；简化棱镜朝向和快门节奏                       |
| 拍立得      | 同一张Polaroid彩色i-Type相纸、相切滚轮与有限试剂      | 教学机械/化学参数，公开时间压缩；不混用Instax结构            |
| 水母        | 同一次海月水母伞运动、排水体积与涡相关后续推力        | 未校准低阶流体/能量模型，不是Navier–Stokes求解               |

水母按主线水动力归入已有“热学与流体”。六篇均登记中英文检索词、编辑建议起始年龄和实测时长；双语源码目录现为80篇。

## 独立复核与修补

相机作者独立复核了首批其他篇。CPU乘加身份、掩码、脉动到达顺序无剩余P1/P2；近视临床面板与Lam原论文表2核对了79/81位完成随访者、均值及标准误。

已修补：微透镜径向切面与瞳孔准入一致、零附加度数焦点重合、eSIM失败状态限制认证与切换并使用新的回应时段、相机帘幕完全开放后才实时读出、有限药囊压缩轮廓不穿滚轮、清洁不能修复已损坏照片、水母休息阴影按真实时序推导，以及按真实位移记回收功且不超已释放能量。相机电信号有露出的PCB、处理器引脚、排线和显示器接头；实体遮挡探针包含桌面双机和手机构图。两种涡流在径向—竖直切面的箭头相反，不把整个圆环绕主轴转动冒充涡核旋转。

主agent实际浏览器审看还修补了焦点近景溢出、手机重复文案、eSIM真实A/B绑定包对照，以及拍立得光孔和滚轮通道。药囊章采用同一张纸、圆柱和有限药囊的直接侧剖；其他物理章节保留实体相机切面。镜筒接续并有空心安装法兰，图像使用polygon offset避免贴图面穿入上滚轮。

## 证据台账

条件：macOS、Node24.19、pnpm11.25、Codex内置浏览器；320×844、390×844与1440×1000视口覆盖只证明布局检查，不能当作真机性能。

| ----------- | ---------------- | -------- |

| eSIM        | 144秒            | 中、英   |
| 近视镜片    | 167.5秒          | 中、英   |
| 单反与无反  | 190.5秒          | 中、英   |
| 拍立得      | 169.5秒          | 中、英   |

Xiaoxiao/Ava录音按实测窗口组成共享章节，不拉伸语速；普通构建不调用语音服务。Whisper large-v3-turbo在无语言提示、无参考稿情况下独立转写82段，语言、相似度与结尾覆盖检查全部通过。ASR不能证明自然语感、节奏或配音表演；原始整条音轨试听仍是明确缺口。

实际浏览器停帧覆盖六篇每章，包括320像素英文构图及中文因果近景。手机冗长视图已压缩，正文标签保持16像素、主要操作保持44像素。英文320像素完整播放器（解释折叠，含字幕与播放控件）约为：处理器708–846、eSIM720、镜片730–857、相机772–836、拍立得779–786、水母747–837像素。未见页面横向溢出；最长视图需少量纵向滚动，对象和控件仍处于同一播放器。

从头自然计时播放与最终交付结果在下方记录。资源与生命周期自动检查使用受控GPU/音频替身，不能证明fallback视觉效果或真机速度。原音轨试听、真机帧率及发热检查仍未完成，分别保留证据缺口。

封面独立实看发现通用“3D”标识不适用于矩阵/SVG专题，已改为准确的互动模型标识。桌面完整播放发现中央光束过窄，现扩展中央矫正区内真实取样；微透镜仍按其小孔径取样。独立420组输入、2800条射线核查了同物点入射角、源面范围、圆瞳孔准入与共同焦点。原始镜片播放因这项视觉修补重新验收，不计旧版中途播放为通过。

拍立得最终封面复用实体毫米尺寸和走纸模型。矢量面分割修复纸面与滚轮的遮挡顺序，近侧局部剖切保留并暴露真实 nip。独立 53,355 个有实体覆盖的采样点没有错误深度排序；最终为 2,221 个面、约 369 kB SVG（gzip 42.7 kB），本机生成约 31 ms。集成者实际审看构建后的社交 PNG，确认镜筒连接、两个滚轮与夹持相纸可辨；同色微边抑制拆面细缝。曝光路径仍为相同三节点、相同快门状态，使用更清楚的深金色薄管，二维剖面同步颜色。

真实自由探索界面核对了零附加光焦度时焦点重合、允许的光学输入上界没有非有限坐标、封包投递失败时正确标记芯片 B 而绑定仍为 A。水母零幅度时二维剖面没有涡流或推进，说明同步明确该状态。相机二维 fallback 在浏览器中实际操作，与注入资源失败的自动检查分别记录。
