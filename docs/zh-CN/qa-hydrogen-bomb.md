# 氢弹审看 — 2026-09-12

[English](../qa-hydrogen-bomb.md) · [制作说明](examples/hydrogen-bomb-brief.md) · [检查索引](README.md#检查记录)

本记录是氢弹（热核聚变）场景的发布前审看，与原子弹场景同批基于父提交 `84d3ab8` 制作。记录检查了什么、由谁检查、哪些尚未检查；不声称部署成功或已核查发布站点。

本篇只讲教材级等离子体与核物理：库仑排斥与经典折返点，D、T 与 ⁴He 的结合能，麦克斯韦尾巴乘以隧穿得到伽莫夫峰，Bosch–Hale 反应率随温度的变化，为什么只有裂变爆炸能为一大团燃料提供温度与辐射，锂-6 增殖氚，以及 Lawson 图上的三种约束方式。关于分级只到公开表述为止——裂变初级的辐射加热并压缩分开放置的聚变燃料——不含几何、尺寸、材料布置、当量或燃料数量。独立审查者按此边界检查了每个场景文件，未发现越界内容。

- 两条完整录音均未经母语试听，两部影片均未被连续观看。ASR 不能证明发音、自然度或词级同步。

- 本篇只用 SVG，不用 WebGL 与 Worker，运行时 WebGL 回退不适用。
