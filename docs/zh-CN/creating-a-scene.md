# 制作一个专题

[English](../creating-a-scene.md) · [中文文档](README.md)

用一条可追踪的视觉因果链解释一个问题。复用制作流程、播放器和生命周期基础设施，每篇根据现象选择自己的构图和媒介。

## 从问题开始

使用 Codex 时，向 [vistep-scene 技能](../../.agents/skills/vistep-scene/SKILL.md)直接描述选题。技能负责研究到实现、双语声音与审看；用户不需要填表或执行脚手架命令。普通贡献者也可直接按本手册制作。

先确定观众原来的直觉、一个全程追踪的对象、改变理解的关键观察，以及模型边界。记录一手技术来源。感应电机的例子应追踪旋转磁场、转子感应电流和转矩，而不只是展示外壳。

内部可选辅助工具 `pnpm scene:new induction-motor --medium three` 创建未发布的 `drafts/<slug>/` 草稿。支持 `three`、`svg`、`canvas`、`audio`、`hybrid`。它写入 `brief.md`、`storyboard.json`、`narration.json`、`zh.mdx`、`en.mdx`、`review.md` 和 `integration.md`，已有草稿目录不会被覆盖。它不生成模型、渲染器或录音，也不做公开登记；使用草稿后仍须完成下文的接入要求。

## 先分镜，后旁白

自动演示 **2–5 分钟，推荐 2–3 分钟，5 分钟封顶**。每章必须增加一个可见观察、因果步骤或受控对照。在原来的短循环上延长讲解不能交付。

每章明确追踪对象、关注细节、可见变化、驱动变化的模型状态、它证明的结论、镜头与手机构图、短字幕和对应口语稿。编码前画出初始、认知转折、结果三个关键画面。

内部结构、接触和遮挡可以使用 3D；矩阵、波形、像素、时序和切片应直接表达。参考[自行车案例](examples/bicycle-brief.md)和[复盘](retrospective.md)，不要复制另一篇的面板布局。

## 实现完整静音主线

方程、单位和约束放在 `src/models/`，重计算放入 Worker。图形、读数与标注来自同一状态。机械检查节距、切向、相位和闭合；系统比较保持相同输入和对象身份。

`useShowcase()` 提供 `chapter`、`chapterTime`、`chapterProgress`、`chapters`、`time`、`run`、`watch`、`playing`。按章节相对进度安排镜头，不绑定旧片的绝对秒数。有历史的模拟用确定性回放，前后跳转应与连续播放一致，暂停时不能继续积分。

先完成静音也能看懂的因果过程，再增加自由探索。明确教学简化；JPEG 系数数量不是文件大小，Transformer 生成不能更新权重。

## 双语写作与音轨

中英文分别写成自然口语，指出此时该看哪里，给观众反应时间，再解释变化。不要照读 UI，也不要用更多文字填充缺少画面的时段。

每段口语都要对照桌面、手机和适用的二维备选构图。手机可能移走时序表，或把曲线放到电路下方；此时用指令编号、信号或仪表名称指示，不能沿用已经不存在的“右边”“下面”。改写前确认画面确实有对应对象，只重录受影响的口语，并重新测量两种语言的共用窗口。区分对象换了位置与因果画面被删掉：章节讲保持架运动、接收屏或供能输入时，手机和后备构图也应保留相应对象，不能只删掉口语指向。

语音讲解默认开启，遵循已保存的手动选择及页面语言。浏览器阻止有声自动播放时，保留明确的主动开启入口，静音演示仍可继续。降噪实验的纯音仍须单独主动开启。

源文件为 `src/data/narration.json`。每段包含 `id`、`title`、`titleEn`、`caption`、`captionEn`、`zh`、`en`、`seconds`（最低计划窗口）、`chapterAt`、`at`。生成器测量两种语音并留出停顿，共同生成 `film-timeline.json`、`audio-tracks.json`、`audio-manifest.json` 与内容哈希 MP3。**不对语音变速。**

```sh
python3 -m venv .venv-voice
.venv-voice/bin/pip install -r scripts/requirements-voice.txt
.venv-voice/bin/python scripts/generate-narration.py --only induction-motor
```

制作使用 Microsoft Edge 在线语音与锁定版本 `edge-tts`，需要联网，普通构建与访客不调用此服务。详见[来源说明](third-party-notices.md)。实测超过五分钟时修改分镜和稿件。只生成改动专题，稿件、清单和录音一起提交。

两种声音都要检查清晰度、术语、语气和镜头同步。可选的 `scripts/audit-narration.py` 使用 Workers AI 独立转写每段录音，也可在 Apple silicon 上安装可选 `mlx-whisper` 后使用 `--backend mlx` 本地转写。两者都不提供语言提示或参考稿，可识别错误语言、乱码和结尾截断，但不能认证自然度，不能称作真人试听。凭据只用于本地制作，不进入 CI 或站点。

批次审看后，两个配音工具都可以在 `--only` 后接多个专题，各自使用有并发上限的工作池。生成器在录音组装成功后更新选中音轨及实测元数据；转录审计只将报告写入被忽略的 `artifacts/narration-transcription.json`，不修改影片或声音清单。由一个接入负责人协调运行，其他并行 worker 不同时写入公共声音清单或同一审计报告。未改动的缓存语音保留原有内容哈希。云端每日额度耗尽时停止转录请求，不为完成审计升级账户。

## 接入

| 文件                                                                    | 要求                                                               |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `src/data/topics.ts`                                                    | 唯一 slug 和编号、元数据、资料、相关专题                           |
| `src/data/discovery-metadata.ts`                                        | 六类兴趣分类之一、8／10／12／14 岁中的建议起看年龄、中英文搜索别称 |
| `src/data/experiments.ts`                                               | 实验组件的显式按需导入                                             |
| `src/content/<slug>.mdx` 与 `src/content/en/<slug>.mdx`                 | 完整正文及 `understand`、`try`、`deeper` 锚点                      |
| `src/i18n/en.json`                                                      | 标注、字幕和元数据，保留插值占位符                                 |
| `src/data/narration.json`、生成的时间轴／声音清单与 `public/narration/` | 两种音轨、对应段落和实测窗口                                       |
| `src/components/covers/` 与 `src/components/TopicCover.astro`           | 从模型推导的原创封面并接入目录；其他封面画幅需要时复用几何         |

服务端渲染与英文客户端入口通过 `src/i18n/english.ts` 加载词典，保持 `en.json` 不进入中文客户端的共享依赖。共享模块不在模块初始化时翻译标注，应在组件渲染时翻译。

同步维护 `docs/catalog.md` 和 `docs/zh-CN/catalog.md` 的完整源码目录，使用相同的发现分类与实测影片时长。元数据回归会逐篇核对两个目录与正式登记，防止新增分类或专题后遗漏。

路由、分段讲解、结构化数据、语言替代链接、PNG 分享图和 sitemap 随构建生成。检查实际封面在 400×230 目录、适用的首页后备视图及 `SocialCard.astro` 分享图中的表现；部分器物还会通过 `ObjectCover.astro` 和 `CollectionCard.astro` 展示。各画幅分别检查构图、接触与纸路／链路，并核对透明背景和重复 SVG ID。登记测试只能查缺项，不能判断表达是否精致。

一次新增多个场景时，agent 必须主动使用 subagent，充分利用可用并发能力，优先为能独立推进的场景分配负责人。派发时写明目标、适用技能、负责文件和验收要求；资料核查、模型审查和视觉／交互复核也可拆成独立子任务。主 agent 协调共享文件、集成并逐篇审看，不能用子任务完成声明代替实际验收。

每个场景负责人负责模型、渲染器、样式、双语正文、分镜和封面。`src/data/scene-packets/` 中的交付文件包含待审的元数据、译文和配音稿，不会自动登记公开路由。接入负责人审看交付、处理公共措辞、分配编号并生成录音。`node scripts/integrate-scene-packets.mjs <slug> [<slug> ...]` 默认只检查，加 `--apply` 才更新 `topics.ts`、`experiments.ts`、`TopicCover.astro`、`en.json` 和 `narration.json`，遇到翻译冲突或已登记专题会停止。它不补发现元数据或源码目录、不生成录音、不执行审看或发布；须完成这些步骤，再移除已消费的交付文件，让正式登记保持唯一内容来源。

worker 不对共享输出运行全局格式化、构建、配音生成或部署。制作、审看和修复保持有界队列：专题冻结交付后，接入负责人接管文件，并给 worker 分配另一个已就绪的独立任务。合成前冻结文稿，声音清单始终只有一个写入者。独立审查目录安装自己的依赖，禁止用符号链接共用 node_modules。

## 审看与发布

完整场景执行 `pnpm scene:check`、`pnpm verify`、`pnpm build:preview`。第一项检查登记、双语内容与声音契约；`verify` 包含格式、本地文档链接、Astro 检查、测试、生产构建及其审计；预览命令单独构建并审计带 noindex 的 `dist-preview/`。局部纠错只重建受影响的资产并做对应检查，不重录未改的语音。分别记录实际版本、环境和证据：

1. 完整静音主线、暂停、重播、每章跳转和自由探索。
2. 双语音轨、缓冲、播放受阻、语言切换、离屏暂停。
3. 关键停帧、机械接触、闭合路径、极值、标注对齐和镜头边界。
4. 桌面、390px、320px；键盘和触控目标；减少动态效果、WebGL / Worker 失败、深链接与 404。

启动能力门禁与运行时失败分别检查。缺少 WebGL 2 或其他必需能力时，实验引擎与首页器物不会加载，应检查能力提示及仍可阅读的静态文章／目录。通过门禁后，渲染器创建失败或上下文丢失才使用相应场景的后备视图；运行时二维降级不代表支持启动时已被门禁拒绝的浏览器。详见[浏览器支持](architecture.md#浏览器支持)。

正文至少 16px，主要操作目标至少 44px。缩窗不是手机硬件性能实测，未覆盖条件必须明确记录。新发现应改进流程，避免堆积无关检查。

交付包含实际场景、预览与证据。推送 main 会自动上线，应先完成科学、视觉和配音审看。按[部署手册](deployment.md)及会话已有授权推进，普通内容贡献不改变域名归属或仓库可见性。

agent 创建或重写的提交须遵循 [AGENTS.md](../../AGENTS.md) 中准确的 `Co-Authored-By` trailer 要求，包括 amend、squash 和合并提交。保留原作者与有效的已有署名，并检查最终提交说明。详见[贡献指南](contributing.md#agent-提交署名)。

公式写法必须符合已安装的 Astro MDX 管线。使用现有 `formula` 区块和可读的行内记号；当前没有配置美元符号包裹的 TeX，花括号可能被当成无效 JSX 表达式。单独 MDX 编译不能替代实际生产构建。

章节定位必须在实际资产站验证：深链接、第二次跳转和重播后，同时核对声音时钟与画面时钟。某些静态服务忽略字节范围请求；共用播放器只在需要定位时回退为本地 Blob，并在离开时中止请求、释放对象 URL。正常播放使用支持 Range 的本地预览，同时用不支持 Range 的服务单独验证兼容逻辑。HTTP 成功与媒体就绪都不能证明定位正常。

## 从审看继续到修复

路由全部接入后，持续使用同一并行队列。每次交接注明实际版本、独占文件、可复现发现和证据缺口，随即分配具体修复或下一组未审专题；作者自查与交叉审看分开记录。冻结交付后文件归接入负责人处理。审看快照保持不变，修复先核对文件哈希，再复制到另一个整合快照。浏览器或设备限制只延期对应证据，模型和代码等独立审查继续推进。

逐章测量包含最长双语字幕和播放控件的整个播放器。本体变短不代表手机页面已经紧凑；优先展示当前因果视图，减少桌面面板的纵向堆叠。会随 SVG 缩小的标签改用真实 CSS 像素排版。相机按实际装配投影检查近侧角点、厚度与活动部件，不能只套名义宽高。暂停、直接跳转与过渡分别检查。

只精简屏幕字幕时，同步修改 `narration.json`、`film-timeline.json` 的对应字幕及 `en.json`。口语稿、时间、声音清单与录音哈希保持不变，不为缩短字幕重生成配音。必要的科学限定保留在可见说明或可展开细节中。
