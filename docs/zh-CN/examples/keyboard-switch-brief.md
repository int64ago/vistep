# 机械键盘轴体 — 制作说明

[English](../../examples/keyboard-switch-brief.md) · [专题制作](../creating-a-scene.md)

观看者最初可能只记住“红、茶、青”，或把轴体简单分成安静和吵。本片用三个可见问题代替这种概括：手指受到怎样的力，什么部件发声，键盘怎样检测按压。持续跟住一颗可信的键帽、外壳和轴心，重建塑料导向、金属弹片、弹簧座与触点。通过明确的前侧观察剖面显示内部关系，不用通用方块换颜色，也不宣称是厂商精密 CAD。

录音前计划 **206 秒，即 3:26**，共九章。每章增加观察。第六章包含银轴与静音轴两段对照，不能将“行程短”与“有缓冲”说成同一种特性。

录音后，[共同影片时间线](../../../src/data/film-timeline.json)实测为 **213.5 秒，即 3 分 33.5 秒**。下表保留原定窗口作为设计记录；最终章起点依次为 0、22、44、66、91、113.5、139.5、165.5、189 秒。时长测量不等于原生试听。

| 编号 / cue         | 计划窗口   | 主体与可见变化                                                                     | 因果关系与配音指引                                                                              |
| ------------------ | ---------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 0 / `parts`        | 0–22 秒    | 键帽带动轴心；有固定座的弹簧压缩并返回；触点间隙闭合再张开。                       | 把机械运动、回弹与检测连成一次按压，剖面中保留三个可见部件。                                    |
| 1 / `linear`       | 22–44 秒   | 红黑轴使用相同行程轨迹，同深度的力标记不同。                                       | 线性不代表一样重。窄屏可保留一颗大主体，但两种对照身份必须明确。                                |
| 2 / `tactile`      | 44–66 秒   | 镜头靠近茶轴轮廓与弹片的接触；阻力越过段落后下降。                                 | 轮廓与弹片造成手感，不能只有一条隆起的曲线。                                                    |
| 3 / `clicky`       | 66–90 秒   | 青轴白色套件相对蓝色轴心跳移，松开时复位。                                         | 两件式结构造成点击事件。触觉、声音、电信号分开显示；不制作冒充真实轴音的声样。                  |
| 4 / `actuation`    | 90–112 秒  | 红轴先停在 2 mm 触发处，再停在 2.5 mm，随后真正按到 4 mm 底部，再回抬复位。        | 在同一颗轴体上分开观察电信号、继续行进、物理触底和回程复位；2.5 mm 只是中途停留，不是行程上限。 |
| 5 / `speed-silent` | 112–138 秒 | 先用相同部分行程比较银轴和红轴，只有银轴先触发；后半观察静音红轴上下端缓冲接触。   | 短预行程不等于小触发力。缓冲减轻撞击，不会消除全部机械声音。                                    |
| 6 / `hall`         | 138–164 秒 | 轴心磁体靠近电路板传感器；同一段回抬再按轨迹同时驱动固定点和普通 RT 两条输出历史。 | 位置测量与有历史的固件规则共同决定输出；两个规则使用完全相同的输入。                            |
| 7 / `optical`      | 164–186 秒 | 轴心开口对准固定发射器与接收器，只有开口重叠时才出现透射光段。                     | 本例按下后通光；弹簧和运动仍属机械部分，不把逻辑反画成阻光触发。                                |
| 8 / `compare`      | 186–206 秒 | 根据需要切换实物，回顾手感、声音来源、检测方式三个标签。                           | 分别比较三种维度，不要求同时摆八颗轴体，不做品牌排名。                                          |

最终界面在桌面和手机都把紧凑的力曲线或状态仪器放在实物下方，保持沿同一观察顺序阅读。320/390 px 手机重新安排实物近镜，只保留当前章必需的辅助图；正文标签用至少 16 px 的 HTML，主要操作至少 44 px。配音不用屏幕左右定位。开场保留完整外观，局部镜头配定位提示；封面共用真实场景几何，让十字轴心、弹簧和触点可辨认，不堆标签。

## 一级来源与边界

资料核对日期：2026-09-12。CHERRY 的 [Red](https://www.cherry.de/en-gb/product/mx2a-red)、[Black](https://www.cherry.de/en-gb/product/mx2a-black)、[Brown](https://www.cherry.de/en-gb/product/mx2a-brown)、[Blue](https://www.cherry.de/en-gb/product/mx2a-blue)、[Speed Silver](https://www.cherry.de/en-gb/product/mx2a-speed-silver)、[Silent Red](https://www.cherry.de/en-gb/product/mx2a-silent-red)产品页提供代表结构与标称锚点。

| 型号         | 触发力 / 段落峰值 | 预行程 / 总行程 |
| ------------ | ----------------- | --------------- |
| Red          | 45 cN / 无段落峰  | 2.0 / 4.0 mm    |
| Black        | 60 cN / 无段落峰  | 2.0 / 4.0 mm    |
| Brown        | 45 / 55 cN        | 2.0 / 4.0 mm    |
| Blue         | 50 / 60 cN        | 2.2 / 4.0 mm    |
| Speed Silver | 45 cN / 无段落峰  | 1.2 / 3.4 mm    |
| Silent Red   | 45 cN / 无段落峰  | 1.9 / 3.7 mm    |

茶轴和青轴的英文摘要容易混淆两种力。茶轴 Properties 明确列 45 cN 触发力，[官方法语页面](https://www.cherry.de/fr-fr/produit/mx2a-brown)同时明确区分 45 cN 触发与 55 cN 段落峰值。[青轴技术数据表](https://www.cherry.de/fileadmin/media/Industrial/Switch/MX_BLUE/Data_sheet_MX2A_Blue.pdf)分别列出 50 和 60 cN。该 PDF 的官方搜索索引可核读，直接打开返回错误；不能把摘要里的峰值当作触发力，也不能把教学拟合的触底力标成官方数据。

青轴正文说明了两件式轴心。官网 HTML 中的爆炸动画参考为 [青轴](https://www.cherry.de/fileadmin/media/Industrial_Security/Switch/MX_BLUE/MX1A-E1NA_ExplodeANIM.mp4)、[茶轴](https://www.cherry.de/fileadmin/media/Industrial_Security/Switch/MX_BROWN/MX1A-G1NA_ExplodeANIM.mp4)、[静音红轴](https://www.cherry.de/fileadmin/media/Industrial_Security/Switch/MX_SILENT_RED/MX3A-L1NA_ExplodeANIM.mp4)。内容作者仅提取真实资源 URL 并交给几何作者，不以此声称已观看动画；产品不直接复制厂商图像。[CHERRY 总览](https://www.cherry.de/it-it/lazienda/notizie/cherry-blog/article/cherry-mx-switches-at-a-glance)解释上下端缓冲。

[Wooting 霍尔轴说明](https://wooting.io/post/what-are-hall-effect-keyboard-switches)支持轴心磁体与电路板传感器的关系；[Rapid Trigger 设置说明](https://help.wooting.io/article/102-how-to-set-up-rapid-trigger)支持初始触发、依运动距离复位与再触发，以及普通/持续模式的区别。该来源也记载模拟光轴的实现，不能称 RT 为磁轴独占。[Razer 光轴说明](https://www.razer.com/razer-optical-switch)明确按下后光通过轴心，本片不代表其他遮光或连续光量检测方案。

独立模型中的准静态力曲线、机械复位阈值、弹片形变、套件轨迹和内部显示尺寸均为教学拟合，不是逐点测量或精密零件参数。霍尔读数采用归一化、单调的类似偶极距离关系及其反函数，不是有限磁体场解、真实电压、磁场强度或 Wooting 标定。普通 RT 由路径极值重建，首次经过阈值启用，回到该阈值上方退出；两种规则共用一段部分回抬轨迹。本片不提供轴音实录、冒充实录的合成声或整机延迟排名。

## 验收与分工

内容作者负责双语 MDX、双语 brief 和临时 packet；模型与几何分别由独立作者负责。root 负责实验界面、共享登记、翻译、录音、浏览器验收及已授权交付。packet 只是交接文件，集成后不能成为第二份事实源。发现元数据建议使用 `mechanisms`、起始年龄 10，含各类轴体、霍尔、光学、预行程与 RT 的双语搜索词。

录音前逐句对照桌面、320/390 px 与后备画面，特别核查茶轴接触区、青轴套件回程、静音上下端接触以及 RT 同一输入。数值检查应覆盖弹簧端点与线圈、接点几何和电状态、公开力锚点与拟合支路、任意跳转、RT 极值历史和光孔透射。测试不等于完整观看或试听；root 另记正常速度播放、暂停/跳转、响应布局、减少动态、资源失败与录音时长。此制作说明不声称已完成浏览器、声音或真机验收。
