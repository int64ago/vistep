# 制作示例：自行车变速

[English](../../examples/bicycle-brief.md) · [制作指南](../creating-a-scene.md)

**核心疑问：**相同踏频下，换挡为什么同时改变速度和踩踏力？

**跟随对象：**一节金色链节。它的完整回路连接齿距、曲柄运动与后轴旋转。双轴三维试验架保留这些关系，移开无关的车身细节。

## 章节安排

| 章节  | 可见证据                                                 |
| ----- | -------------------------------------------------------- |
| 1–4   | 跟随闭合回路，近看齿距，数齿，连接齿数比与后轴旋转。     |
| 5–6   | 换小后齿轮，在相同踏频下比较速度与所需踩踏力。           |
| 7–9   | 换大后齿轮，增加坡度，再改变踏频；每次改变对应真实计算。 |
| 10–12 | 对照功与功率，展示模型边界，回看三种齿比。               |

时长以[生成时间轴](../../../src/data/film-timeline.json)为准，不在文档中重复维护秒数。导演按踏频积分曲柄转数，几何与读数共用齿数。独立参数实验呈现为新的稳态配置。

## 构图与模型约束

总览保留双轴、曲柄、链条与回程；近景让啮合可检查。手机保留完整链路。换挡切换到张紧的配置，并未模拟拨链器全过程。

[稳态模型](../../../src/models/bicycle.ts)包含坡度、滚阻、风阻和 96% 传动效率，计算维持踏频所需功率，不假设骑行者功率无限。比较条使用相同踏频与坡度。

[几何模型](../../../src/models/mechanisms.ts)共用节距与偶数链节。测试枚举前盘 34/50、后盘 11–34 和八个相位，相邻链辊间距容差为节距的 1.5%。这是采样几何检查，不是所有相位接触关系的解析证明。

## 审看要求

模型与几何变化检查不变量和极值停帧；镜头变化检查宽窄构图；配音变化检查两种语言与同步。旧版本审看不能替新镜头、录音或时间轴背书。
