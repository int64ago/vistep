# 手机漫游：外国网络怎样认出你

[English](../../examples/mobile-roaming-brief.md)

## 问题与范围

出了国，手机怎么还认得你？常见的直觉是“家乡运营商的信号伸到了国外”，或者“当地网络直接相信 SIM 卡”。关键观察推翻了两者：当地网络从来拿不到用户密钥 K。它从 IMSI 的国家码与运营商码读出归属网络，经漫游互联网络 IPX 向家里要一组认证向量；SIM 用 K 对随机挑战算出应答来证明自己，同时用 AUTN 验证挑战确实来自家里。随后家里记下用户所在网络，电话和数据按这条记录与漫游架构选择路线。

跟踪对象是一份签约身份：IMSI 的数字，以及从不离开 SIM 与归属网络的 K。范围包括自动选网、基于 MILENAGE 的 EPS AKA、S6a 位置更新、绕回家与就地出口两种数据路径、电路交换的被叫流程。小区、测量与切换属于兄弟专题 `cell-handover`，无线速率属于 `mobile-5g`。建议起始年龄 12 岁：影片需要理解多位编号、双方共享秘密与往返时间；十六进制与公式属于可选内容。

## 视觉方向

一张平静的两国地图切片：左边旅行地，右边家乡，中间是海和 IPX 节点。网络要素都是小图形（带 SIM 的手机、A/B/C 基站、MME、IPX、HSS、网关）；金色钥匙只出现在手机 SIM 和家里的 HSS 旁，每一帧都如此。地图下的四个泳道标题（手机、当地网络、IPX、归属网络）向下延伸成消息阶梯的生命线，地理位置与消息顺序共用同一组横坐标。各章面板换用不同形式：从信号顺序重排为 SIM 优先级的网络列表、拆成彩色数字格的 IMSI、真实 MILENAGE 数值的字节格、归属网络的用户记录卡、分段往返时间条和来电阶梯。面板下只留一句限定说明，模型边界放在探索模式的展开说明里。

手机构图：地图重新排成 192 px 高、去掉节点标签但保留泳道标题；每个面板重新布局（字节行折成每行 8 格，标签移到行上方，数据与来电章节隐藏会遮挡的国名）。所有 SVG 文字按 16 px 编写，viewBox 与实际宽度相同，渲染后仍是 16 CSS px。

## 模型与边界

- `src/models/mobile-roaming-milenage.ts`：AES-128（FIPS-197）与 MILENAGE f1–f5、f1*、f5*（TS 35.206），HMAC-SHA-256（复用本站 SHA-256 模型）与 K_ASME 派生（TS 33.401 附录 A.2），以及 BCD 编码的 PLMN。测试逐项复现 FIPS-197 示例、TS 35.208 测试集 1 和 2、RFC 4231 的 HMAC 用例。
- `src/models/mobile-roaming.ts`：显式 MNC 位数的 IMSI 解析、归属域名、TS 23.122 自动选网顺序（标准对高质量组随机排序，模型按信号排序以便重现）、含篡改情形的 AKA（K 错一位、改 RAND、重放旧向量并生成 AUTS）、含 5004 拒绝的位置更新、只计传播的时延模型（光纤 204 km/ms、1.4 倍绕行、无线 25 ms、每节点 2 ms），以及带跨国段计数的来电路由。
- `src/models/mobile-roaming-film.ts`：以章节进度定义节拍，拖动时可确定地重建。
- 身份均为虚构或测试值：001-01 是 3GPP 测试 PLMN；MCC 002 与 A/B/C 三家运营商是虚构的；K/OP/RAND/SQN/AMF 取自 TS 35.208 测试集 1。信号值为示意。NAS 安全模式、加密、SUCI 计算、IMS、话单与优化路由只在文字中说明。
