## 一个粒子的显微观察

以金色微球为唯一追踪对象，从不规则路线开始，再进入惯性时钟、参数对照和重复实验。与 diffusion 的浓度 PDE、convection 的整体流动分开；不绘制装饰性分子、随机反弹球或光子轨迹。

原生 SVG 显微视野使用柔和底色、固定原点与物理标尺。开场放大同一长观测的第一秒。纳秒章另起一次短观测，只放大质心位移，明确说明圆点不表示真实半径。长时间对照的惯性与过阻尼轨迹由同一积分热浴驱动。参数对照以半透明球体轮廓保留真实相对半径，避免大球盖住小球。

边缘是观察窗口，不是容器。模型没有反弹、周期穿越或瞬移。构图根据整次所选轨迹及球半径计算，保留 20% 径向余量；参照网格不代表被求解的流体。文字采用原生宽度坐标，至少 16px。

## 独立模型与数值方法

内部采用 SI 单位。默认 T = 300K、η = 0.001Pa·s、a = 0.5µm、ρ = 1050kg/m³。玻尔兹曼常数精确取 1.380649 × 10⁻²³ J/K。质量 m = 4πρa³/3、阻力系数 γ = 6πηa、τ = m/γ、D = kBT/γ；默认 D = 0.439474226µm²/s，τ = 58.333333ns。

每个方向满足 `m dv = −γv dt + √(2γkBT) dW` 与 `dx = v dt`。初始位置为零，速度各分量按热平衡高斯分布采样，方差 kBT/m。零温章有意保留参考初速度，属于非平衡初态。

数值采用位置与速度的联合高斯精确转移，不是 Euler 随机踢动。设 h = Δt/τ、A = exp(−h)、B = 1−A，无量纲条件噪声协方差为 Qvv = 1−A²、Qxv = B²、Qxx = 2h−2B−B²。速度单位为 √(kBT/m)，位置单位为 τ√(kBT/m)。小 h 级数和 `expm1` 避免相消；Cholesky 分解产生关联噪声。

随机数通过种子与序号寻址的哈希 Box–Muller 生成，没有全局随机游标。四秒长观测用 512 个区间，12τ 惯性观测用 384 个区间。最近一个完整的 16 步冲量窗宽度是 0.5τ。阻力冲量为 −γΔx，热浴冲量为 mΔv + γΔx，条形图来自这两个真实积分量。

积分方程也给出 `xOD = x + τ(v−v0)`，因此可直接构造同一热浴的过阻尼位置，无须在一秒内积分数十亿个极小时间步。

两个观测坐标的理论均方位移是 `4D[t−τ(1−exp(−t/τ))]`，短时极限为 `2(kBT/m)t²`，长时为 `4Dt`。三维系数不同。平均位置、样本均方位移和均方根均由相同的 64 条轨迹计算；圆圈表示理论 RMS 尺度，不是围墙或某个置信概率边界。

精确转移只保证离散观测时刻的模型分布。直线显示插值与轨迹抽样不代表更细时刻被解析。过阻尼数学路径不光滑；带惯性的模型位置具有速度，不能把“不光滑”无条件延伸到任意短的惯性尺度。

## 简化、手机与资源

采用均匀、无边界、各向同性的经典热浴和稀悬浮无滑移球。省略整体流、外力、墙壁、粒子作用、重力、约束、流体附加质量、流体记忆、有限分子碰撞时间和仪器噪声。自由空间位置持续展开，没有可归一化的静止平衡分布；速度仍可维持热平衡。真实液体极短时需要流体修正，纳秒章明确解释理想 Markov 模型。温度与黏度独立设定，不声称零温或 450K 下参考液体仍实际存在。

场景本身就是完整二维 SVG，无需 WebGL、透视相机或另一个简化渲染器。没有音频上下文、Worker、外部资产、定时器或动画循环。轨迹缓存有明确上限，统计仪表最多采样 129 点；单个 ResizeObserver 在卸载时断开。离屏、后台与减少动态效果由现有 Showcase 导演管理，场景不推进自己的时钟，控件 CSS 过渡在减少动态效果时关闭。

手机按章节选择 345px 单粒子视野、265px 质心视野或 252px 重复实验视野，仅附当前仪表。320px 闭合 watch 舞台在双语检查中为 663.039–852.383px。展开探索后允许更长内容。按钮实测高 46.398px，滑块 44px，均有显式翻译名称。重置恢复 300K、1mPa·s、0.5µm、种子 137、单条轨迹、两秒及隐藏的 6τ 惯性时间。
