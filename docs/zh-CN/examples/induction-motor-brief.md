## 因果主线与器物表达

转子没有电源引线，也没有永磁体。跟随计算出来的旋转磁场进入闭合鼠笼，转折点是完全同步：追上磁场以后，转子的感应电流与驱动力矩反而归零。带负载运行需要一点落后，这个转差同时决定转子铜耗占气隙功率的比例。

深青色机座托住剖开的灰绿色定子，露出温暖的铜条与两只完整端环。定子不是实心圆环里硬塞几根线：六个真实槽腔避开三个连续绕组束。每组示意三匝，有两个独立端头、供电端子与相连的星点。转子有 24 根与端环接触的导条、叠片铁芯、连续轴、轴键、轴承与支撑。线圈路径、导条端点、端环、端子与槽腔来自同一模型。电流不使用粒子代替。

主证据是轴端圆形截面：绕组空间轴、主磁场和铜笼标记可以直接比较。启动、同步、负载与功率章节分别换成对应曲线或收支图，不保留一堆始终不变的仪表。

| 时段       | 可见变化                                   | 因果观察                                                 |
| ---------- | ------------------------------------------ | -------------------------------------------------------- |
| 0–22 秒    | 三个空间方向的作用合成绿色磁场；转子固定。 | 定子不动，三相电流仍能产生旋转主磁场。                   |
| 22–44 秒   | 磁场转两圈，铜色转子标记保持不动。         | 一对磁极、50 Hz 对应同步转速 3000 rpm。                  |
| 44–66 秒   | 导条中出现方向标记，前端环显示返回路径。   | 两只端环把导条连接为闭合电流通路。                       |
| 66–88 秒   | 从静止释放转子，启动曲线先升后平。         | 转矩加速惯量，转差下降使感应减弱。                       |
| 88–110 秒  | 外力指定的转速逐渐达到同步。               | 转差、转子电流、转矩同时准确归零。                       |

## 手机构图与操作

以场景自身宽度 620 px 为分界，手机镜头更接近沿轴观察，并单独设定目标和取景范围。多数章节主机器高 248 px，导条回路章为 263 px，功率章为 206 px。每章只挂载当前需要的一个仪器：启动、同步、负载、功率章都不再附加磁场图。手机删去重复的仪器标题和次要曲线解释，当前一句说明紧邻因果证据。

关闭扩展说明时，观看舞台保留最小高度，以减少播放器位置变化；320 px 视口下的目标是约 900 px 以内。**本工作者没有测量实际浏览器中的舞台高度。** 图表文字使用 HTML，磁场截面使用独立的 300 单位坐标系和 20 px 相标记；正文与操作文字至少 16 px，主要按钮和滑块高度至少 44 px。展开说明和探索后增加高度属于主动操作。

探索可以选择稳定负载或直接设定转差，停在一个电源相位，改变相序，切换磁场、转矩、功率观察，并重置。滑块明确关联标签，按钮使用原生键盘与焦点语义。3D 镜头使用共享 Studio 操作。WebGL 失败或切换二维时，轴测图仍保留闭合铜笼、转子标记、绕组和磁场；截面与仪表继续使用同一个状态。

## 独立模型与简化

每相电路为 `R1+jX1` 串联 `jXm` 与 `R2′/s+jX2′` 的并联。相电压 120 V、频率 50 Hz、一对磁极；R1 = 0.65 Ω，X1 = X2′ = 0.9 Ω，Xm = 30 Ω，R2′ = 0.5 Ω。电流为有效值，转子量折算到定子侧。参数用于教学，没有绑定某款电机或从外观尺寸反推电气性能；可见三匝代表绕组束，不据此宣称真实匝数与空间谐波。

同步角速度 `ωsync = 2πf/p`，转差 `s = 1−|ωrotor|/ωsync`，转子电气频率 `frotor = sf`。A–B–C 对应绕 +z 的正方向；反向相序使转矩与机械速度同时变号，正常电动运行的机械功率仍为正。

求解器使用导纳 `s/(R2′+jsX2′)`，同步时不除以零，也不用假小转差。`P气隙 = 3|Egap|²R2′s/(R2′²+(sX2′)²)`，转子铜耗为 `sP气隙`，机械转换为 `(1−s)P气隙`，转矩为带方向的 `P气隙/ωsync`。定子铜耗为 `3|I1|²R1`，真实输入功率独立从端电压与复数定子电流求出。励磁电流为 `I1−I2`，它的平衡三相空间矢量和决定绿色主磁场。A、B、C 读数显示瞬时定子电流。

铜条电流采用空间基波、等效转子电流幅值、相序符号和转差对应的阻抗角。它们是归一化相对电流，不是单根铜条的实物安培数。前端环解 `Kj−Kj−1=Ibar,j`，去掉环流偏置，后端环方向相反，所有节点满足电流守恒。等效转子电阻包含铜笼整体损耗，没有逐段求解实物导条和端环电阻。

稳定负载只取最大转矩点之前的低转差根。本参数集的最大转矩为 25.900074 N·m，转差 0.2647304。0–6 N·m 的手动负载处在稳定支，达到或超过最大转矩的请求被拒绝。6 N·m 的稳定转差为 0.02476271；零负载在这个无机械损耗的理想模型中会达到同步。

启动以固定 2 ms 的 RK4 表积分 `J dω/dt = T−1 N·m`，J = 0.025 kg·m²，从静止开始；2 秒时约 2988.31 rpm。这是准稳态加速包络，不是开关电磁暂态。任意时刻的机械转换功率分为负载功率和动能增长。正、反两次启动都从静止重建。指定转速和稳定负载章节是运行点比较，不冒充自由加速。

角度检查对电源和转子采用相同慢放比例，启动横轴保留物理模型秒数。变速检查角度通过速度积分得到，不使用“末速度乘经过时间”。启动表与角度表不可变，和渲染历史无关。状态只依赖共享章节、进度和手动输入，没有随机相位、独立时钟或帧历史。

模型明确忽略铁耗、风摩耗、轴承摩擦、饱和、集肤效应、电阻温变、绕组空间谐波与快速电磁暂态。几何是结构教学剖面，不是制造图，效率不是实物性能预测。
