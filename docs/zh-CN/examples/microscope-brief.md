## 问题与导演方向

看得更大，是否就能看出更多细节？先追踪一个几何示踪点，经过物镜、真实中间像面和目镜；再换成可计算的荧光点靶。光路回答像在哪里，孔径积分回答这个像有多宽。

开场是一条展开的靛蓝光学台：镜片用克制的主平面符号，金色和浅青色表示光线，珊瑚色标出中间像面。随后切换为圆形观察视场及当前所需的一条调焦尺或剖面。采用 SVG/Canvas，没有透视相机或装饰性三维。轴向与横向显示比例不同，但每段直线严格由模型坐标映射。镜片轮廓明确是薄透镜符号，不把主平面折转伪装成真实镜组表面折射。

标本是两个互不相干的荧光点，或在深度方向相隔 20 µm 的两排点。没有照片、预绘清晰版本或 CSS 模糊。每个光斑、强度剖面、像点位置与标尺都来自同一套计算。开场较高的离轴点是单独声明的光路标记，不冒充微小点靶的另一个放大视图。

## 光线模型

光路单位为 mm，方向使用近轴斜率。自由传播矩阵为 P(L) = [1, L; 0, 1]，薄透镜矩阵为 L(f) = [1, 0; −1/f, 1]，两者行列式都是一。物镜焦距 8 mm，固定中间像距 160 mm，清晰物距 u₀ = 8.4210526 mm，对应横向放大率 −19。160 mm 是光学主平面距离，不是商用物镜机械镜筒长度的声明。

标本层深度为 z、载物台偏移为 F 时，u = u₀ + (z−F)/1000，真实几何像距为 1/(1/f−1/u)。每条线选择孔径分数 a，从标本高度到达物镜上的 ar，按 θ′ = θ−y/f 折转，再传播到目镜并再次折转。显示末端没有手工吸附到焦点。

孔径半径 r = u₀ NA₀，控件设定名义近轴孔径，当前值为 r/u。精确正弦定义为 sin(arctan(r/u))，在支持的低孔径范围内差异小于 3%；不外推到高 NA 或油浸模型。目镜焦距为 250 mm 除以参考倍数，位置是 v+fₑ。对焦时同一点出射束平行，参考角放大率为 −v/u × 250/fₑ。250 mm 只是裸眼比较约定，不代表在那里画了实像或视网膜，也不模拟眼睛调节。

固定像面上的质心放大率为 −v/u，即使最佳像面偏移也继续按实际物距计算。几何弥散圆半径为 |r(1+v/u−v/f)|。目镜通光半径设为 2.5 mm，并检查光线是否落在孔径内；当前支持的探索光线均可通过。

## 点像与归一化

波动计算使用相同的 u、v、f 和 r，在固定中间像面计算。λ = 0.55 µm；ρ 为孔径归一化半径，R 为像面径向距离。离焦相位 β = πr²(1/u+1/v−1/f)/λ，长度单位一致后计算：

`I(R) = |2 ∫₀¹ ρ J₀(2πrRρ/(λv)) exp(iβρ²) dρ|²`。

β = 0 时得到 Airy 强度 `[2J₁(q)/q]²`；轴上强度为 `[sin(β/2)/(β/2)]²`。数值方法为 96 段径向 Simpson 积分，径向无量纲表格间隔 0.05、范围至 q = 36。J₀/J₁ 在 14 以下使用收敛级数，以上使用十二项渐近展开，并用独立周期角积分核对。有限只读孔径表约 0.53 MiB，不是帧历史；范围以外的远环被截断。

各荧光点按自己的实际物距计算像面中心和横向尺度，再将强度相加。图像使用 161×161 像素中心采样，固定线性显示参考为清晰单点峰值的 1.25 倍，超范围截断。暖色是单色显示着色，不代表另一个波长。归一化明确用于比较形状，不比较孔径之间的通光量。未模拟光子统计、噪声、像差、矢量偏振、部分相干照明、聚光器、荧光化学或眼睛成像。

目镜控制角视场，名义物方跨度为 16 µm × 10/目镜倍数。已有像与模糊按同一角尺度一起变化。Rayleigh 参考间距采用 Airy 第一零点系数 0.6098349456λ/NA；λ/NA² 仅为声明的衍射景深尺度，不冒充半高宽或普遍清晰阈值。轴向曲线本身直接来自上述积分的轴上解析值。
