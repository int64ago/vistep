## 因果主线与视觉方向

“更软就更舒服”把储能和耗能混成了一件事。本篇沿着路面、轮胎、轮组、车身追踪一次输入，先隔离刚度，再隔离阻尼。对照始终使用相同路面、初始位移和观察时刻；最后在轮胎法向载荷为零处停止，明确线性接触模型的边界。

画面是四分之一车的垂直激振试验架：浅陶瓷色车身、铜色弹簧、剖开的青色减振器、黑色轮胎与金属轮辋，连接在轮架、竖直导轨和带螺栓的激振台上。轮胎不转，因为没有水平行驶输入。导轨明确是试验约束，不是假造的汽车摆臂。弹簧座、减振器吊耳、活塞和杆都跟随模型端点。第五章逐渐淡化轮胎，露出缸筒窗口。

手机按章节重新构图。连接章节保留完整试验架和一个必要读数；刚度、阻尼对照以共用坐标的响应曲线为主画面，配简洁的颜色与参数索引，不堆叠两个总装。接触章节改为紧凑的轮胎剖面与载荷曲线。假设默认折叠。二维后备图独立设计，使用同一模型姿态并保留连接关系。没有下载厂商 CAD、纹理或图片。

## 配音测量前的分镜

计划 176 秒，八章各 22 秒。每段中英文分别撰写，预留 21.5 秒窗口，章节内 0.45 秒开始。父任务负责实测合成、中央时间轴和音频。所有章节通过 `useShowcase` 的章节与进度驱动，测量后时长变化仍保持相同事件顺序。

| 时间       | 可见变化                                          | 因果观察                             |
| ---------- | ------------------------------------------------- | ------------------------------------ |
| 0–22 秒    | 平滑凸起进入连接完整的试验架。                    | 轮胎、轮组和车身有不同响应。         |
| 22–44 秒   | 阻尼为零，凸起过去后继续振动。                    | 理想弹簧会归还能量。                 |
| 44–66 秒   | 12 与 30 kN/m 弹簧接受相同凸起，均无阻尼。        | 更软改变静态下沉与节奏，不替代耗散。 |
| 66–88 秒   | 相同弹簧分别搭配零与 1.4 kN·s/m 阻尼。            | 阻尼使振荡能量逐渐离开。             |
| 88–110 秒  | 固定路面，从 40 mm 位移释放；轮胎淡出露出减振器。 | 机械能减少，累计耗散增加。           |
| 110–132 秒 | 1.4 与 6.5 kN·s/m 阻尼经过同一凸起，比较加速度。  | 较大阻尼也可能更强地传递快速输入。   |
| 132–154 秒 | 带包络的 10.4 Hz 起伏使轮胎载荷到零。             | 线性轮胎不能继续作为拉住路面的弹簧。 |
| 154–176 秒 | 回到默认完整试验架。                              | 车身响应、行程与接触是不同的结果。   |

接触章节前 84% 的进度走到计算出的零载荷时刻，末尾 16% 停留观察边界；释放章节观察三秒物理响应；其他章节观察一段八秒物理响应。没有反复播放短循环来填充讲解。

## 模型、单位与边界

向上为正，`zs, zu` 是相对静态平衡的车身与轮组位移。被动模型：`ms*zs'' = -ks*(zs-zu)-c*(zs'-zu')`；`mu*zu'' = ks*(zs-zu)+c*(zs'-zu')-kt*(zu-r)`。总法向载荷为 `N=(ms+mu)*g+kt*(r-zu)`。默认簧载质量 300 kg、非簧载质量 45 kg、悬架刚度 18 kN/m、阻尼 1.4 kN·s/m、轮胎刚度 180 kN/m。它们是教学选择，不是车型拟合或选购建议。

固定步长 1/600 秒的四阶 Runge–Kutta 积分计算位移、速度、累计阻尼耗散与路面做功。任意拖动由前一个固定网格状态加一个余量步重建，不依赖渲染帧率或历史。对照在最早的零载荷时刻一起停下；用 32 次二分细化边界。这里不计算离地、碰撞或重新接触。

平滑凸起从 0.8 秒开始、持续 0.48 秒。连续起伏使用五秒正弦平方包络，并有解析速度导数。输入是路面平台位移，不是车速。能量为相对静态平衡的正定二次扰动能量；阻尼功率 `c*(vs-vu)^2`，路面功率 `kt*(r-zu)*r'`，满足 `E+D=E初始+W路面`。固定路面的释放试验中路面功为零。累计焦耳不代表油温。

弹簧自由长度始终为 640 mm，静态压缩为 `ms*g/ks`；实际安装长度再加两端相对位移。螺旋外观只标识线性弹簧，不从线径计算刚度。轮胎自由半径 340 mm，静态压缩为 `(ms+mu)*g/kt`，底部接触顶点贴合模型路面。减振器缸筒长 550 mm、杆长 550 mm，活塞插入量随两端位置变化；阻尼系数不改变零件尺寸。忽略俯仰、侧倾、摩擦、轮胎阻尼、悬架限位与非线性阀系，没有制动距离、抓地系数或安全车速结论。
