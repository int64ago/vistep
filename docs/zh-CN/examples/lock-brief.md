# 弹子锁：六个接缝，一条边界

[English](../../examples/lock-brief.md)

## 因果主线与视觉方向

先追踪一根跨住锁芯与固定外壳的上弹子。完整的匹配钥匙沿同一条路径进入，通过圆头接触抬升六组弹子，使接缝对齐，再带动锁芯转动、回正和退出。需要纠正的直觉是“每根下弹子都要抬到相同高度”：它们长度不同，需要同时让开的是接缝。

模型使用蓝灰色固定外壳、黄铜锁芯、浅镍色钥匙与上弹子，选中的下弹子用铜色追踪。后侧外壳和锁芯材料保留，半剖导向孔、钥匙槽底面、支架、弹簧顶盖与尾部拨片形成相连结构。钥匙是有前端斜面、肩部、颈部与匙环的连续实体。没有复制厂家 CAD、图片、纹理或生成图像。封面为完整的 400 × 230 SVG，接受可选 color 参数，其齿形、弹子高度与弹簧端点同样来自模型。

桌面使用完整插入路径、接触近看、回正位置的两把钥匙比较，以及接近轴向的转动视角。总览镜头根据钥匙偏移与整个装置的边界确定中心和宽度。手机改用单组纵剖面解释接触与匹配，短剖面对比解释偏差，端面三维视角解释转动和回正。不会把缩小的总装、局部图、图表和控件继续纵向堆叠。

## 独立接触与让开条件

长度均为展示单位 u，不是商品钥匙编码或加工尺寸。六个固定位置分别有不同的匹配齿台高度与不可变的下弹子长度。钥匙上缘是连续折线，平坦齿台宽于圆头直径；前端渐缩、下边缘固定。另两把钥匙只把第三个齿台改变 ±0.18 u。

位置 x 处圆头的最小不穿透圆心高度为 `max(h(u) + sqrt(r² − (u − x)²))`，同时不能低于钥匙槽底面支承。斜率 a 的线段候选接触位置是 `u = x + ra/sqrt(1 + a²)`，再限制到线段有效区间；检查所有候选包含折点与前端。模型不是直接读取轴线正下方的齿高。钥匙整体移动，下弹子按这一支承包络升降，上弹子和弹簧下座使用同一抬升。

锁芯半径 1.05 u，外壳孔名义径向间隙 0.018 u。相对锁芯半径的接缝误差为 e，则 `e ≥ 0` 表示上弹子不侵入锁芯，`e ≤ 0.018` 表示下弹子不侵入外壳实体。六组必须同时满足，且钥匙肩部完全到位。三个给定轮廓在到位时要么名义精确对齐，要么第三处偏离 ±0.18 u，只有匹配实例可以转动。被阻挡的转角请求不会产生实际位移。

转动采用明确说明的几何理想化：下弹子顶面和上弹子底面沿锁芯圆柱边界弯曲。对齐后，下弹子旋转仍在同一径向包络内，上弹子连续受到锁芯表面支承，不会突然换位置、让弹簧悬空，或让平面端部的实体角点穿过外壳。实际弹子常采用近似平端与倒角；加工配合、弹性接触、摩擦和冲击未纳入。本图的间隙不是生产公差结论。

弹簧为七圈，两端由模型中上弹子顶面与固定盖板确定。中心线端点各让出线半径，渲染线材抵住两个座面。全部给定行程中，圈间轴向间距大于线径，线圈包络小于导向孔。弹簧只说明准静态压缩与连接关系，没有虚构刚度、操作扭矩或开锁力。

钥匙、下弹子、锁芯导向孔和尾部拨片共享绕 X 轴的转动；上弹子、上部导向孔与弹簧座属于固定参考系。手动命令禁止转动时退出、未完全退出时换钥匙。重置恢复匹配钥匙、零插入、零转角请求、第一组与机构视图。二维退化沿用同一高度和轮廓，端面剪切弧也保留相同圆柱边界。不提供拨动单根弹子或绕过机构的控制。
