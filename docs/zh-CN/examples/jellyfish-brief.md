# 水母 — 制作说明

[English](../../examples/jellyfish-brief.md) · [制作指南](../creating-a-scene.md)

## 对象与认知转折

跟随 Aurelia aurita 月水母的一次脉动，再跟住暖色停止涡。初始直觉是“收缩推一下，后面只靠惯性”。转折是伞已完全舒张却仍能再次加速：流体运动继续抵向伞内表面，产生压力与推力。先前做功建立了这段流动，没有免费能量。

主要依据 [Gemmell 2013 PNAS](https://doi.org/10.1073/pnas.1306983110) 与 [2014 高速摄影／DPIV 后续论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4203578/)；水族馆及学术物种资料辅助形态。水族馆页面的 A. labiata 与研究中的 A. aurita 不同，文章明确区分。不转载外部照片或视频。

蓝绿色水中呈现透光、受光的实体：双层伞壁、四个马蹄生殖腺、径向管、中央四条褶皱口腕、短而细的伞缘触手。涡环承担因果标识，不用泛粒子冒充流体求解，不堆无关百科。

## 模型与边界

空腔是半椭球，初始 R=0.02 m、H=0.009 m。余弦收缩量共同驱动两尺寸、体积与解析通量；三维内伞面就是该空腔，外伞面向外增加 0.0005 m 的组织厚度。幅度归零时尺寸冻结，一个周期出入体积守恒。

动力未用实验标定：开口 A=πR²，主动推力采用 ρQ出²/A 的整体通量近似，二次阻力系数 0.8，有效质量取休息排水质量的 1.8 倍。忽略真实扁平伞周围的空间压力、卷吸、流固耦合。流出水动能通量近似的 35% 成为可回收预算，在完全舒张阶段平滑支取。回收机械功不超过已支取能量，支取加剩余不超过累计预算。35% 是教学选择，不能冒称论文测量比例或实际效率。

涡环位置与转向随同一脉动阶段变化，仅示意本周期，不求解 Navier–Stokes、压力或历史尾流。零幅度不产生涡或推力。柔性附件的偏移来自同一通量／速度状态，没有独立飘动时钟。虚拟比较仅移除回收项，保留同一几何、初始条件与主动力／阻力规律。

## 170 秒计划分镜

0 秒整只水母的脉动与形态；24 秒收缩排水和模型体积；48 秒起始涡进入尾流；70 秒弹性回弹及反向停止涡重新定位；96 秒伞静止而二次推力仍在；122 秒相同动作、带／不带回收项的虚拟距离和速度比较；146 秒连看完整周期，保留涡环以匹配最后旁白的观察对象。双语录音实际窗口必须由集成人重新测量。

观看使用 Showcase 统一时钟，章节相对进度选择物理时刻。参数改变时重建固定步长确定性轨迹，跳转直接查帧，没有私有动画计时器。共享 Studio 负责渲染、离屏／后台暂停、静止跳转就位、减少动态、运行期失败 fallback 和资源释放。镜头过渡只使用 Studio 渲染增量，不推进物理模型。

手机重新用 326 px 水窗（320 px 宽时 310 px）、完整运动包络与几何外的 CSS 字号图例构图。比较改成两轨迹与曲线，不叠整块桌面舞台。二维轮廓、口腕和触手读取同一几何，最低的当前周期起始涡仍在画面内。正文与图示解释至少 16 px，控件至少 44 px；学名 kicker 是装饰层级。

## 作者自审与交接

关键停帧：第 1 章 0.5 有出通量；第 3 章 0.6 停止涡移至伞下；第 4 章 0.5 体积变化率为零且回收力为正；第 5 章 1.0 比较默认四周期。末章保留涡环以承接旁白。封面选择已舒张但回收仍为正的一帧，涡环位置来自模型，仅在实际正回收力时显示力箭头。

回归检查解析体积导数、出入守恒、零幅度无免费动作／涡、能量预算、步长收敛、回跳、幅度／周期边界、非退化周期网格及附属器官连接。渲染器测试遍历姿态和剖面、检查缓冲有限、完整伞面恢复及镜头距离不漂移。表现测试直接跳到完全舒张章节，真实把幅度设零，并检查比较几何没有 NaN／Infinity。

这些都是作者自审，不能证明浏览器材质效果、独立科学复核、完整观看、生成配音、原生试听或真机性能。集成人仍需分别检查桌面／390／320 px 双语完整播放器、涡与身体边界、剖面转换、启动能力拒绝与运行时 WebGL 失败、catalog／social 封面和双语整段声音。场景作者未改发布或共享声音清单，正式整合后移除临时 packet。
