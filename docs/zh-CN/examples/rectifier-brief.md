## 视觉论证

先跟住两只导通二极管，再发现储能电容改变的是它们**何时导通**。深蓝色画面中，正半周用琥珀色，负半周用蓝色，负载用浅绿色，电容用紫色。四只二极管方向、两个交流端、有限源电阻、并联电容与负载、正负输出回线始终完整可见，没有用断开的箭头或装饰粒子代替电流。

桥采用展开的矩形布局：D1 为 A→P，D2 为 B→P，D3 为 N→A，D4 为 N→B，因此四只二极管在各自竖直支路中都指向上方。交流源和源电阻连接中间的 A、B，负载与电容连接 P、N。正半周 D1/D4 接通，负半周 D2/D3 接通，回路均经过源闭合。负载始终从 P 流向 N。截止区间四只二极管都暗下去，电容仍通过负载形成供电路径。

SVG 是主渲染和完整二维表达，不依赖装饰性外壳。二极管亮度来自各自电流，电容箭头来自净电流方向，紫色填充来自 `vC/Vpeak`。填充表示电压，不是液体或独立动画。

## 冻结分镜

临时 packet 含分别撰写的中英文讲稿、字幕和标题。八章，每章初拟 22 秒，总计 **176 秒**。所有声音文本、字幕、标题、章数、顺序和时长均已**冻结**。

| 时间       | 计算状态                                | 因果观察                               |
| ---------- | --------------------------------------- | -------------------------------------- |
| 0–22 秒    | 不接电容的正半周                        | D1/D4 闭合回路，负载电流向下           |
| 22–44 秒   | 不接电容的负半周                        | 换为 D2/D3，负载方向不变               |
| 44–66 秒   | 完整交流周期                            | 每周期两个输出脉冲，但过零附近仍下落   |
| 66–88 秒   | 空电容启动，三个真实交流周期            | 超过门槛才开始导通，电荷连续增加       |
| 88–110 秒  | 一个含电容的计算稳态周期                | 源幅值跨越 vC+2VF，充电窗口与放电交替  |
| 110–132 秒 | 220 µF 与 2200 µF 稳态比较              | 同一电压刻度下，纹波缩小               |
| 132–154 秒 | R 从 200 降至 50 Ω，再从 50 改为 100 Hz | 更大需求增加纹波，更短补充间隔减小纹波 |
| 154–176 秒 | 峰值接入空电容，Rs 为 0.5 与 5 Ω        | 源电阻限制浪涌，也使充电变慢           |

频率比较始终保留 **20 ms** 横轴窗口，因此 100 Hz 输入能直接看见更多脉冲。最后一章显示峰值接入后的前 10 ms，使用同一个 18 A 电流范围。启动和浪涌镜头用确定性的二次时间映射，让初次充电停留更久，不独立缓动任何物理参数。稳态比较明确不是更换器件的真实暂态。

## 声明的独立模型

SI 状态为 `vC`；`vs=Vp sin(2πft+φ)`，`iB=max(0,(|vs|−2VF−vC)/(Rs+2rD))`，`iR=vC/R`，`C dvC/dt=iB−iR`。桥导通和电容净充电并不等同；只有 `iB>iR` 才增加电荷。移除电容后没有储能状态，采用分母 `Rs+2rD+R` 的代数解。

默认源为 **12 V 峰值**、50 Hz，电容 1000 µF、负载 100 Ω、源电阻 2 Ω，每只二极管压降 0.65 V、动态电阻 0.08 Ω。探索范围：1–18 V 峰值、25–100 Hz、100–2200 µF、50–300 Ω、源电阻 0.5–8 Ω。最低电压低于两只二极管门槛，会正确得到零稳态输出。

导通区间使用正弦驱动一阶方程的解析解，截止区间使用 RC 指数解。四分之一周期划分固定驱动正弦的符号，42 次二分定位二极管事件。记录步长不超过 T/512，导通时进一步限制为充电时间常数的 1/16。电荷和功率以同一解析状态做 Simpson 积分。标量耗散周期映射经包围法求不动点，没有强制峰值保持或用纹波近似画图。

能量账为源输入等于负载、两只二极管热耗、源电阻热耗与电容储能变化之和；电荷账为桥输入电荷减负载电荷等于 CΔvC。交流源电流符号随电压变化，桥输出和各二极管正向电流均非负。

默认平均输出约 9.54 V，纹波 0.70 V，导通比例约 28%。峰值接入时，0.5 Ω 源电阻得到 16.21 A 初始电流，5 Ω 得到 2.07 A。这些是教学模型数值，不是实测或器件额定值。模型不含电容 ESR、源/变压器电感、反向恢复/结电容、保护、反馈调压和温度效应；也不是市电搭建指南。

## 手机与交互

桌面和手机使用不同电路坐标，逻辑宽度分别为 750 和 300。手机保留两组完整桥臂，器件标签为 22 单位，移除重复标题和细节。当前解释紧挨电路；下方只放本章相关波形，浪涌章节改为电流。波形 SVG 本身没有缩小字体，图例和刻度使用 16 CSS px 文本。舞台最小高 790 px，320 px 时以 ≤900 px 为构图目标；本工作任务尚未浏览器测量这个目标。

六个范围输入都有唯一 id、显式关联标签、翻译 aria-label 和至少 44 px 高度。按钮至少 44 px，并提供选中/禁用状态。经模型测试的重置工厂恢复所有数值参数、电容连接、源相位、启动、观察项与时间。移除电容会禁用相关启动操作；选择峰值接入会实际进入空电容启动。

时间只来自 `useShowcase` 或手动取样。场景不创建定时器、RAF、Worker、音频对象、Canvas 或 Three.js 资源。离屏、后台、减少动态效果由共享播放器处理，窄屏 hook 在卸载时移除监听。缓存仅含有限固定分镜配置，不包含播放历史。
