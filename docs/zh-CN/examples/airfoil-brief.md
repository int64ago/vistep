# 机翼升力：空气没有约定在翼尾重逢

## 制作意图与镜头

深蓝观察窗中的一枚银灰色对称翼型，青色与赭色区分压力和示踪点。对象承担主要解释，不用通用侧栏仪表板。观察窗只是构图，不作为风洞实体壁参与求解。主媒介为 SVG，同时天然支持无 WebGL 环境；没有外部图片或生成素材。

以两个同时出发的空气示踪点为主问题，把计算速度、表面压力和整圈合力串在一起。先由边界条件确定速度场，再用伯努利关系换算压力。没有用翼面长度拟合速度，也没有设定等时到达。

自动演示共 176 秒，八章各 22 秒，画面静音可读，中英文口播分别创作。

| 时间       | 镜头         | 新的可见因果                                                 |
| ---------- | ------------ | ------------------------------------------------------------ |
| 0–22 秒    | 对称起点     | 零攻角的真实流线示踪与压力镜像相抵，升力为零。               |
| 22–44 秒   | 改变攻角     | 从 0° 到 +6°，各稳态的速度箭头、压力与升力一起变化。         |
| 44–66 秒   | 尾缘近景     | 两侧探针靠近尖点，速度趋向共同的有限解析极限。               |
| 66–88 秒   | 一圈表面载荷 | 逐段加入压力贡献，累计水平与竖直分量；完整一圈才是总合力。   |
| 88–110 秒  | 同时释放     | 两个相邻起点按实际速度场积分，共用时间但先后通过翼尾测量线。 |
| 110–132 秒 | 环量路径     | 沿外部数学闭合路径测切向速度，独立核对压力积分的升力。       |
| 132–154 秒 | 升力反向     | 从 +6° 经零到 −6°，压力镜像、升力反向。                      |
| 154–176 秒 | 风速平方关系 | 固定 +6°，15 到 30 m/s，Cp 不变、环量两倍、升力四倍。        |

攻角和风速变化是独立稳态族，不模拟转动或加速。逐段揭示载荷是积分讲解，不是力随时间建立。环量金点是计量位置，不是空气绕圈。真实空气示踪按物理时间取样，画面明确放慢，退出后不回绕。

## 科学模型与边界

Joukowski 映射 `z = ζ + a²/ζ`；辅助圆心 `−εa`，半径 `R = (1+ε)a`，经过 ζ = a。固定 ε = 0.1、弦长 1 m。平移与旋转后，实验室来流水平。翼型、法向、压力测点和速度均由同一映射生成，逆映射只取外部分支。

复势导数含均匀流、偶极子和环量项，再除以映射导数求真实平面速度。Kutta 条件给出 `Γ = −4πRU∞ sin α`，逆时针计正。表面不穿透、远处来流及环量积分分别验证。精确尖尾缘、内部实体与映射极点不直接求速度。尖点使用独立解析极限 `U∞ cos α/(1+ε)` 检查；求逆前先检查物理尖点，防止平方根把浮点误差放大。

`Cp = 1 − (v/U∞)²`；`p = p∞ + ½ρU∞²Cp`。512 个单元作周期中点积分，计算 `F′ = −∮(p−p∞)n ds`，另在外部闭合曲线上独立积分 Γ，以 `L′ = −ρU∞Γ` 核对。减去均匀环境压力不改变闭合表面的总合力。向外的蓝色增量表示向内压力减少，不表示负绝对压强的吸引力。

作者参数：空气密度 1.225 kg/m³、环境绝对压强 101325 Pa、默认 +6°、25 m/s；N/m 是每单位翼展的力。手动范围为 −8° 到 +8°、10–35 m/s、物理时间 0–180 ms 与表面测点。模型拒绝零/反向来流、非有限输入、超出教学域、退化几何和精确尖点速度。这些范围不是失速边界。

模型不含边界层、分离、失速、黏性阻力、有限翼展诱导阻力、可压缩效应或起动环量过程。二维理想压力阻力为零，不意味着真实机翼没有阻力。Kutta 条件直接施加，未模拟真实流动建立环量的机制。

示踪采用四阶 Runge–Kutta，物理步长按弦长/来流缩放，遇排除几何可减半步长。不可变轨迹最多缓存八组，任意时间用二分查找取样。两个种子位于 x = −0.85 弦长，在上游分界流线两侧各偏移 0.035 弦长，同时释放；测量线垂直来流并经过实际尾缘。默认到达时间为 49.6967 与 59.8559 ms，只属于本例种子。

默认升力 274.276819812645 N/m，CL = 0.716478223184，与环量公式一致。较困难的测试组合（8°、ε = 0.08）使用 64、128、256 单元时，升力误差分别约 0.00467、1.63e−7、4.55e−13 N/m。这是实现的数值收敛证据，不验证域外实际空气动力学。

## 手机、交互与生命周期

桌面观察窗高 440px，手机独立坐标窗高 320px；压力、成对示踪和环量章节采用不同视域，始终保持几何等比例。尾缘章节使用独立近景和小型全翼定位图。每章只保留当前两项读数，没有图表堆叠。手机主解释 18px、SVG 标签 16px、正文至少 16px。所有范围通过共享 Range 的显式、翻译后 aria-label 命名，作用区至少 44px，按钮不小于 44px。

键盘方向键修改物理参数、时间或测点。完整重置恢复 +6°、25 m/s、0 ms、测点 0.25、表面载荷视图。所有自动画面由 useShowcase 的章与进度确定；没有独立动画时钟、随机状态或逐帧历史。共享播放器负责离屏、后台和减少动态效果；本地过渡也尊重减少动态效果。卸载时断开 ResizeObserver 并清除轨迹缓存，没有 Three.js、Worker 或音频资源。

颜色在 Cp ≤ −2.5 与 +1 饱和以提高辨识，数值不截断。压力载荷与速度箭头采用独立显示比例。合力箭头放在手机翼型包围框之外，负升力不会穿过翼型。SVG 不依赖外部图像与 WebGL。
