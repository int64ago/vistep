## 因果主线

跟住一个有地址的字节，经过只读缓存。关键转折是其他组仍有空位时发生冲突未命中；随后在相同数据容量、地址序列和冷启动条件下，只改变相联度。

## 画面与章节

地址地图与缓存行保留块身份、标签、有效位和返回值。八章依次展示整行复制、地址拆分、空间局部性、时间局部性、冲突、相联度、LRU 替换和行大小比较。手机保留相关地址窗口，不把全部 64 字节缩成小字。

## 模型与边界

独立模型使用不可变的 64 字节主内存、精确的组号/标签/偏移计算及确定性 LRU。数据容量不计元数据。未命中复制完整对齐行，替换只移除缓存副本。独立队列参考实现检查 240 组访问序列。动画拆解一次原子读取，不代表处理器周期或延迟；不模拟写入、一致性、预取与多级缓存。
