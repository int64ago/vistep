# CPU 指令流水线：指令工坊

[English](../../examples/cpu-pipeline-brief.md)

## 选题与视觉论证

一条指令仍要五拍，为什么整份程序可以更早完成？沿着同一组指令编号观察纸面工坊和时序记录，关注真实操作数与结果，不用处理器外壳充当解释。

开篇单独跟随 I1。转折在第 5 拍：I3 从两处流水线锁存值取得四与七，算出十一，此时 r3 尚未写回。随后近看加载依赖，区分“已经算出”与“数据尚未读到”。结尾对同一程序重新执行两种安排，检查全部寄存器、内存与有效指令顺序。

桌面构图采用五个横向工位、保留身份的彩色指令条、真实前递弧线和当前章节的时序行。手机采用五个纵向工位、完整字号的标签、文字前递记录和四拍时序窗口，重新排布坐标。探索模式开放完整桌面时序账本、逐拍推进、初始内存输入与前递开关。

## 八章独立短片

计划 176 秒，八章各 22 秒。组件读取 `useShowcase().chapter` 与 `chapterProgress`，后续实测配音可以调整章节时长，不必重写模型。中英文脚本分别创作，均位于集成 packet。

| 章节         | 画面对应模型状态                   | 新的因果观察                                         |
| ------------ | ---------------------------------- | ---------------------------------------------------- |
| 1 · 一条指令 | 逐条参考第 1–5 拍                  | I1 编号沿五级移动；加法经过访存位置但不访问内存。    |
| 2 · 重叠     | 流水线第 1–6 拍                    | 老指令离开工位，年轻指令马上利用空位。               |
| 3 · 吞吐量   | 同一经过拍数 0–40，两种执行安排    | 完成编号更密集；I1 的延迟仍为五拍。                  |
| 4 · 值未写回 | 关闭前递，第 3–8 拍                | I3 保持在译码；老指令继续推进，不读取错误旧值。      |
| 5 · 数据前递 | 开启前递，第 3–7 拍，停留第 5 拍   | 从 WB 取得四，从 EX/MEM 取得七；r3 尚未更新。        |
| 6 · 加载依赖 | 第 5–9 拍，近看第 7、8 拍          | IF、ID 保持，EX 气泡；下一拍才把加载的十一送入执行。 |
| 7 · 分支成立 | 第 8–12 拍，停留第 9 拍            | I7、I8 撤销；I9 重新取指，M[4] 保持零。              |
| 8 · 结果核对 | 两种安排重新运行至完成，再拆解拍数 | 同样八条有效指令、相同结果，15 拍对比 40 拍。        |

每一章都包含其之前的完整架构状态，直接跳转不只改变字幕。主题没有独立定时器、音频实例、网络请求、观察器、渲染器或 Worker。离屏、后台、减少动态效果和配音权限沿用共享播放器；CSS 移动只在其 `playing` 状态为真时启用，暂停跳转直接落到目标状态。

## 独立模型约定

实现 ADDI、ADD、SUB、LW、SW、BEQ；八个 32 位寄存器，按有符号整数显示，r0 固定为零。算术保留低 32 位。数据内存按字节寻址，只允许四字节对齐的整字，未写入位置读零。程序预先解码，分支目标用指令索引表示。这是教学用 RISC-V 风格子集，不是二进制兼容模拟器。

快照保存本拍各级中的指令以及本拍结束后的数值。WB 写入先于 ID 读取。前递优先选择 EX/MEM 中较新的值，其次选择 MEM/WB，排除 r0。紧邻加载使用停顿一拍；关闭前递则等待写回。存储数据与分支输入也遵循依赖规则。分支在 EX 决定，成立后撤销 IF、ID 中的年轻指令，阻止任何副作用。存储在 MEM 更新内存，存储和分支也经过 WB 完成。

逐条参考采用相同的五个等长工位，不允许重叠。另有不复用流水线执行逻辑的独立解释器验证架构结果。没有把教学时钟当成真实频率，也没有模拟缓存缺失、异常、多发射、乱序执行和真实电路时延。

2026-09-05 核对的一手资料：

- [Harris 与 Harris 微架构课件](https://pages.hmc.edu/harris/class/e85/old/fall21/lect22.pdf)，尤其第 53–56 张：加载依赖互锁、EX 判断分支与清除两条年轻指令。
- [Brown CSCI1952y 五级流水线课程](https://cs.brown.edu/courses/csci1952y/2024/notes/pipelined_cpu.html)：锁存器前递、最新值优先、寄存器同拍读写及加载停顿。该课程的分支在更晚一级判断，清除三条；本模型没有套用其数量。
- [RISC-V International RV32I 规范](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html)：加减、加载存储和条件分支语义。更小的寄存器文件与简化目标表示均已明示。
