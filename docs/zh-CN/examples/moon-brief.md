# 月相 — 制作分镜

[English](../../examples/moon-brief.md)

属于[新增 50 篇](../expansion-50.md)。从一轮安静的大月亮开始，由月牙变为凸月，再退到太空中看产生这种外观的几何关系。地面月面与轨道视图共享同一个太阳方向，弯曲明暗边界必须来自球面受光，不能用移动圆片遮住图片冒充。

采用观测台的视觉：深蓝黑、温暖阳光、有细节的哑光月面和克制的小地球。大幅月面承担主要信息；空间视图说明角度，明确标注天体大小与距离分别缩放，并保留从地球看到的月面。手机在月面与轨道构图间切换重点，不挤入两块桌面面板。月面采用 NASA SVS 的 LROC 色彩图与 LOLA 高度图，保留署名。色彩图经过适合视觉渲染的处理，不用于地表科学测量。地球采用自主示意图，不能把 8 位凹凸纹理称为按实测高程精确缩放的地形。

八章分别为变化的月面、单侧照亮球体、观察角度、主要月相、满月与地球阴影、同步自转、恒星月与朔望月，以及完整重建。月食段调整轨道平面来做受控几何对比，不把它描述成一个月内真实发生的轨道变化。两种月份对比明确采用共面圆轨道。

独立模型采用惯性黄道坐标中的圆轨道、平行太阳光、固定轨道极与平均周期。计算朝向地球的月面坐标基、照明、同步转动的表面坐标及本影／半影锥。地面和太空渲染器必须使用相同向量。5.145° 轨道倾角通常使满月避开地影，独立的交点例子使月球进入本影。阴影覆盖按正投影面积计算，不模拟大气颜色，不提供月食时刻表。不能把背面等同于永远黑暗。天平动、轨道偏心、地平线朝向、地照和真实日期预测暂不实现。

资料：[NASA 月相](https://science.nasa.gov/moon/moon-phases/)、[NASA 月球问答](https://science.nasa.gov/moon/top-moon-questions/)、[NASA 食的几何关系](https://science.nasa.gov/eclipses/geometry/)、[NASA 公转周期](https://starchild.gsfc.nasa.gov/docs/StarChild/questions/question32.html)。

物理参考量见 [JPL 天体参数](https://ssd.jpl.nasa.gov/astro_par.html)、[JPL 卫星半径](https://ssd.jpl.nasa.gov/sats/phys_par/)及 [IAU 名义太阳常数](https://www.iau.org/common/Uploaded%20files/IAUGA2015-Resolution-B3-recommended-nominal-conversion.pdf)。月面纹理来自 [NASA SVS CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/)，保留原始 JPEG，不重新压缩。

专题已接入 177 秒双语演示、正文、封面、按需导入及录音。六项模型测试覆盖主要月相、日照面积数值核对、锁定表面坐标、阴影命中与避开、恒星月和朔望月，以及降级多边形、阴影遮罩与面积读数的一致性。月面使用固定表面坐标的球面着色器和独立几何阴影；8 位高度图只改变轻微的局部材质明暗。

已查看桌面关键帧及 320 px 下全部八章的布局。手机轨道、影锥与月长图采用独立坐标和标签位置，不将桌面图整体缩小。读数因小数像素宽度换行的问题已用明确网格列修正；已操作手动范围端点、重置及二维模式。全部 16 个章节／语言组合通过独立 ASR，最低相似度 0.8743；这不等同于试听。完整连续播放、全部失败及无障碍情形、真机性能仍待完成。发布证据见扩展记录。
