# 二进制加法 — 制作分镜

[English](../../examples/adder-brief.md)

属于[新增 50 篇](../expansion-50.md)。从熟悉的竖式开始：`1 + 1 = 10₂`。追踪多出来的进位，先进入有明确接线的逻辑门，再沿着一个八位数向高位传播。

采用温暖的计算纸面、严格对齐的位权和铜色进位线。半加器与全加器使用可辨认的门符号、引脚和连接点；交叉但没有圆点的导线不相连。手机另排纵向线路，不缩小桌面图。数字输入和信号进度只在自由探索中显示。

八章分别讲二进制位权、半加器真值、上一级进位、四位相加、`255 + 1` 的长进位、第九位输出、有符号与无符号溢出，以及最后的 `42 + 19`。播放时钟揭示真实计算的中间信号，不能只改变标签的高亮。

模型用 XOR／AND／OR 构建全加器，连接逐位进位。信号就绪采用“最早可以保证判定”的教学模型：输入开始时已知，XOR 等待两个输入，AND／OR 可以由控制值提前确定。相对延迟取 XOR=2、AND／OR=1，未知值不显示为零。这不是晶体管瞬态、毛刺或实测纳秒仿真。有符号溢出与最高位进位要分开表示。

资料：[MIT 6.004 设计权衡](https://ocw.mit.edu/courses/6-004-computation-structures-spring-2017/pages/c8/c8s1/)、[Computation Structures 加法器实验](https://computationstructures.org/exercises/adder/lab.html)、[Nand2Tetris 布尔算术](https://www.nand2tetris.org/project02)。专题已接入 178.0 秒自动演示及中英文录音。五项数值测试覆盖全部 65,536 组八位输入、信号就绪边界和有符号溢出。桌面与 320 px 审看检查了竖式对齐、手机纵向接线、未知输出、键盘极值及稳定的章节高度。全部 16 个章节／语言组合通过独立 ASR，最低相似度为 0.8143；这不代表已验证声音自然程度或完整试听。连续观看、更多容错检查及真机性能仍待完成。
