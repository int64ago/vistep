# 虹吸：连续水柱与整体落差

[English](../../examples/siphon-brief.md)

## 选题与表达

水为什么能先越过高处，再流向低处？跟住透明弯管里的一份水，然后逐项撤掉让它持续流动的条件。转折是顶部进气：低出口仍在，持续流动却停止。最后把大气压在能量平衡中的角色，与它对液柱连续性的约束分开观察。

画面采用安静的实验室剖视：透明浅槽、淡绿色水柱、黄铜色进气口与克制的压力标注。这是有纵深线索的混合剖面表达，不依赖 WebGL。管壁闭合轮廓、水段、压力采样和示踪位置来自同一条按弧长参数化的中心线。两端管口有意开放；虹吸不是闭合循环，不凭空增加回水管。

水源浅槽足够宽，刚性管绕浸没入口转动时不穿过槽壁，接水容器随出口横移。高管比较使用不同长度的直立管腿，每组分别预充，并把新管内容积纳入同一总水量。画面不拉伸软管，也不让调参凭空产生水。

## 176 秒的八个因果章节

| 时间       | 画面变化                                         | 解释任务                                           |
| ---------- | ------------------------------------------------ | -------------------------------------------------- |
| 0–22 秒    | 入口段进水，但顶部保留空气；观察环定位断处。     | 低出口本身不能给普通空管完成预充。                 |
| 22–44 秒   | 连接手动预充器，水前沿推进，充满后移开预充器。   | 最初预充需要外部做功，之后由落差维持。             |
| 44–66 秒   | 金色标记越过顶部并离开；两槽水位与库存相应变化。 | 上升段属于整体下行路径，水量守恒。                 |
| 66–88 秒   | 顶部压力标记与沿管压力曲线伴随排水。             | 位置、速度和损失来自同一能量关系。                 |
| 88–110 秒  | 定长刚性弯管转动，出口接近液面，示踪停止。       | 自由出口水头归零，不需要改变管长。                 |
| 110–132 秒 | 出口放低后恢复流动，再打开进气口，两侧水段退开。 | 落差仍在也可能断流；退水分别计入两侧容器。         |
| 132–154 秒 | 逐组比较预充好的高管，顶部压力余量缩小。         | 普通水的单相液柱模型受到蒸气压边界约束。           |
| 154–176 秒 | 固定 8.5 m 高管，降低环境压力；失效前流量不变。  | 两端相同大气压不增加驱动水头，却改变绝对压力条件。 |

中英文口播分别创作在集成包中，每章规划 22 秒、口播延后 0.45 秒进入。父任务负责生成并实测两种声音、调整共同窗口、完整试听。此交接没有音频生成或试听证据。数值演示依赖章节进度，配音窗口变动不破坏跳转重建。

## 独立模型与明确边界

- 统一 SI 单位；自由出口、等截面、准稳态一维伯努利加损失。内径 12 mm，达西系数 0.03，入口损失 0.5，弯管损失 0.4，均为作者设定。忽略水面速度、启动惯性、水锤、雷诺数相关摩阻和两相动力学。
- 水密度 998.2 kg/m³，重力加速度 9.80665 m/s²。水温只改变 NIST 饱和蒸气压拟合，界面范围 5–29 °C，不声称同时重算黏度和密度。
- 水源面积 0.06 m²、接水容器面积 0.12 m²、总水量 0.063 m³。水源槽宽 1.25 m、深 0.048 m；接水槽宽 0.65 m、深约 0.185 m。视觉纵深压缩。接水槽底 −0.5 m，槽口固定在 0.12 m，低于默认 0.2 m 的管口。
- 直线、半圆弧、直线组成解析连续路径；口径在画面中放大。示踪运动为真实模型速度的 22%，金色标记离开出口后消失，不跳回上游循环。
- 前六章使用 0.1 秒固定步长缓存，跳转重建水量与湿润管段。手动时间从每次设定的起点重算。
- 预充和进气排空采用指定教学进度；每段排出的水仍逐项守恒。空管第一章为静态液面平衡，手动进气按钮从重新准备的排空平衡态开始对照。
- 顶部达到饱和蒸气压是普通含气水的教学停止条件，不预测真实失效位置、时间或气泡体积，也不作特殊脱气液体的一般性结论。金色气泡是失效符号；液体库存仍保留。失效后的压力为假设连续液柱所要求的值，流量输出停止。

## 手机、生命周期与后备表达

`ResizeObserver` 用容器实测宽度设置 SVG 像素坐标系。窄屏重新安排横向间距、注释锚点与构图，SVG 字号保持 16 px，不缩小桌面 viewBox。300 px 画面中的宽槽容纳转动管段，接水标注向右边缘对齐。长文字使用 HTML 自然换行；主要按钮与滑块至少 44 px。

共用 `useShowcase` 管理播放、离屏和后台暂停、减少动态效果、重播、章节、跳转与配音。本组件没有独立动画计时器、网络媒体或 Worker，卸载时断开尺寸观察器。线稿按钮用同一模型简化纵深表现；无 WebGL、无纹理、无声音时，解释仍完整可见。
