## 核心现象与画面

问题是：电能怎样越过绝缘玻璃，先在锅底变成热？

跟随两个互不接触的闭合电路。铜色平面螺旋位于玻璃下方，蓝色等效涡流位于锅底内部。线圈内端从下方跨过其余匝，再经过电源、回线接回外端；电源内部支路闭合。锅的前半部透明剖开是观察方式，不是把导体真的切断。材质采用克制的铜、灰钢和青绿色玻璃；没有火焰、发光金属或虚构的热粒子。

注意力从连接关系，移到磁通的变化率，再移到损耗深度，最后进入缓慢的热储存。末两章用锅与玻璃的热节点取代三维组件，避免手机把结构、图表和控件一直叠成长页面。

## 已冻结的 176 秒短片

共八章，每章 22 秒，起点为 0、22、44、66、88、110、132、154 秒。每章语音起点比章起点晚 0.45 秒。数据包中的标题、字幕、中英文独立口播、章节数量与时序已冻结，交由父任务生成录音；本任务不生成任何声音文件。

| 时间       | 画面变化                                                               | 新的因果观察                                               |
| ---------- | ---------------------------------------------------------------------- | ---------------------------------------------------------- |
| 0–22 秒    | 完整线圈与独立锅底环随着规定电流增加而显现。                           | 两个回路各自闭合；这里比较交流稳态，不是假装求解通电瞬态。 |
| 22–44 秒   | 一个慢放的载波周期中，电流箭头和磁通方向反转，下方显示三个有符号读数。 | 感应电动势跟随磁通变化率；电流还受阻抗决定。               |
| 44–66 秒   | 频率从 15 升到 60 kHz，锅底标记点下的损耗深度曲线收窄。                | 集肤深度与电损耗来自电路所用的同一个有限厚平板解。         |
| 66–88 秒   | 保持电流不变，同一口锅最多抬高 15 mm。                                 | 几何积分得到更小互感，传入锅底的实功率下降。               |
| 88–110 秒  | 相同几何与电源条件下，依次切换钢、非磁性不锈钢、铝。                   | 导电率、磁导率影响负载；非磁性不代表绝对无法感应加热。     |
| 110–132 秒 | 展开 24 秒物理时间，展示四秒周期、35% 通电比例。                       | 开启时保持原有功率，关断段电输入为零，时间平均功率降低。   |
| 132–154 秒 | 180 秒连续加热过程被加速呈现。                                         | 锅先升温，玻璃经接触传热后变暖。                           |
| 154–176 秒 | 电输入归零，继续观察 240 秒冷却。                                      | 总储热下降，但玻璃起初仍可能升温。                         |

所有输入、相位、锅的位置、叠加色、读数与热状态都由 `inductionShot(chapter, progress)` 直接重建。共用播放器负责播放、暂停、重播、章节与拖动；没有私有累积时钟或随机历史。

## 模型、单位与界限

内部使用 SI 单位。主线圈为十二匝阿基米德螺旋，半径 25–105 mm，导线半径 1.8 mm；经过圆滑处理的下穿接线中心线同时用于三维管道和 Neumann 积分。锅底厚 3 mm，等效环半径 75 mm、有效宽度 40 mm。实际锅底连续导电，透明前半部仅为剖视。

主线圈电阻 0.04 Ω、电感 30 µH；次级外部电感 0.28 µH。互感来自完整闭合路径的空气中几何积分，默认约 1.5184 µH，没有用任意距离倍率代替。这里把分布场缩减为一个短路环，**不求铁磁材料对空间磁场的集中**；磁性仅进入线性表面阻抗。因此材料比较不能当作某台商用电磁炉的性能预测。

单侧激励、背面磁场为零的有限厚导电平板使用 γ = (1 + j)/δ、Zs = (γ/σ)coth(γt)、δ = 1/√(πfμσ)。小参数级数与厚导体极限保证稳定。等效电阻、内部电抗和沿深度的焦耳损耗使用同一个解；对有效面积与厚度积分，回到电路锅底功率。曲线是周期平均电损耗，不是光亮度或已求出的空间温度分布。

有效值相量满足 I₂ = −jωMI₁/Z₂，U₁ = (R₁ + jωL₁)I₁ + jωMI₂。电源实功率等于线圈与锅底电损耗之和。固定频率、开启段内还验证包含两项自感储能和 M i₁i₂ 互能的瞬时能量平衡。磁通正方向来自显式参数化的环方向。逆变、谐振补偿、锅具检测、电源调节和硬件实现均省略。

材料用固定教学值：钢 σ = 6×10⁶ S/m、μr = 40；非磁性不锈钢 σ = 1.4×10⁶ S/m、μr = 1；铝 σ = 3.5×10⁷ S/m、μr = 1。忽略磁滞、饱和以及温度引起的参数变化。场景讲的是金属中的电阻损耗，不冒充完整家电的实测损耗分解。专门设计的设备可以加热非磁性锅，兼容性仍取决于具体设计与制造商规格。

默认 25 kHz、28 A 有效值时，锅底约 144.10 W，线圈约 31.36 W；相同电源下另外两种材料分别约 65.85 W 和 14.02 W。电源没有为不同负载重新匹配。这些是教学参数，不是烹饪设置。

热模型从 20 °C 开始，把金属锅与玻璃各视作一个均温节点。锅的热容来自底板和侧壁质量，玻璃热容取 500 J/K。接触热导随抬升减弱并保留少量残余耦合，两节点分别向环境散热。每个恒功率段通过二维矩阵指数精确推进，通断边界逐段重建。锅底电损耗进入此热域，线圈损耗在域外。没有食物、沸腾、空间对流场、局部玻璃温度或随温度变化的辐射求解。四秒通断包络忽略极短开关瞬态及其少量电磁储能。

## 分别构图与交互

桌面采用柔光三分之四剖面。手机使用更正面的镜头、按本地宽度布置的 SVG 和当前章节最相关的证据。热过程章移除三维结构，主观看区一般为 796 px；在 320 px 英文视口，较长的集肤与通断章低于 823 px。调参只在探索模式出现；共用播放条不属于本任务可修改范围。

镜头拟合不是只看名义宽高：模型列出底座、电源和玻璃的实际角点、抬升锅沿以及磁通标记边界，经过真实透视基底投影并保留余量。观看态直接重建镜头。探索态采用包围球距离，防止旋转露出被裁切的近角；视口、抬升、观察内容或模式变化时重新拟合，其余时间允许自由转动。二维后备使用独立的双方向投影拟合，保留原生 16 px 标签，并为 44 px 模式按钮留出空间。

六个滑块均有明确译文名称：有效值电流、频率、额外抬升、通电比例、周期相位和热过程时间。材料、视图按钮有选中状态。完整复位恢复六项输入、材料、视图、镜头和二维模式。原生滑块键盘操作、焦点轮廓、方向键转镜头与二维入口均可用。共用 Studio 管理减少动态效果、离屏与后台暂停、WebGL 失败以及资源释放；本组件新增的 ResizeObserver 在卸载时断开。没有新增音频、Worker、网络素材或独立运行的计时器。

## 证据与未覆盖内容

- **模型：** 15 项专题 Vitest 测试，包括闭合路径、实际镜头边界、独立互感积分加密收敛、直流与强集肤极限、有效值及瞬时互易功率、独立差分法拉第符号、4,000 点深度损耗积分、零值与二次幂极限、热守恒、独立 18,000 步 RK4 及环境散热积分、冷却、占空比与分段重建、有界输入、168 个倒序拖动状态。
- **编译与内容：** 专题严格 TypeScript 检查；中英文 MDX 经仓库版本 Astro 7.3.1 / MDX 8 的实际转换与预渲染后处理；封面经实际 Astro 编译和容器渲染，默认色及自定义色均通过，并检查 Resvg 生成的 400×230 图。正文仅用原生公式块与 Unicode，没有原始 TeX。
- **数据包：** 精确顶层契约、176 秒八章、元数据、界面文字与既有译文保留均检查。临时包供父任务并入权威登记，不作为第二份长期真相。
- **浏览器：** 独立夹具拥有自行离线安装的依赖，内存替换共用 director 以定位章节；最终交互审看使用 CUA 内置浏览器。检查桌面和 320 px 图像，并通过 CUA 检查八个英文手机章的横向与 SVG 文字溢出，最大主观看区 821.969 px。这只是布局证据，不是完整观看。一次处于尺寸切换中的测量被排除；稳定集肤帧投影 28,034 个网格/线顶点，最大 |NDC x| = 0.860、|NDC y| = 0.676。桌面结构帧 20,616 个顶点，对应 0.421 和 0.860。修正后手机探索键盘转角帧对应 0.766 和 0.485。
- **交互及故障：** CUA 验证 Home 将电流和损耗归零，Right 恢复一安培，六个输入可改、材料和视图可选、复位全部恢复，手动二维模式以及模拟 WebGL 上下文丢失后可用。复位审看发现并修正了探索态手机镜头；二维审看发现并修正了几何、标签与按钮之间的空间分配。CUA 卸载检查确认活跃 ResizeObserver 数量回到零，错误日志为空。
- 更早的 shell 浏览器测量发生在后来 CUA 限制之前，不作为最终交互审看的依据；收到限制后没有再通过 shell/CDP 操作浏览器。
- **不声称：** 整合后的完整 176 秒观看、录音生成或试听、音频拖动/currentTime 验证、减少动态效果的实际运行模拟、实体手机性能、帧率、父任务注册、全量生产/预览构建或发布。夹具里没有音视频元素。共用生命周期路径已经读代码，不能据此声称设备性能通过。

父任务负责注册、语音合成与实测时长、完整双语观看试听、整合后的播放条位置、全量构建和发布。本交付不修改共用文件或此前冻结专题。
