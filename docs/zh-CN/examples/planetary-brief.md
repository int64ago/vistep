# 行星齿轮：制作分镜

[English](../../examples/planetary-brief.md)

已随[新增五十篇](../expansion-50.md)正式发布，中英文录音各 174.5 秒。下文审看记录对应制作检查点；发布不代表完整观看、试听或真机验收已经完成。

起点是一个问题：紧凑的齿轮组，为什么不更换齿轮就能改变速度甚至方向？跟住一颗有标记的行星轮、它的轴心和太阳轮上的一个齿。先区分自转与公转，再改变被固定的部件。

## 几何与来源

采用 20° 标准齿形：太阳轮 24 齿，三个行星轮各 18 齿，内齿圈 60 齿，模数相同。同心条件为 `60 = 24 + 2 × 18`；`(24 + 60) / 3` 是整数，满足等间隔装配条件，相邻行星轮齿顶也有间隙。

[KHK 齿轮机构资料](https://khkchilun.com/gearknowledge/gear_technical_reference/gear_systems.html)提供装配条件和不同固定方式；[KHK 齿轮尺寸资料](https://khkchilun.com/gearknowledge/gear_technical_reference/calculation_gear_dimensions.html)区分内齿渐开线、向内的齿顶、齿根深度和干涉条件。渲染器使用真实的内齿边界，不把外齿轮反色充当齿圈。

在行星架坐标系中，`Ns(ωs − ωc) + Nr(ωr − ωc) = 0`。太阳轮与行星轮的啮合给出行星轮自转。所有位置从绝对角度重建，跳转不继承播放历史。现有测试检查两组速度约束、装配条件、重建一致性，并在四种约束状态下采样检查完整行星轮齿廓与两侧邻轮的间隙。

## 演示方向

计划八章，每章约 20 秒；最终时长由中英文实际录音共同确定，遵守 2–5 分钟要求。

| 章节           | 画面变化                                     | 观察结果                                             |
| -------------- | -------------------------------------------- | ---------------------------------------------------- |
| 装配           | 各部件沿轴向分开，齿面与轴承装配到位后再转动 | 太阳轮、行星轮、齿圈和行星架分工不同                 |
| 自转与公转     | 固定齿圈，追踪一个行星轮和它的轴心           | 轴心在公转，行星轮还在向另一方向自转                 |
| 固定齿圈       | 跟踪输入和行星架的标记，数完整转数           | 太阳轮输入 3.5 圈，行星架输出一圈                    |
| 慢下来换来什么 | 将两侧转角与理想功联系起来                   | 降速可换得更大的输出转矩，不会创造功率               |
| 固定太阳轮     | 改变固定部件，从齿圈输入                     | 行星架以另一种减速比跟随                             |
| 固定行星架     | 锁住行星轮轴心，驱动太阳轮                   | 齿圈输出反向转动                                     |
| 连成整体       | 连接两个中心部件                             | 相对运动停止，整组一起转动                           |
| 选择约束       | 使用相同输入刻度比较三种固定方式             | 约束决定行为；仅给自由轮系一个速度不足以确定全部状态 |

主物体是一套浅开口齿轮箱，轴和行星轮销轴有真实连接。柔和的斜视全景转到正面的啮合视图；只有明确标为装配过程的镜头允许行星架轴向分离，转动时齿轮始终装配到位。手机将物体与转角对比上下排列，保持齿廓足够大。自由探索选择固定部件与输入角度，二维降级保留相同控件。

模型不模拟有限侧隙、制造误差、齿面应力、润滑、真实载荷分配或效率，齿根圆角有简化。六项数值测试只是模型证据，不代表专题或视觉验收完成。
