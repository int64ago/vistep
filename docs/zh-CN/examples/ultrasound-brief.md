# 超声成像：从一束脉冲到逐列重建

[English](../../examples/ultrasound-brief.md)

## 问题与视觉方向

声音返回的时间怎样变成深度，多条回声又怎样组成图像？本篇用一张声学实验台，把有限脉冲、已知分层体模、A 线 RF、相干包络和 B 模式扫描连接起来。

体模采用浅鼠尾草色，仪器屏幕用深青色，金色显示包络，浅青色显示返回脉冲。探头包含相连的背衬、压电元件、匹配面、耦合条和电缆；这些结构说明理想匹配接触，不模拟探头的机电转换。体模刻意采用水平平面界面，严格对应独立垂直声线的计算范围。已知体模可见的垂直侧壁不在扫描中产生虚构回声，并在说明中明确排除。没有人体解剖装饰、伪散斑或无关的三维物件。

镜头按问题切换：脉冲位置与往返时间、界面能量分流、中心对齐的正负 RF、逐列扫描、长短脉冲、衰减阴影、声速校准。一句当前解释与相关图像放在一起；静音也能理解因果关系。

## 独立模型与约定

单位使用 mm、µs、MHz、MRayl、m/s 和 dB/(cm·MHz)。体模深度范围为 0–64 mm，水平界面位于 12、40、56 mm。四层声阻抗依次为 1.5、1.9、1.6、2.3 MRayl。薄片横向范围 −15 至 −3 mm，深度 27 至 27.64 mm，阻抗 2.7 MRayl；嵌块横向范围 6 至 15 mm，深度 20 至 28 mm，阻抗 4.8 MRayl。常规章节各层声速均为 1540 m/s。这是明确指定的教学材料，不声称是人体组织的实测参数；同声速、不同阻抗对应不同密度。

每个位置只计算一条独立的垂直声线，保留一次界面反射以及去程、回程的全部透射。忽略列间传播、垂直侧壁散射、折射、衍射、有限束宽、波束形成、散斑和多次反射。体模剖面的绘制和回波计算共用同一个分层函数，不另外画一张与计算无关的“超声图”。这是一台制造体模的单次散射实验，不是临床图像模拟器。

压强反射系数 r = (Z₂−Z₁)/(Z₂+Z₁)，去程压强透射 t₁₂ = 2Z₂/(Z₁+Z₂)，回程透射 t₂₁ = 2Z₁/(Z₁+Z₂)。无损界面的反射能量比例 R = r²，透射能量比例 T = (Z₁/Z₂)t₁₂² = t₁₂t₂₁，满足 R + T = 1。因此压强透射系数大于一，不等于能量凭空增加。

每个回波中心时刻等于上方各层厚度除以实际声速之和的两倍。回波压强为本界面 r、上方各界面的 t₁₂t₂₁ 与两程衰减的乘积。若单程累计衰减为 D dB，则压强衰减因子为 10^(−2D/20)。背景采用 0.35 dB/(cm·MHz)，嵌块再增加所选值；这些数值是教学设定。衰减按中心频率求值，在脉冲带宽内视为常数。两程损失 6 dB 时，压强乘以 10^(−6/20)，能量乘以 10^(−6/10)。

发射采用有限 Hann 窗载波，支撑时长 τ = 周期数/频率。**零时刻是发射包络中心**，领先半段自然出现在负时间，避免把半个脉冲宽度误计入深度。RF 是所有带符号、带延迟的脉冲相干叠加，随后对理想已知正交分量求模得到包络；不是各回波绝对值的相加，也不声称是紧支撑实信号的精确 Hilbert 变换。窄带的位置和上下边沿由同一声线的积分传播时间反解，包含有限脉冲刚接触界面和刚返回探头的边界状态。

薄片比较固定发射峰值压强，不固定总发射能量。两周期与八周期的 cτ/2 分别为 0.513、2.053 mm。对于本片的厚度和相位，实际相干包络分别具有两峰和一峰。这里的尺度来自有限脉冲支撑，不是普遍分辨率或半高宽保证；包络、相位、带宽、噪声都会影响可辨程度。不作信噪比或临床性能结论。

## 图像怎样计算

73 列对应 x = −18 + 0.5k mm 处的完整 A 线。351 行覆盖固定 0–70 mm 显示深度；每行取深度单元中心，以“二倍深度/假定声速”换算采样时刻，再读取该列相干包络。亮度使用 20 log₁₀、固定 0.25 压强参考和 45 dB 范围。零信号为黑，不逐列归一化，不加随机纹理、自动增益或预绘形状。

横向图像边缘比最外侧探头中心多出半个采样单元，使探头、选中线和像素中心严格对齐。逐列揭示只根据当前扫描进度遮罩同一份确定的计算缓冲。阴影实验只改变嵌块内部损失，声速实验只改变深度解释，原始回波到达事件不变。

Canvas 原样显示像素缓冲，不插值平滑。若无法取得二维上下文或写入图像数据，则由 SVG 绘制同一组 8 位灰度像素，只合并相邻同灰度单元。降级路径有真实重建数据，不是空画布或占位说明。封面也以同一模型的低分辨率重建配对已知体模。

## 手机、探索与生命周期

桌面并置体模与仪器，在分辨率章节改为宽幅双波形。手机使用独立 320 单位构图：前三章保留紧凑 277 单位体模和短波形/能量读数；极性章节只显示对齐回波；扫描、阴影、声速只保留扫描图和探头位置条；分辨率只保留上下两条比较。不将所有桌面仪器向下堆叠。主视觉预留 423 CSS px，下面是一条紧凑读数和当前解释，目标是在 320 px 视口下将主观看区控制在约 900 px 内。此处是设计预算，不是真实浏览器或手机测量。

正文至少 16 px，主要动作目标至少 44 px。原生范围控件通过共享 `Range` 明确设置翻译后的可访问名称。五类参数为横向位置、周期数、嵌块额外衰减、假定声速、观察时间。只显示当前视图能影响的参数：默认实验台有四个命名范围，探头进入嵌块列时才在此视图增加衰减，分辨率比较聚焦周期数。保留方向键、Home、End。完整重置恢复位置 0、两周期、额外衰减 2.2、假定声速 1540、时间 18 µs、实验台视图；两个预设也先恢复全部状态。模型细节按需展开。

影片使用 `useShowcase` 的章节和进度，拖动、重播可无历史地重建；暂停、减少动态、离屏和后台暂停使用共享播放基础设施。没有私有计时器、动画循环、音频引擎、WebGL 或 Worker。Canvas 卸载时清理上下文；`useCompact` 使用并释放共享媒体查询监听。SVG 为完整降级显示。
