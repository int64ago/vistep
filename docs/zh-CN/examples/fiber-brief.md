# 光纤 — 制作分镜

[English](../../examples/fiber-brief.md)

属于[新增 50 篇](../expansion-50.md)的制作范围。跟随一束脉冲进入玻璃纤芯，理解把光留在里面的是折射率边界和入射角，而不是金属镜面。

画面依次采用发光轴向剖面、放大的介质边界和到达时间图，不添加装饰性的三维电缆。手机展示长度更短、明确标注的局部剖面，横向结构保持原有比例；边界图按手机宽度重新安排。

八章分别展示纤芯／包层／涂覆层、玻璃到空气的反射与折射、跨越临界角、回到纤芯与包层、超出接收角、消除折射率差、比较不同路径的到达时间、发送短比特序列。每一步变化均对应计算结果。自由探索可选择实验，调整入射方向、界面角度或包层折射率。

模型实现斯涅尔定律、非偏振菲涅耳光强系数、真实边界交点、反射与逸出分支的能量、阶跃型光纤子午光线的路程，以及延迟接收的比特。功率在入口内侧归一化。纤芯半径为 25 μm，折射率为 1.48／1.46，是教学参数，不对应特定产品。没有计算完整波动模式、倏逝场、弯曲损耗、偏振演化、材料色散、涂覆层光学或实际损耗预算；不能把几条几何光线当作精确波导模式，也不能用它解释单模光纤的完整约束机制。
