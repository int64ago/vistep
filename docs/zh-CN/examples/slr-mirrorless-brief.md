# 单反与无反：同一镜头，两条取景路线

[English](../../examples/slr-mirrorless-brief.md) · [制作指南](../creating-a-scene.md)

## 要解释的因果问题

为什么传统光学取景单反在按快门时短暂变黑，无反用什么路线代替它？始终追踪同一条黄色镜头中心光线。转折是反光镜抬起：**取景先中断，传感器曝光随后才开始。** 结尾明确区分反光镜与机械快门。

## 资料与边界

2026-10-05 核查一手资料：[Canon 单反技术](https://global.canon/en/technology/canon-tech/tech/dslr/)、[Canon 无反技术](https://global.canon/en/technology/canon-tech/tech/mcamera/)、[Nikon 单反与无反结构](https://www.nikonusa.com/learn-and-explore/c/products-and-innovation/mirrorless-versus-dslr-exploring-key-differences)、[Sony 快门说明](https://www.sony.com/electronics/support/e-mount-body-ilce-9-series/articles/00018997)。

比较传统光学单反与传感器实时取景无反，并明确加入单反实时取景：信号抵达后屏，光学目镜保持黑暗。代表性全机械无反拍摄先关闭取景时开放的快门，再重新开始曝光；无反不等于只有电子快门，也不保证无黑屏。本片不推荐机型、不排名相机。

闭合四连杆是可信的教学驱动，不是厂商拆机复刻。五棱镜纵切面包含两块真实反射平面，但不计算横向屋脊反射和图像方向校正。对焦屏散射、自动对焦模块、镜头像差和真实光速省略。玻璃外形并非真实镜头处方。补偿只演示显示亮度因子，不仿真完整自动曝光。

## 电影与构图

7 章计划 168 秒，以录音测量后共享时间轴为准。全部状态从章节进度直接计算，暂停 seek 不继承历史。

| 章节               | 计划窗口   | 画面因果                                       | 桌面                 | 手机                                      |
| ------------------ | ---------- | ---------------------------------------------- | -------------------- | ----------------------------------------- |
| 同一镜头，两条路径 | 0–24 秒    | 同一中心光线穿过相同镜片，机身内路线不同       | 两台并列切开相机     | 先单反后无反，每次保留完整主体            |
| 跟着光到眼睛       | 24–48 秒   | 45° 主镜、对焦屏、两次棱镜反射到目镜           | 一台完整纵切面       | 保留全高度光路，文字在画布外保持 CSS 尺寸 |
| 镜子先让路         | 48–76 秒   | 连杆抬镜，取景黑，第一帘与第二帘依次经过传感器 | 固定剖面与放大取景窗 | 相同主体，镜状态和快门开口在下方          |
| 单反也能实时取景   | 76–100 秒  | 落镜恢复光学取景，再抬镜开放快门，信号给后屏   | 后屏与连通线路       | 不把光学目镜画成电子取景器                |
| 显示屏发出新的光   | 100–124 秒 | 传感器、处理器、电子取景器，预览亮度随补偿改变 | 无反剖面与图像       | 一台无反加取景窗                          |
| 无反也可以有快门帘 | 124–148 秒 | 开放快门先关，再做两帘曝光，没有反光镜运动     | 两条实际遮挡边界     | 传感器、帘、黑屏与重新开放同画面          |
| 把定义分开         | 148–168 秒 | 光学亮度不读预览补偿，电子亮度会变化           | 两台完整相机比较     | 单反再无反，当前主体保持完整尺寸          |

主体是实体 3D 切开模型；运行时 WebGL 失败使用同一几何推导的 SVG 剖面。放大取景窗是示意图，不声称实际追迹镜头像。黄色为光路、蓝色为读出电信号；fallback 保留后屏与取景中断的因果步骤。共享 Studio 管理离屏、后台、减少动态效果、键盘探索与资源释放。手动曝光相位无独立计时器，可反复停留观察。

## 模型验收与证据

作者数值检查覆盖主镜反射、两次棱镜折转、全行程固定铰点及四连杆长度、先清空镜面再曝光、每行等时曝光、实时取景、确定性 seek 与有限边界。6 项模型测试通过。另有 1 项取景回归将每个可见网格顶点经过实际相机投影，在多个拍摄相位检查桌面单台／双台以及 320 px 页面内 296×292 px 的手机主体视窗。此检查发现并修正了最初双台构图近侧镜头裁切。两个定向测试文件现共 7 项通过，独占 TypeScript 依赖闭包的严格 ES2023 no-emit 检查也通过。

本次交接是作者自审。浏览器关键停帧、完整电影观看、双语录音原声试听、真机性能与集成构建检查由主 agent 的验收记录分别建立，不以模型测试冒充。

集成复核补充：帘幕完全重开才恢复实时读出；露出的PCB、引脚、排线与显示器使用同一路由，实体遮挡探针覆盖五种构图。当前两个相机模型/渲染文件共9项回归通过，浏览器证据另见[六篇审看记录](../qa-six-explorations.md)。
