# 纠错编码：奇偶织网

[English](../../examples/error-correction-brief.md)

核心问题是：接收端没有原始副本，怎样定位被翻转的一位？始终跟随消息 `1011`，让位置编号穿过编码、信道和解码全程。转折点用真实双错制造误纠：修正之后校验全通过，消息却变了。随后增加总奇偶校验，让相同双错被拦截。

## 构图与逐章因果

暖纸色底上，以灰绿、柔金与灰紫三条细线交叠成校验织网。七个节点放在对应的七种集合成员区域，严格匹配 C1、C2、C4。红色短线表示信道翻转，绿色勾表示解码器修改，同时提供位值、编号和校验结果，不只靠颜色传意。曲线表示集合，不是实际电路走线或数据流动轨迹。

| 章节 / 起点     | 画面变化与观察                                         |
| --------------- | ------------------------------------------------------ |
| 四位数据 / 0 秒 | 保持 3、5、6、7 位数据，依次填入 P1、P2、P4。          |
| 重叠 / 22 秒    | 依次聚焦三条线，看位置 6 为什么只参加 C2、C4。         |
| 信道 / 44 秒    | 对齐收发编号，仅将第 6 位从一改为零。                  |
| 综合征 / 66 秒  | 逐个揭示校验结果，把 110 读作二进制位置 6。            |
| 修正 / 88 秒    | 先保留接收字，再翻回第 6 位，提取恢复的数据。          |
| 歧义 / 110 秒   | 翻转 3、5，再让普通解码器误翻 6，显示错误数据。        |
| 总校验 / 132 秒 | 加第 8 位，施加相同双错，用 s≠0、q=0 阻止交付。        |
| 边界 / 154 秒   | 依次展示无错、单错 6、单错 8、双错 3+5，标亮对应判断。 |

八章各 22 秒，共 176 秒。中英文讲稿分别创作，语音起点为章节起点后 0.45 秒。讲稿、字幕、章节数与时间现已冻结供父任务录音。交接 packet 只是临时汇入材料，不是第二份正式登记表。

桌面将较大的织网与按编号对齐的接收码字、解码说明并置。手机优先保留织网与当前推理，移除累计构造侧栏及次要成员列表；仅在传输章节展示发送和接收两行。后续章节将综合征配上当前纠正或拒绝输出。正文至少 16px，手动操作至少 44px。手机也移除重复章节标题，让当前解释靠近织网；页面标题与共享章节导航仍保留上下文。下方最终测量包含真实 lesson 页边距。

## 科学契约

独立模型实现二元系统 Hamming(7,4) 与全字偶校验扩展 Hamming(8,4)。`c=dG`、`s=Hr`、`HGᵀ=0`；数据列为 3、5、6、7。解码器只接收码字，不获取界面对照用的原消息或翻转数量。扩展解码检出双错时，不返回“纠正”字与数据。允许手选任意翻转子集，以直接暴露能力边界。

普通综合征若只用于检测，可以报告全部双错；若按单错规则纠正，则无法区别双错产生的相同综合征。扩展 SECDED 可以纠正全部单错、检测全部双错，不能可靠纠正双错。Hamming 距离是不同位置的数量，奇偶校验是选定位集合的异或。翻转 1、2、3 位和 1、2、3、8 位分别构成误纠和漏检反例。没有对具体硬件、实际故障率或解码速度作推断。

2026-09-05 核对的一手资料：

- [Hamming 1950 年原论文，第 3–5 节](https://ineffectivetheory.com/edu/papers/hamming-codes-1950.pdf)：构造、扩展与距离论证。
- [MIT 6.02 纠错编码讲义](https://web.mit.edu/6.02/www/s2010/handouts/lectures/L6.pdf)：距离及有界纠检能力。
- [MIT 6.111 信息论习题解答](https://web.mit.edu/6.111/www/f2004/tutprobs/temp/info.htm)：双错歧义与总校验逻辑。

图形全部为自绘 SVG/CSS，位值从模型导出，没有添加外部位图、字体或媒体资源。无需 WebGL、canvas、Worker 或网络即可显示完整二维说明。
