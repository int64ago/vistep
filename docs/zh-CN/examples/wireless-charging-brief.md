# 无线充电：电能跨过一道间隙

[English](../../examples/wireless-charging-brief.md)

选题 `wireless-charging`，组件 `WirelessCharging`。正式讲解位于 `src/data/narration.json`，元数据在 `src/data/topics.ts` 登记。八章，每章计划 22 秒，共 176 秒。交付前已冻结中英文讲解、字幕、章节顺序与模型导演时序。关联已存在的 `transformer-electric`、`electric-generator`。

## 因果主线与构图

先把“有感应电压”和“实际送出功率”分开。跟着两条完整铜线，从开路接收端走到闭合交流负载，再依次改变间距、错位、频率、磁片与铜阻。转折点是发送线圈里仍有明显电流，接收端却可能得到很少功率。

浅色陶瓷底座上方悬置剖开的接收部件，铜线、绝缘跨线、半透明磁片、支架和接收负载可以同时追踪。靠近与错位占据全宽主画面；下方证据窄带随章节换成波形、磁链/电压、重叠几何、频率响应和功率分配，不复用感应电机的圆筒剖面布局。

| 时段       | 可见事件                               | 因果观察                                                                       |
| ---------- | -------------------------------------- | ------------------------------------------------------------------------------ |
| 0–22 秒    | 接收开关断开，发送交流幅值逐渐建立。   | 发送电流在独立且完整的电路中往复。                                             |
| 22–44 秒   | 共享磁链与感应电压走过一个电气周期。   | 感应电压取决于磁链变化率，不是静态磁链大小。                                   |
| 44–66 秒   | 进度 35% 时，接收串联开关闭合。        | 负载电流与功率出现，反射负载也改变发送电流。                                   |
| 66–88 秒   | 对齐线圈从 20 mm 靠近到 3 mm。         | 本工况范围内，耦合增强，负载功率上升。                                         |
| 88–110 秒  | 保持 4 mm 高度，横向移开 30 mm。       | 高度没变，错位仍能削弱耦合。                                                   |
| 110–132 秒 | 固定位置，频率由 85 kHz 扫向 150 kHz。 | 补偿改变电抗、电流和功率；曲线是电路解，不是先假定峰值再画图。                 |
| 132–154 秒 | 章节中点比较有、无磁片两个稳态。       | 电感与互感同时改变，固定电容不再按原来的条件调谐；磁通仍有闭合的空气返回路径。 |
| 154–176 秒 | 两只线圈电阻增至默认值的 3.5 倍。      | 铜耗占比上升，交流负载功率下降，但每一瓦仍有去处。                             |

开关与磁片变化比较变化前后的稳态，不宣称相量模型解析了快速切换暂态。磁片章节是前后对比镜头，不是材料拆除的动态求解。虚线用原有的 6.8 µH 电感值标记基准曲线。

## 几何、手机与操作

每只线圈是连续八匝阿基米德螺旋：内半径 8.5 mm、径向节距 1.6 mm、外端半径 21.3 mm、线半径 0.45 mm。内端在相隔 1.5 mm 的绝缘层跨到外侧，避开外圈和磁片；外端引线、电容电极、发送源模块、接收开关与电阻都有明确连接。没有额外隐形匝数或断开的装饰螺旋。

深灰色磁片、支撑圈、陶瓷底座、接收框和电路板构成可信的装配。接收磁片透明仅用于剖视。铜线颜色由电流正负与大小驱动，接收负载的弱强调由功率驱动，不假装计算温度。四条闭合磁路来自同一模型几何，方向和强调程度由发送端贡献的共享磁链决定；曲线明确不是有限元场线或 B 值测量。

场景自身宽度低于 620 px 时，采用更靠近深度轴的镜头，把横向偏移从 +x 改为 −z 展示。对于这里的旋转对称线圈，欧氏距离、耦合与电路完全相同，30 mm 不会被缩成一个小图标。二维后备另用 300×330 坐标系，保留连续线圈、绝缘跨线、电容、开关、交流负载与闭合磁路。

手机按章节选择一个证据视图。相位/电流章主物体高 304 px，靠近章为 346 px，错位/调谐/磁片章为 252 px，功率章为 265 px。删去重复标题和不必要的刻度端点。关闭说明时设定 770 px 最小舞台高度，减少播放器位置变化；320 px 视口下目标约为 900 px 以内。**本工作者没有测量真实浏览器高度。** 图表文字用至少 16 px 的 HTML，按钮与滑块至少 44 px 高。

六个范围控件同时有稳定的 `htmlFor`/`id` 和经过翻译的 `aria-label`。重置覆盖间距、偏移、频率、负载、铜阻倍率、取样相位、开关、磁片和观察模式。播放、暂停、跳转和重播全部由共享播放器控制，自由探索没有独立计时器。

## 电路、符号与近似

两只内端均为同名端，正电流沿内端→外端，对应绕组法线 +y。相量为有效值，时间约定为 `Re(√2 I exp(jωt))`。双串联补偿电路：

`Vs = Z1 I1 + jωM I2`；`0 = jωM I1 + Z2 I2`。

`Z1 = Rs+R1+j(ωL1−1/ωC1)`；`Z2 = R2+RL+j(ωL2−1/ωC2)`。

闭合接收支路的反射阻抗为 `Zref=(ωM)²/Z2`，`I1=Vs/(Z1+Zref)`，`I2=−jωM I1/Z2`。开路时 I2 和负载功率为零，但感应电动势 `E2=−jωM I1` 可以非零。波形展示发送端贡献的磁链 `λ2←1=M I1`，单位 Wb·turn，不是接收端总磁链或空间磁感应强度。

默认 Vs = 2 V，Rs = 0.5 Ω，R1 = 0.25 Ω，R2 = 0.28 Ω，RL = 3 Ω。磁片存在时 L1 = L2 = 6.8 µH，移除时取 4.2 µH。固定补偿电容 165.5574896 nF，使单线圈自谐振分别为 150 kHz 与约 190.86 kHz。完整耦合电路的功率峰值不必准确落在单线圈自谐振点。电阻是教学等效参数，没有从画中铜线材质反推。

耦合采用作者明确指定的近似 `k=k0/[1+(d/0.015)²]^(3/2) × exp[−(x/0.022)²]`，带磁片 k0 = 0.22，不带磁片 k0 = 0.1364，互感 `M=k√(L1L2)`。轴向项借用几何衰减形状，侧向高斯和磁片系数均为声明的近似。没有计算纽曼积分、磁片场解或 Qi 实测标定，也不宣称实物充电效率。手机和桌面用相同的 d、x、k 与电路解。

实功率从 `Re(Vs I1*)` 独立计算，等于 `|I1|²Rs + |I1|²R1 + |I2|²R2 + |I2|²RL`。所有电阻为正，且 `M²≤L1L2`，电感矩阵无源。谐振可以抬高电压或循环电流，不能提供主动功率增益。测试也检查瞬时磁能 `½L1i1²+½L2i2²+Mi1i2` 与两只电容的储能收支。稳定直流时串联电容阻断电流，响应归零，并没有伪造有限容抗。

模型示例：默认闭合负载约得 0.975 W；对齐线圈从 20 mm 到 3 mm，负载功率约从 0.171 W 增至 1.187 W；4 mm 高度下错位 30 mm，功率约从 1.167 W 降到 0.075 W。这些是指定参数的结果，不是硬件测量。

未建模部分包括开关谐波和暂态、磁片磁滞与涡流损耗、集肤/邻近效应的频率依赖、温升、异物、整流、稳压、电池、通信及保护。源电阻只是声明的串联损耗，不是完整逆变器效率模型。没有加入未经计算的电池充电动画或整流器读数。
