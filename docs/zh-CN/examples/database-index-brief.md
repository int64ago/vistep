## 现象与美术方向

问题是「不用翻遍整张表，怎样找回一条完整记录？」场景由真实的页号与行号组织：蓝色页签是索引页，绿色页签是堆页。桌面保留经过的页路径，主要视觉集中在当前页；手机把当前页放大到可读宽度，只显示最近四个页号，并用省略号说明前面还有路径。分裂时并排展示两张真实的新页，不缩小整棵树。

完整解释由共享 Showcase 字幕承担，观看区不重复大段说明。主体只保留章节标题、查询条件、比较式、页号、行号与简短模型注记。没有三维装饰、虚构二叉树、缓存柜布局或假耗时。

## 模型与简化

独立、仅插入的 B+ 树：叶页最多三项，内部页最多四个子页，堆页最多四行。非根叶页保持两到三项，非根内部页保持二到四个子页；所有提交后叶子深度相同，支持空根叶页。

按整数键值升序、同键按唯一行号升序排序。分隔键准确等于右侧子树最小的键值行号对。下界探针使用行号零，排在所有真实同键记录之前；到达叶页后沿链接继续，遇到超过包含式上界的键才停止。模型支持正负一百万内的整数，界面有意只开放零到九十九。不支持字符串、空值、浮点数或排序规则。

完整记录按插入顺序留在堆中；叶项只保存键值与行号。取内容必须触及对应堆页。每次查询从空的、无容量限制的缓存开始，已读页保留；计数是不同索引页、不同堆页，以及比较器调用次数，不是磁盘读次、毫秒或加速倍数。数值比较两边使用行号零，内部路由比较完整对；下界不满足时不比较上界。结果显示排序在访问计数之外，两种方案规则相同。

每次插入复制树，保存独立事件快照。叶页第四项触发二加二分裂，修复邻居链接，把右页最小项复制到父页。内部页第五个子页触发三加二分裂，中间分隔键向上推，分裂后两边都不再保留。根分裂创建新根。局部事件可能还没有连接进父页，画面明确标注；查询只在已提交整树执行。没有删除、合并、事务、MVCC、并发、缓存替换、持久化、覆盖索引优化或生产执行计划。

## 八章影片

八章各二十二秒，共一百七十六秒；每条语音起点为章节起点加零点四五秒。中英讲稿分别撰写，英文每章五十一到五十四词。

1. 在六张堆页中逐行扫描二十四条记录，找键六十三；允许重复键，所以找到一条还不能停。
2. 读取根页实际分隔键 `(38,r3)、(47,r4)、(70,r2)`，用 `(63,r0)` 选路。
3. 跟随 `I8 → I7 → I10 → I11`，再到 `H4` 取回 `r14` 的内容 `item-14`。
4. 同一答案：索引触及四张索引页加一张堆页、比较十一次；全扫六张堆页、比较三十三次。
5. 范围三十八到四十七返回 `(38,r3)、(42,r6)、(42,r7)、(42,r8)、(47,r4)`；索引触及六加二张不同页，比较十七次。
6. 插入四十、五十三、六十六，再插入七十九，让叶页分裂并把 `(82,r22)` 复制到父页。
7. 继续插入九十二、五、十八、三十一、四十四、五十七、七十、八十三、九十六。最后一次插入触发叶页分裂、两次内部页分裂和新根，树高变为四。前置插入占本章四分之一，最终级联占四分之三。
8. 全取三十七条记录：索引十七加十张不同页、比较七十七次；全扫十张堆页、比较七十四次。结果相同，页数优势倒转。

`diShot(film, chapter, progress)` 只根据共享导演的章节与进度重建画面，没有独立时钟、逐帧随机状态或播放历史。手动输入不影响自动影片。CSS 高亮缓和，并尊重减少动态效果。无 WebGL、音频、Worker 或观察器资源；共享播放器负责可见性、后台暂停和播放控制。

## 自由探索与可访问性

所有输入与选择器有明确的 `htmlFor/id`，步骤滑块另外设置翻译后的 aria-label。提供查询上下界、两种访问路线、两种堆顺序、新插入键、步骤滑块、前后按钮和全量重置。非法整数与反向边界通过状态文字说明。每个新行分配独立行号，最多新增三十行；切换排列会从相同键值多重集重新建表。

重置恢复排列 A、种子十九、查询六十三到六十三、索引路线、插入键七十九、零新增行、查询与分裂第一步、查询视图，以及关闭规则说明。标准 HTML 是主要渲染方式，不依赖三维或特殊设备才能理解。
