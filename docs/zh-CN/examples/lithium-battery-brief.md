## 画面要说明的事

可充电电芯通过改变两个宿主之间的锂分布，储存可逆化学功。跟住固定的金色示踪点穿过内部湿润孔道，再跟住蓝色示踪点沿外部导线移动。休息时，电压回升但电量不增加；充电时，外部供能，同一组路径反向。

器物采用竖立的电芯剖面：铜集流体、带导电连接的层状石墨颗粒、真正开孔的隔膜、带导电网络的 LFP 颗粒、铝集流体。电解液位于多孔区域。极耳实际接入外部负载/电源回路，内部离子路径与电极反应共同完成工作回路，隔膜中没有电子导线。第一章让前方观察面逐渐透明，不拆开工作连接。

材质使用石墨蓝灰、柔和 LFP 绿、铜色和象牙色隔膜。Li⁺ 为金色，e⁻ 为蓝色，圆环标出零号示踪点。十八个身份固定的示踪点跟随净电荷移动，反向时原路返回，没有取模循环、重生或随机时钟。它们是选出的路线示踪对象，不是原子计数或微观速度模拟。

## 科学边界

限定化学体系为石墨 / 磷酸铁锂。平均组成是 LiₓC₆ 与 LiᵧFePO₄，x = 0.05 + 0.9z、y = 0.95 − 0.9z，z 为可用 SOC。两宿主各有 Q/(0.9F) 摩尔位点，Q = 3600 C，F = 96485.33212 C/mol。电极中的总锂守恒，每摩尔转移对应一法拉第外部电荷。电解液的库存视为不变的平均背景，不逐个绘制阴离子和局部电中性过程。

SOC 端点表示选择的可用窗口，不表示锂的有无。正常石墨储锂是嵌入，不是金属锂负极。平均组成不求石墨分阶、LFP 两相共存、相界运动或颗粒间差异。可见厚度、粒子和孔被放大，是显示几何，不是测量显微图或制造尺寸。

开路曲线是明确自拟的 LFP 平台状近似：U(z) = 3.30 + 0.08w + 0.14w⁹ V，w = 2z − 1，**没有拟合商用电芯**。取放电电流为正，dz/dt = −I/Q，dp/dt = (I − p/Rₚ)/Cₚ，V = U − IR₀ − p。参数为 R₀ = 0.04 Ω、Rₚ = 0.03 Ω、Cₚ = 1500 F、τ = 45 s。RC 是被动等效状态，不是真实电容，也不是已经求解的扩散场。

可逆化学功储库 Echem = Q∫U dz，以可用下端为参考零点；极化暂存项为 Cₚp²/2，内部热功率为 I²R₀ + p²/Rₚ。有符号端口功率 VI、两项储能变化率和内部热满足瞬时恒等式。指数解和 p² 的解析积分给出累计热与端口能量；独立 RK4 对状态、功和热的积分验证它，而不是只重复这条恒等式。

影片末尾，初始加充入约 5.212 Wh，保留约 3.300 Wh，输出约 1.818 Wh，内部热约 0.094 Wh。这些四舍五入的数值属于教学模型，不是产品指标。休息时化学功储库与 SOC 不变，减少的 RC 储能成为热；电压回升没有制造新的能量或电荷。

控制器在可用容量端点或示例 2.8/3.6 V 边界关断电流，并在当前指令段剩余时间保持断流，电压边界通过分段括区求根定位。没有模拟真实恒流恒压充电协议。温度固定，不可逆热记入环境；熵热、老化、副反应、锂析出、浓度空间分布、相变与量热预测均不在范围内。

## 几何、手机与资源

独立模型提供集流体、颗粒、外部路线、隔膜孔和实际边界。每条可见离子通道都经过真实挤出隔膜的开孔；电子路径始终在导电电极/集流体或外部装置中。位置、宿主颜色、示踪点、负载/电源状态和数字都来自同一个模型。

镜头拟合考虑底座、外壳、集流体/极耳和电源边界，保留透视余量。观看态镜头可直接定位；探索采用包围球距离，避免转出一个被裁切的近角。共用 Studio 管理减少动态效果、离屏/后台暂停、渲染器与材质释放和上下文丢失，不修改共用实现；新增 ResizeObserver 在卸载时断开。

桌面是居中的竖直剖面，部件名称靠近器物。手机用更正面的镜头，库存/功率章缩为 230 px 器物区，证据使用原生宽度；隔膜章改用独立剖面；休息和容量端点章完全替换器物。正文/SVG 字号 16 px，主要操作与滑块至少 44 px。章节按内容分配紧凑高度，不用大块空白强行统一。

三个有明确名称的滑块控制初始 SOC、电流大小、过程/休息时间。过程与视图按钮支持键盘并标明选中状态。复位恢复 85%、1 A、600 秒、放电、路径视图、镜头及三维模式。所有变更从所选初态重建；休息实验先放电 120 秒。没有专题私有音频、Worker、外部素材或持续运行的时钟。
