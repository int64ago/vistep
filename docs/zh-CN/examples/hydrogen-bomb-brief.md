# 氢弹：热核聚变

[English](../../examples/hydrogen-bomb-brief.md)

## 主问题与因果主线

两个轻核聚合放出的每核子能量远高于裂变，为什么点燃聚变却要先引爆一颗原子弹？跟住一颗氚核冲向氘核：在任何能达到的温度下库仑势垒都把它推回；隧穿给出一个极小、随能量陡升的穿越概率；麦克斯韦分布的尾巴乘上这个概率形成伽莫夫峰。于是反应率 ⟨σv⟩ 随温度提高几倍就上升几千倍。化学火焰在这个尺度上是零；只有裂变火球能提供所需的温度与辐射，压缩则让燃料在飞散前烧掉。燃料用锂-6 自产氚，同一反应可以靠引力、磁场或惯性约束。

## 内容边界

本篇讲教材级核物理与等离子体物理。只陈述公开概念“裂变初级的辐射加热并压缩分开放置的聚变燃料”，不涉及几何、尺寸、材料、辐射通道、级结构、当量或燃料量。压缩模型固定任意一团低温 D–T 密度的燃料，只描述标度关系。

## 画面方向

深蓝紫底上的明亮等离子体语言，与裂变篇的暗室区分。每章一个仪器：

1. **势垒**：由模型采样的库仑山，对数间距轴（1 fm 到 10⁷ fm），氚核在距离轨道和山坡上来回，3kT/2 的能量线，折返点，以及带概率读数的淡色隧穿分身。
2. **结合能**：对数 A 轴上的结合能曲线，氘氚抬升到氦-4，D–T 与铀裂变的每核子条。
3. **分布**：按峰值归一的麦克斯韦能量分布、右侧对数轴的隧穿概率，两者乘积形成伽莫夫峰；火焰温度用一根针代替看不见的尖峰。
4. **反应率**：⟨σv⟩ 的双对数图，D–T 与 D–D 曲线，移动的读数点，太阳核心与 10⁸ K 的参考线。
5. **压缩**：对数温度阶梯（火焰、太阳核心、裂变火球），按 C^(−1/3) 收缩的燃料球，密度、反应率 ∝ n² 与燃烧比例读数。
6. **燃料**：反应链 D + T → ⁴He + n，被追踪的 14 MeV 中子，n + ⁶Li → T + ⁴He，新氚回到起点。
7. **约束**：密度对约束时间的对数图，10 keV 点火线，依次显示托卡马克、惯性约束与太阳。

桌面用 440 px 舞台，带侧标签与开尔文换算；手机（600 px 以下）用 372 px 舞台，温度阶梯改为水平轨道，去掉次级刻度标签，SVG 文字保持 16 px。探索模式提供七种视图、D–T/D–D、3000 K 到 100 keV 的对数温度滑块和 ×1 到 ×1000 的压缩滑块。

## 实测影片

七章各计划 24 秒；录音实测两种语言均为 **210 秒**，章节起点为 0、27、56.5、84.5、113、145、175.5 秒（`src/data/film-timeline.json`）。时长测量不代表试听通过。

| 章  | 可见的因果变化                                                          |
| --- | ----------------------------------------------------------------------- |
| 1   | 3000 K、太阳核心、10 keV 三次靠近都在接触点之外折返；隧穿分身带概率出现 |
| 2   | 在曲线上标出 D 与 T，抬升到 ⁴He 并放出 17.59 MeV，再与裂变按每核子比较  |
| 3   | 温度从 3000 K 的针经太阳核心升到 10 keV；隧穿曲线与伽莫夫峰出现         |
| 4   | 反应率读数点从 1 keV 升到 30 keV，经过太阳核心与 10⁸ K 参考线           |
| 5   | 火焰标记不动；火球到达 10 keV；同一团燃料压缩 ×1000，烧掉比例上升       |
| 6   | 被追踪的中子离开 D–T 反应，撞锂-6 生成氚，新氚回到起点                  |
| 7   | 托卡马克、惯性约束与太阳依次出现在点火线旁                              |

## 模型

- 结合能取 AME2020：Q(D + T) = 17.59 MeV，中子 14.05 MeV，α 3.54 MeV；Q(n + ⁶Li) = 4.78 MeV。
- 库仑势 1.44 MeV·fm / r；接触距离 1.2(2^{1/3} + 3^{1/3}) = 3.24 fm；势垒 0.444 MeV。
- 伽莫夫能量 E_G = 2 m_r c² (πα)² = 1182 keV（D–T）、986 keV（D–D）；隧穿 exp(−√(E_G/E))。
- 麦克斯韦相对能量分布及其尾巴（不完全伽马函数）；伽莫夫峰 E₀ = (E_G (kT)²/4)^{1/3}。
- 反应率：Bosch & Hale 1992 参数化，与公开表格在 1、2、5、10、20、50、100 keV 对照；低于 0.2 keV 按 T^{−2/3} exp(−3E₀/kT) 外推并在 0.2 keV 处衔接。
- 燃烧：f = ρR/(ρR + H_B)，H_B = 8 m_i c_s/⟨σv⟩，c_s = √(2kT/m_i)；同一质量压缩 C 倍给出 ρR ∝ C^{2/3}。
- Lawson 参考 nTτ ≈ 3×10²¹ keV·s/m³（10 keV）；示例点为公开的数量级数值。
