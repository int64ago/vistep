# 直升机制作说明

[English](../../examples/helicopter-brief.md) · [制作流程](../creating-a-scene.md)

问题是：机身停在原地，机翼怎样把它托起来？全片跟踪同一片铜色桨叶，同一架原创民用直升机始终在场。机体不是某个实机型号的复刻。

## 实物表达

机身采用克制的灰绿色蒙皮、烟蓝玻璃、连续尾梁和相连滑橇；旋翼毂、桨根与尾桨保持真实的连接关系。机舱由连续截面放样，玻璃和蒙皮共用精确边界，避免椭球相交造成锯齿与白块。风挡柱、窗框、门缝、座椅、仪表台与发动机通风槽提供观察尺度。

七个章节都以这架飞机或它的真实相连部件为主体。第 2 章在 0.75R 处切开实体桨叶并近看其截面，第 3 章靠近桨毂与桨根，第 4 章镜头跟随同一铜色桨根转一圈。角落保留标注为“观察部位”的小整机定位图；短波形只为当前部件提供数值对应。推力、重力和尾桨侧推直接锚定实体。没有用随机气流粒子或虚构偏航轨迹填充画面。

## 资料与分镜

依据 [FAA 第 2 章](https://www.faa.gov/sites/faa.gov/files/regulations_policies/handbooks_manuals/aviation/helicopter_flying_handbook/hfh_ch02.pdf)的旋翼气动力、[第 3 章](https://www.faa.gov/sites/faa.gov/files/regulations_policies/handbooks_manuals/aviation/helicopter_flying_handbook/hfh_ch03.pdf)的操纵分工，以及 [NASA NDARC 理论附录 §11-4.1](https://rotorcraft.arc.nasa.gov/Publications/files/NASA%20TP-2009-215402-app3.pdf)的理想诱导速度。

计划七个最短 24 秒窗口，共 2:48；配音生成后需按两种语言的实测时长重排共享时间轴。

| 章节       | 实物上发生的变化                                  | 要说明的因果                         |
| ---------- | ------------------------------------------------- | ------------------------------------ |
| 旋转的机翼 | 铜色桨叶绕主轴转动，机身保持同一位置              | 桨叶仍在相对空气运动                 |
| 桨距与空气 | 桨距 6° → 10° → 6°；同一位置的剖面同步放大        | 桨距、入流、迎角和升力相连           |
| 总距       | 两片桨叶一起从悬停值增加 1.8°，然后恢复           | 固定转速时，总距改变推力大小         |
| 周期变距   | 同一片桨叶的角度随每圈方位变化                    | 跟踪桨叶身份，避免把曲线当成不同桨叶 |
| 倾斜推力   | 相连双叶旋翼沿给定叶尖轨迹平面运动，倾角 0° → 20° | 同一主推力分出垂直与水平分量         |
| 尾桨       | 尾桨锚点的侧推箭头随补偿 1 → 0 → 1 改变           | 侧推乘长力臂产生反向力矩             |
| 重新平衡   | 保留倾角，稍增总距直到 T cos β = mg               | 垂直恢复平衡，水平分量仍在           |

手机采用完整机体加当前需要的一种短附图或一行量，不堆叠桌面仪表。所有正文与 SVG 文本保留 16 px。章节状态与姿态来自共享播放时钟，不开独立动画定时器。

## 模型与几何边界

近悬停模型沿两片等弦长、无扭转桨叶积分线性叶素升力，并求解同一个均匀诱导速度，使 `T = 2ρAvi²` 成立。半径 4.5 m、桨根半径 0.7 m、弦长 0.32 m、角速度 42 rad/s、质量 1,000 kg。自由探索覆盖总距 4–13°、周期变距幅度 0–3°、给定倾角 0–25°和尾桨补偿 0–1.4。

理想诱导功率为 `Tvi`，反扭矩使用该功率除以角速度。尾桨实际锚点和计算力臂同为 4.7 m；两条力矩条统一以 7,000 N·m 为满量程。倾盘几何满足 `y − ymast = −x tan β`，桨根仍汇入同一主轴锚点。这是明确给定的跷跷板式姿态，不是挥舞动力学结果；周期变距波形与倾盘求解分开，不把某个机械相位当作通用定律。

不模拟型阻损失、失速、高速前飞、发动机响应、侧向配平和完整飞行轨迹。

## 验收分工

作者测试覆盖叶素与动量闭合、径向收敛、反求总距、推力分量、对侧桨距、尾桨力矩、输入边界、寻址复现、桨根连接、2D 构图稳定和实体投影边界。400×230 与 290×167 封面栅格自审记录在 `artifacts/helicopter/`。

作者自审不等于独立复核。主集成 agent 负责实际浏览器、完整播放、窄屏、资源失败、双语配音、全项目验证和发布记录；原生试听与真机性能分别保留证据缺口。
