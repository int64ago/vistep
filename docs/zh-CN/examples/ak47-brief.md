# AK-47：一条能量线

[English](../../examples/ak47-brief.md)

## 问题与实物方向

一股燃气，怎样变成一次往返？从可信的实物开始：深色钢材、成形木件、弯曲弹匣和枪管上方的导气管。外壳变浅后，镜头靠近相连的活塞杆、枪机框和连续的回位簧。理解转折在于：输入结束，运动还会继续；弹簧先储能，再把能量交回运动。

主画面为立体器物，包含原创外形、柔和倒角、金属接缝与加强筋、不规则木纹和细微表面粗糙度。后续章节明确近看运动部件，允许外形离开局部镜头。同一组外部轮廓和实体几何生成投影 SVG 备用视图与独立构图的封面。外形属于视觉重建，不是制造图；不能由它补全被省略的操作系统。

手机开场优先保持完整对象，后续优先呈现相连的运动部件。同位比较在一个局部镜头中放两份实物组件，位移相同、方向相反，能量条使用相同比例。解释标签全部为 16 CSS 像素 HTML。旁白按部件名称和能量颜色指认，不依赖桌面方位。

## 计划分镜

七个 24 秒窗口，共计划 168 秒。最终共享时长由录音测量确定；下表记录可见的因果顺序。

| 窗口       | 章节         | 新的观察                                                       |
| ---------- | ------------ | -------------------------------------------------------------- |
| 0–24 秒    | 一条能量线   | 从完整器物露出活塞杆与枪机框的固定连接。                       |
| 24–48 秒   | 燃气做功     | 导气管内能量高亮对应短暂输入和运动起点。                       |
| 48–72 秒   | 始终相连     | 活塞杆与枪机框保持偏移，一起后移。                             |
| 72–96 秒   | 把运动存起来 | 输入结束后仍后移，压缩回位簧，弹性储能增加。                   |
| 96–120 秒  | 把能量交回来 | 弹簧展开，在无新输入时推动相连组件返回。                       |
| 120–144 秒 | 同位不同向   | 两个同位移时刻的压缩量与弹性储能相同，速度反向、累计耗散不同。 |
| 144–168 秒 | 一轮能量路径 | 单次往返到达边界，剩余运动计入耗散并停住。                     |

首章进度 0.23 开始透视，到 0.48 达到观察状态。播放中的镜头变化平滑过渡；暂停跳转直接落在对应状态。弹簧从两端连接点重新生成，替换时释放旧几何。共享 Studio 管理渲染器、可见性和控件生命周期；本篇自行释放纹理与监听器。

## 范围与独立计算

本篇为非操作性机械概览。表现相连大部件，省略供弹、击发、闭锁、弹药、真实压力、真实时间、弹道与射击控制。探索只选观察时刻或同位移对照，不调节武器性能。建议从 12 岁观看，依据运动、储能与方向这些概念前提，不是访问分级。

`src/models/ak47.ts` 在画面背后采用通用、无量纲的质量—弹簧近似 `x″ = f(τ) − x − c x′`。平滑单次输入在最大位移前结束，运动、输入功、阻尼耗散使用相同 RK4 子步。返回边界经求解确定，剩余运动能量计入耗散后停止。这不是真实枪械碰撞或工作周期预测。

能量条使用同一总输入功作为固定分母，遵守“输入功＝运动能量＋弹性储能＋耗散”。同位比较分别求解两个对应时刻。实时几何用同一个位移驱动相连的杆与框，弹簧两端持续连接。器物中导气管与活塞共轴，但不采用校准后的硬件尺寸。

## 来源与原创性

- [史密森尼美国国家历史博物馆 AK-47 藏品](https://americanhistory.si.edu/collections/object/nmah_439260)：战后背景与导气式说明。2026-09-12 直接读取曾返回 500，但精确 ID 搜索返回完整机构历史正文。
- [史密森尼 AK-47 第二型号藏品](https://americanhistory.si.edu/collections/nmah_1067460)：机构外观照片用于观察材质分离和轮廓；不复用照片。
- [格林尼治皇家博物馆 AK 系列藏品](https://www.rmg.co.uk/collections/objects/rmgc-object-227949)：导气方式、木材和金属外观。实物为同族 Type 56，不作为精确零件来源。
- [英国历史后装轻武器协会 AKM 分类](https://hbsa-uk.org/knowledge-and-research/hbsa-dvd-index-and-content/hbsa-historic-machine-guns-dvd/akm-7-62x39mm-automatic-rifle/)：AK 系列长行程导气分类，其它性能数据不在本篇范围内。
- [OpenStax 大学物理第一卷 15.2 节](https://openstax.org/books/university-physics-volume-1/pages/15-2-energy-in-simple-harmonic-motion)：运动能量和弹性储能的一般关系。

轮廓、表面细节、纹理与编排均为原创代码绘图，不复制博物馆图片或机构图。封面从主场景共用的外表面和回转件几何生成，以独立镜头构图。

## 审看界限

作者测试覆盖能量账、速度／力的有限差分、无输入回程、同位对照、确定性跳转、外形几何有限性、弹簧端点连接，以及完整／局部／手机构图下实际网格顶点的投影。这些属于模型和几何证据。集成负责人另行检查浏览器停帧、完整播放器高度、静音完整播放、目录和社交图、录音及发布。原生试听和真机性能必须在实测前明确保持未验证。
