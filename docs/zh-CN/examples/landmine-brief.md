# 地雷制作说明

[English](../../examples/landmine-brief.md) · [专题制作](../creating-a-scene.md)

本篇以逼真的完整地雷外壳为主角，观察不透明土层、外壳近镜与植被变化。原创程序化几何参考 [Smithsonian 美国国家历史博物馆的 Model 43 Tellermine 馆藏外观](https://americanhistory.si.edu/collections/nmah_407167)，保留圆盘形壳体、封闭覆盖件、卷边与连接的侧把手。它只提供外部观察，不带制造尺度或可工作的内部机构。

初始普通地表完全遮住地雷。教学观察切面打开时，物体位置固定；土质底层始终保留，其接触高度直接由外壳最低点推导。未剖开的土壤、草与落叶共用一张裁切平面。近镜容纳完整外壳和把手，仅保留局部柔和接触暗影。顶面改用平面纹理映射，消除径向重复色斑，固定磨损保持克制。

最终分镜为 **7 × 24 秒 = 2:48**，实测配音后确定共享时长：

| 章节                   | 可见观察                                                               |
| ---------------------- | ---------------------------------------------------------------------- |
| 地表之下               | 不透明土层打开观察切面，固定外壳显露，下方仍有接触土层。               |
| 完整外壳近看           | 连续推进的镜头观察封闭轮廓、卷边和侧把手。                             |
| 静止的外表，储存的能量 | 镜头缓慢环视外壳，简短旁注区分触发事件与事先储能；不按压、不演示爆炸。 |
| 地表在变，物体仍在     | 镜头回到原土层，草叶位置不变，覆盖外观变化。                           |
| 时间不是安全证据       | 四个时间阶段推进，物体仍在，状态仍未知。                               |
| 磨损也不是答案         | 近看固定涂层、磨损与泥土，这些外观不提供安全结论。                     |
| 让观察停在接触之前     | 回到土层，以不靠近、不触碰及联系专业机构收束。                         |

用户明确要求逼真实物后，原概念椭圆、整屏三节点图和归一化能量波形已删除。独立模型负责确定性观察、对象身份、连续镜头和未知状态，不计算反应、爆炸传播、伤害范围、实际装置状态或随年龄变化的危险概率。交互仅改变实物观察、地层可见性、植被或教学时间。

三维模型与投影图共用完整外壳轮廓。视口宽度为 361–600 px 时，模型区高 320 px；宽度不超过 360 px 时，模型区高 250 px。16 px HTML 标签独立于透视缩放，主要控件至少 44 px。博物馆外观参考不是型号识别指南。建议归入“武器与安全”，起始年龄 12 岁仅为编辑建议。

2026-09-12 查阅的原始科普来源包括 [ICRC 的长期遗留危险说明](https://www.icrc.org/en/article/landmines-and-explosive-remnants-enduring-human-cost-measured-decades)、[ICRC 的社区影响记录](https://www.icrc.org/en/article/landmines-impact-communities)和 [UNMAS 风险教育](https://unmas.org/en/news/unmas-south-sudan-provides-life-saving-risk-education-to-sudanese-refugees)。末章建议不靠近、不触碰可疑物，并联系当地主管部门或专业排雷机构。

针对检查覆盖外壳位于未剖地表下方、土层接触高度、身份保持、确定性跳转、章节镜头连续和桌面及 244/314 px 窄模型区的完整几何投影边界。根集成人另行浏览器审看发现并推动修复土层支撑缺失、径向 UV 色斑及巨大阴影接收平面。配音、完整播放、实际播放器尺寸、资源失败与发布由根集成人负责；源码测试不能替代原生试听或真机性能测量。
