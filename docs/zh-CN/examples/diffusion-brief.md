## 核心现象与独立构图

用静止、封闭的浓度带替代对流的流动玻璃格。画面**没有粒子、预设路线或整体流速**：深蓝背景上一条纤细玻璃带承载计算浓度，下方对应曲线让峰值降低、面积守恒直接可见。颜色段均值、截面梯度、带符号通量、选区总量与方差历史都来自独立解析模型。

八章各有对应仪器：初态虚线；固定截面与切线；带两个通量读数的选区；有限域方差历史；D 对照；真实不等长的带；两种守恒标记；最后为理想储库端点。蓝/暖色曲线与深色玻璃边缘，和暖色对流器物保持区别。封面为可选 color 的完整 400 × 230 SVG，使用同一模型，没有外部资产。

手机按实际宽度重新构造 SVG 坐标，文字 16px，曲线图区单独取 150px 高。比较章只放两条薄浓度带和**一张共用曲线图**，不堆两套完整面板。长度比保持 2:1。共用 Showcase 展示当前字幕，观看模式没有重复的大段顶部说明，只保留本章边界、标尺、符号的必要注记。

## 模型与边界

截面积取 1，横截面内浓度均匀，介质静止，D 恒定且非负，无内部物质源或反应。方程为 `J = −D cₓ`、`cₜ = −Jₓ = D cₓₓ`。

封闭初态是 `(M/L)(128/35) sin⁸(πx/L)`，恰好由常量 M/L 及 n=2、4、6、8 四个余弦模态组成，系数为 `(M/L)[−1.6, 0.8, −8/35, 1/35]`。每项乘 `exp[−D(nπ/L)²t]`。这是作者明确初态的精确有限模态解，不是截断方波或数值时间步积分。两端 `cₓ = J = 0`。

总量、选区量、一二阶矩和非均匀程度由解析积分得到。对称脉冲的方差满足 `dσ²/dt = 2D − DL[c(0)+c(L)]/M`，趋于 `L²/12`；无限域的 2Dt 增加只作早期参照。浓度起伏平方积分按扩散耗散率降低，不表示分子变慢或停止，也没有模拟微观时间反演。

混合初态为 `(1 ± 0.95 cos(πx/L))/L`，两种不反应的稀标记使用同一个 D。各自总量为 1，总浓度在每个位置、每个时刻都为 2/L。不求解真实多组分液体的交叉扩散、体积改变或浓度依赖物性。

储库章明确重新从 `1 − x/L − 0.2 sin(πx/L)` 开始，端点固定为 1 和 0。正弦项以 `D(π/L)²` 衰减，线性基态保留。两端累计通量解析积分与变化的内部总量闭合，稳态通量为 D/L。这不是声称与封闭脉冲同初态的对照。给这个固定浓度问题指定非默认总量会被拒绝，因为库存由浓度条件确定。

默认 D=0.015、L=1、M=1。模型支持 D 0–0.1、L 0.5–2、封闭 M 0.1–2、时间 0–120；手动时间 0–40、D 0–0.04。两倍比较在支持范围内，长度明确最多为 2。负时间、反向积分区间、越界位置/参数及不适用的第二物种会被拒绝。显示负零归零，解析浓度不裁剪来假装守恒；颜色映射仅容忍精确零处的浮点舍入负值。

颜色带采用精确区间均值，吸收配色为作者示意，不是真实染料光谱。箭头**仅示方向**，数值给出通量大小，不把净通量当作粒子或流体速度。不包含平流、Brownian 路径、膜、电场、反应或非 Fick 型扩散。
