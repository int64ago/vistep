# 二维码：一个字节，找到自己的位置

[English](../../examples/qr-code-brief.md)

跟住 `https://vistep.ai` 中 `v` 的一位，走完真正可扫描的 QR 编码。要改变的直觉是“黑格一定来自原始的一”：同一位原本为 1，经过可逆掩码后却印成白格。字节、位流、码字与模块坐标始终有明确身份。

## 视觉与导演

暖白纸面、精确黑白模块、低饱和海绿色文字与一处金色追踪框。开场先放大字母 v，再让纸面依次成为位流、真实多项式余数、功能预留图、折返放置路径与干净成品。没有机柜、工位或装饰性数据纹理；每个模块都由模型计算。

| 开始   | 章节     | 可见因果变化                                                        |
| ------ | -------- | ------------------------------------------------------------------- |
| 0 秒   | 跟住 v   | 字节 118 展开为 01110110，锁定左起第二位 b6。                       |
| 22 秒  | 读法说明 | 加入模式、长度、消息与终止位；用短消息展示真实 EC/11 填充。         |
| 44 秒  | RS 校验  | 逐个处理 19 个数据码字，七个前缀余数最终变成 D2 B9 37 2B E9 51 39。 |
| 66 秒  | 预留结构 | 先定位与隔离，再时序，再格式，留下 208 个位置。                     |
| 88 秒  | 折返放置 | 两列一组向上向下；同一位到达 (13, 11)，随后填完 208 位。            |
| 110 秒 | 比较掩码 | 遍历八种真实候选及评分，最后停在编号 3，保留追踪位异或。            |
| 132 秒 | 格式信息 | 显示 L/掩码、BCH 余数及 0x789D，依次描出两份格式信息。              |
| 154 秒 | 扫描成品 | 先还原原始位；章节进度 38% 后退出高亮，保持完整真实二维码。         |

初始故事板为八章各 22 秒，共 **176 秒**；语音起点为章节起点加 0.45 秒。中英文分别创作自然讲述。交接时冻结双语脚本、字幕、章节数量/顺序与时间点。

手机按章选择视觉重点：去掉重复章标题；位流章隐藏次要码字条；RS 章省略长多项式；掩码章隐藏次要评分分解，保留八个总分与当前位值。计算保持不变。矩阵保留静区，不依靠缩小 SVG 文字。在真实 20px 页面边距的 320px 视口中，双语每章采样主舞台均为 **820px**，后续播放操作位置稳定；正文最小 16px。

## 科学与实现边界

- QR Code Model 2、Version 1-L、单一字节消息段。ASCII 支持 1–17 字节，不加 ECI；非 ASCII 使用 UTF-8 与 ECI 26，最多 16 字节。拒绝空输入和不成对代理项。不实现其他版本/等级、模式优化或多消息段。
- 默认网址：4 位模式 + 8 位字节数 + 136 位内容 + 4 位终止 = 152 位，即 19 数据码字。短消息对齐后交替补入十六进制 EC/11。默认头部 12 位，因此原始字节与码字编号不可混用。
- GF(256) 约化多项式 0x11D，α = 2，RS 生成根 α⁰ 至 α⁶。单块为 19 数据 + 7 校验码字；长除法与逐前缀余数均真实计算。
- 233 个功能格、208 个唯一放置位置。第一版无校正图形和单独版本信息区。两份十五位格式信息采用 BCH 多项式 0x537，最后异或 0x5412。数据掩码不改功能格。
- 八种掩码在各自完整格式信息已写入后评分，包含连串、方块、带白色上下文的完整仿定位比例纹、明暗比例。同分选编号较小者。网址选择掩码 3，评分 1087。
- 第九个字节的 b6 对应位流索引 77、码字索引 9（从零计）、坐标 (13, 11)。原始 1 ⊕ 掩码 1 = 印出 0；坐标不包括静区。
- 不实现受损码解码器、污损实验、标志遮挡恢复，也不把面积换算为纠错保证。正文解释七个校验码字在正确取得码字/块结构前提下可纠正至多三个未知位置错误码字；定位、采样与格式读取另有要求。格式 BCH 与数据 RS 为不同保护层。

`qrShot(chapter, progress)` 直接从共享导演重建每个状态，不使用私有时钟、随机数或帧历史。暂停拖动直接落到目标图案。码字颜色仅在播放时柔和过渡，减少动态模式禁用过渡。共享 Showcase 负责离屏/后台暂停、重播、拖动与配音。本专题不分配 WebGL、音频、Worker、计时器或对象 URL；SVG 就是默认二维呈现。

自由探索真实重算输入与掩码，追踪可选字节/位，展开码字并下载无高亮 SVG。错误输入移除旧矩阵。完整重置恢复网址、自动掩码、字节索引 8、位索引 1、追踪关闭。所有输入和选择框有稳定显式翻译标签；没有本专题 range。按钮支持空格操作，原生选择框支持键入匹配。
