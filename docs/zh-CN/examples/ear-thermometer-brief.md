# 耳温枪——接收辐射，再解释视场

[English](../../examples/ear-thermometer-brief.md) · [制作指南](../creating-a-scene.md)

起点误解是耳温枪向耳内发射什么。追踪对象是组织自己发出的热红外；转折保持全部组织温度不变，只转动同一探头，真实第一交点从鼓膜移到耳道壁，混合辐亮度和反演读数随之变化。本片不提供诊断或治疗建议。

独立美术采用精绘解剖与器物切面：温暖耳廓、折痕、耳道壁厚、倾斜鼓膜和少量听小骨参照；浅色探头保留红外窗口、金属窄口通道、吸收膜、封装、交替材料串联热电偶、两根信号线和独立双引线温度参考，线路实际接到放大/ADC。接收路径没有被激光或装饰箭头替代。

## 一手依据与取舍

- [Braun 器物说明](https://www.braunhealthcare.com/us_en/thermometer/thermoscan-5/)：接收来源包括鼓膜及周围组织；不照搬商品精度、临床换算或预热参数。
- [Analog Devices 工程说明](https://www.analog.com/en/resources/technical-articles/important-design-considerations-for-digital-thermometers.html)、[Hamamatsu 热电堆技术说明](https://www.hamamatsu.com/content/dam/hamamatsu-photonics/sites/documents/99_SALES_LIBRARY/ssd/thermopile_kird9005e.pdf)：吸收膜、串联热电偶、小电信号及封装参考。
- [Melexis 热扰动说明](https://www.melexis.com/en/news/tech-talks/eliminating-thermal-disturbances-in-non-contact-temperature-measurement)：吸收膜与封装温度、稳态边界；不把某款芯片的波段/FOV冒充本片参数。
- [US6435711B1](https://patents.google.com/patent/US6435711B1/en)：耳用限孔探头、红外窗口、冷端热敏电阻和双输入换算；本片跟踪中空通道的窄口直达路径，未复刻该专利或仿真多次反射波导。
- [NIST 辐射温度校准资料](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication250-43.pdf)：普朗克谱辐亮度及单位；矩形 8–14 μm 响应明确属于教学选择。
- [Yeoh 等，2017](https://doi.org/10.1371/journal.pone.0174120)：鼓膜附近温度不均匀、取样位置影响读数；未复制其临床数值，也未把模型读数等同核心体温。

## 同一几何与辐射模型

毫米坐标包含分段线性上下耳壁、倾斜鼓膜及 (4,0) 探头转轴。0.65 mm 半径接收口距离所追踪的吸收膜中心 5 mm，直达半角为 `atan(0.65/5)`，约 7.41°。61 个二维方向使用归一余弦/梯形角权重。计算从接收口反向求第一组织交点，显示顺序却始终为组织→窗口→吸收膜。路径共线，确实在通道内，共用真实端点。外壳、通道、封装、ADC、接线与编号指向坐标在主切面、近看和封面间共享。

普朗克带内辐亮度使用 SI 常数及 96 段 Simpson 积分；先混合辐亮度，再反演，而非算术平均摄氏温度。示例净电压为 `G[L视场−L带(T封装)]`，教学增益 `0.075 mV/(W·m⁻²·sr⁻¹)`。加入同一参考辐亮度并单调反演得到读数。UI信号份额是各区域真正的加权辐亮度贡献；几何取样权重另外保留。黑体 34/37/40°C 参考点展示已知模型响应，不声称拟合出商用校准算法。

默认鼓膜37°C，壁温从入口32°C线性上升到26mm处36.3°C，封装22°C。0°时鼓膜角权重99.17%，等效读数四舍五入37.0°C；20°时鼓膜权重为0，读数约34.6°C。这些都是人为选择的示例输入。同温边界下，无论命中哪里，转动探头不改变读数。

未求解三维角响应、多次反射、发射率变化、套膜透射变化、热梯度/热冲击、组织冷却、耳垢、吸收膜瞬态和个体解剖。真实FOV常表示灵敏度衰减而非硬边界。微观热电偶被放大，红外标记慢速仅为追踪。本模型未经临床校准。

## 七章，计划168秒

| 开始  | 可见因果                                              | 桌面与手机保持的指代                                              |
| ----- | ----------------------------------------------------- | ----------------------------------------------------------------- |
| 0秒   | 组织源点发出暖色脉冲，标记向内接收；探头逐渐显明。    | 完整耳/探头，无视场填色；辐射从组织出发。                         |
| 24秒  | 窄口接受区域逐渐显出，出现组织信号份额。              | 完整剖面、信号图例和一个等效读数。                                |
| 48秒  | 路径经窗口/通道到膜，串联热电偶与ADC可近看。          | 上方保留完整缩略剖面；放大切面上的CSS16px编号与标签共用真实坐标。 |
| 72秒  | 参考22→30°C，净信号缩小、参考通道上升，补偿读数保持。 | 缩略耳道、吸收膜及两条通道同时保留，不因手机排版丢输入。          |
| 96秒  | 同探头接收34→40°C已知黑体，当前点沿响应曲线推进。     | 桌面并列腔体/曲线，手机上下重排；理想响应与参考温度说明保留。     |
| 120秒 | 探头0→20°，组织温度固定，交点移到更冷壁面。           | 完整切面、原颜色身份、重算的份额与读数。                          |
| 144秒 | 探头回到原朝向，连接几何、接收、参考与单个等效温度。  | 完整切面，末帧37.0°C，组织身份始终存在。                          |

中英脚本分别创作，使用稳定对象名称，避免“右边”等桌面专用指代。168秒是计划窗口，还不是录音实测时长。root先接收静音画面，再统一生成录音。

## 展示与证据

本篇原生SVG是主媒介，不分配WebGL、外部位图、Worker或私有动画时钟。`useShowcase`决定每帧进度，标记相位只来自同一章进度；共享播放器管理离屏、背景、减少动态与旁白。本篇无需把WebGL失败伪称自己的fallback，也不声称能力门禁拒绝的浏览器可以运行实验。

桌面/手机重新安排解剖与近看高度、校准双列/单列、标签位置。正文与编号是实际CSS16px，主要控件至少44px；短leader接到同源部件坐标。近看有意裁切机壳后部，完整耳/探头仍在缩略图中。CSS声明不能代替root实看320/390px整播放器与最长英文字幕。

手机近看保留102px完整耳道缩略图。参考章只标注吸收膜/参考的3/2号，通道标题保留匹配编号，省略重复四标签行；热电堆章仍保留旁白说到的全部编号。额外解释段只在探索展开，减少重复且不缩16px文字。两条因果通道都在，整播放器实际高度仍待浏览器测量。

作者定向测试覆盖4000步独立中点积分、有限波段与全谱区别、单调反演、真实组织交点、通道准入/共线、朝向混合、参考不变性、辐亮度混合边界、极端输入与倒退seek。真实组件测试操作实际控件，验证同温、双参考通道及memoization。此类证据不等同浏览器或听审。

独立peer `esim_scene`查588种同温组合/35,868条路径：同温恢复误差≤1.05×10⁻¹¹°C，权重和误差≤6.67×10⁻¹⁶，参考变化不漂；独立384段Simpson相对96段差≤1.03×10⁻⁷ W·m⁻²·sr⁻¹。未发现科学P1/P2；它建议的director有限输入校验已加。

后续几何审查发现黑体图一处P2：入口错误使用6/11系数，直达路径发生折弯。现由`earCalibrationPath`按真实5mm通道、共享源点与吸收膜坐标推导，已补共线/口径回归。peer在2026-10-05 23:21复核修复及全部七章双语脚本，无剩余P1/P2。作者最终两套共13项测试通过；peer另外8项独立测试分别记录。

当前开发机Node v24.19.0，预热后200次变化朝向/参考的模型调用平均0.293ms；这是Node模型计时，不是真机或浏览器性能。组件只依赖5个物理标量memoize，单独改变marker/reveal不再重算热模型，同温采样在一次调用内共用积分。

交接缺口：真实材质/手机/接触审看、完整自然速度观看、录音与原声听审、真实浏览器自动播放、真机性能、目录与社交封面及全局集成构建。root统一负责；worker未写共享登记、录音、提交或部署。
