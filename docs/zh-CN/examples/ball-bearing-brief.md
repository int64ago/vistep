# 滚珠轴承：跟随一颗球穿过承载接触

[English](../../examples/ball-bearing-brief.md)

## 因果线与美术方向

从“球只是跟着轴绕圈”的直觉出发，跟住带黑色标记的金色球。两条无滑动条件同时决定球心公转与球的反向自转，保持架跟随球心。接着让同一颗球穿过方向固定的承载区，区分球的运动与载荷方向。最后放大接触，说明理想滚动并不等于真实轴承零损耗。

主体是一只开式单列径向轴承，连接短轴、外壳、支脚和底座螺钉。冷色钢件、暖色保持架与深色观察背景构成近距离机械检查。前侧局部材料柔和隐去，后侧整条滚道仍然连通。滚道为圆弧，球为球面；冠形保持架的凹球面兜孔连接到背面的连续圆环。全部几何与封面原创，不复制制造商照片或 CAD，不依赖远程纹理。

宽屏把轴承与观察窗并置。手机分别排列模型与局部图，各自使用紧凑坐标，不缩小整页；对照图上下展开，手机在这一章用两张接触图替代重复的整机视图，文字和操作保持可读。探索直接控制绝对转角，不增加会偏离播放器的独立时钟。

## 模型及边界

节圆半径 `R = 1.75`，球半径 `a = 0.34`，内侧接触半径 `ri = R − a`，均为展示用长度单位。固定外圈且接触角为零时，外侧满足 `ωc R + ωb a = 0`，内侧满足 `ωc R − ωb a = ωi ri`。由此 `ωc/ωi = ri/(2R)`，`ωb/ωi = −ri/(2a)`。渲染使用固定支座参考系的自转；相对保持架的自转另为 `ωb − ωc`。

十颗球等距布置，兜孔共用同一保持架相位。滚道轴向沟曲率半径 0.36，大于球半径，在径向接触处相切。球与兜孔净间隙 0.025；兜孔避开径向承载接触，也避开滚道肩部。轴承外径、内孔与外壳、轴的安装面对应；重合安装面的深度偏置只解决显示闪烁，不改模型位置。结构为教学简化，不是某款 SKF 轴承的工程图。

整体运动采用刚性球、零径向游隙、零接触角和理想无滑动。保持架为简化球引导冠形结构，主装配未安装密封。承载亮度取 `max(0, cos θ)^(3/2)`，明确标注为教学权重，不是求解弹性位移、游隙和力平衡得到的实际力。接触斑与润滑膜是夸大的定性局部图，不反馈为整体模型的尺寸变化。不提供摩擦系数、效率、温升、寿命和额定载荷；不把纯弹性形变本身当作损耗。
