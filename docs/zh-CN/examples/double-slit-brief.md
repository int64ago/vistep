# 双缝干涉

[English](../../examples/double-slit-brief.md)

## 主问题与因果主线

多开一道缝，为什么有些地方反而更暗？跟住屏幕上的同一个点，从光程差追到电场相位，再把两路电场相加并取合成振幅的模平方。分清主要由缝间距决定的细条纹，与每道缝自身宽度决定的衍射包络。最后按同一分布逐点累积探测结果，不绘制光子的确定轨迹。

## 画面方向

光学装置包含孔径截面、屏幕探针 P、发光屏带及其定量光强曲线。相位章用首尾相接的两支复振幅箭头代替光路视图；同一屏幕坐标与强度参考把各视图联系起来。两路描线用不同颜色区分贡献来源，实际采用相同光学波长与偏振。

桌面为装置与接收屏留出足够空间。窄屏按当前因果步骤安排探针、相位或图样，不把所有视图一起缩小。调参章始终保留毫米尺。只有探测章累积离散点，且点只出现在接收屏上。光路是几何示意，放慢的振荡用于帮助观察。

## 实测影片

中英文生成音轨实测均为 **168 秒**，共用七个 24 秒章节窗口。下表对照 `src/data/film-timeline.json`；时长测量不代表自然度试听已经通过。

| 实测窗口  | 章节                 | 可见的因果变化                                                        |
| --------- | -------------------- | --------------------------------------------------------------------- |
| 0–24 s    | 多一道缝，反而更暗   | 在同一 0–4 光强标尺下由单缝变双缝，选定的暗纹位置光强下降。           |
| 24–48 s   | 跟住屏幕上的一点     | P 依次经过光程差为 0、λ/2、λ 的位置。                                 |
| 48–72 s   | 先加电场，再算亮度   | 首尾相接的复振幅从同相变反相，合成振幅模平方对应光强。                |
| 72–96 s   | 两缝拉开，条纹变密   | d 从 180 增到 300 μm，a 保持 35 μm、λ 保持 550 nm。                   |
| 96–120 s  | 波长变长，条纹变疏   | λ 从 550 增到 650 nm，保留 d = 300 μm、a = 35 μm。                    |
| 120–144 s | 缝变宽，包络变窄     | a 从 35 增到 70 μm，保留 d = 300 μm、λ = 650 nm，并说明光强参考改变。 |
| 144–168 s | 一个点，一个点地积累 | 保留最终 300 μm / 650 nm / 70 μm 配置，累积同一分布的探测点。         |

调参章承接上一章的最终配置，使每次比较只改变一个物理输入。自由探索仍提供较宽的范围：d = 120–300 μm、λ = 450–650 nm、a = 20–70 μm。

默认 λ = 550 nm、d = 180 μm、a = 35 μm、L = 1 m。影片屏幕范围为 ±10 mm，探索探针限制在 ±8 mm。近轴条纹间隔约为 3.056 mm；第一干涉零点距中心约 1.528 mm。光程差为一个波长时，y ≈ 3.056 mm、I/I₀ ≈ 3.527；这是同相位置，不是受到包络调制后曲线的精确峰位。

## 模型与解释边界

本篇使用两道相同、均匀照明矩形缝的标量 Fraunhofer 模型：单色相干平面波正入射，两路偏振相同。

`θ = atan(y/L)`、`β = πa sinθ/λ`、`φ = 2πd sinθ/λ`、`I/I₀ = 4 sinc²β cos²(φ/2)`，其中 `sinc 0 = 1`。

`I₀` 是**当前缝宽下**单独开一道缝时的中央光强。打开第二道缝时参考不变，因此中央由 1 变为 4；改变缝宽时参考也改变，此章只比较归一化图样，不比较绝对透射功率。默认单缝包络的第一零点约在 ±15.716 mm，超出屏幕。a = 70 μm 时，550 nm 光的第一零点约在 ±7.857 mm；影片最终采用 650 nm，对应约 ±9.286 mm。细密的干涉项与宽广的包络相乘，不能只用其中一项替代整个图样。

相位使用远场光程差 d sinθ，不从示意路径量取精确长度差。模型忽略近场传播、有限缝高与厚度、材料边界和偏振耦合。以完整孔径跨距 D = d + a 计算，指定范围中最苛刻组合（d = 300 μm、a = 70 μm、λ = 450 nm、L = 1 m）给出 D²/(λL) ≈ 0.3042，轴上边缘被忽略相位约为 0.239 rad。这是近似诊断，不声称全范围误差都可忽略，也不沿用单缝专题另设的 0.1 显示护栏。

探测抽样用屏内各区间的强度除以整个显示窗口的强度积分，表示**已知探测落在该窗口内**的条件概率。选定的点数不代表发射亮度或透过率。对保持相干、没有可区分哪路信息且探测效率均匀的理想单光子条件，同一空间光强图样给出归一化探测概率。本篇不模拟光子轨迹、哪路测量、探测器噪声或量子态坍缩；点阵是模拟抽样，不是实验记录。
