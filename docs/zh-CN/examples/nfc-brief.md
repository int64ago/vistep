# NFC：没有电池，也能回答

[English](../../examples/nfc-brief.md)

## 问题与范围

没有电池，标签怎么回话？跟随同一只被动标签线圈，从取得能量走到读卡器检出回应。改变直觉的关键是：读卡器持续提供载波，标签通过切换负载就能送出信息。能量方向与数据方向必须分别解释。

范围是读写模式下的被动 NFC 标签，信号采用 NFC-A 约 106 kbit/s 的编码片段。本篇不是完整协议交换、手机卡模拟、天线设计工具或支付演示。建议从 12 岁开始观看：主片只需要变化磁场与二进制信号的直觉，电路方程按需展开。

## 原创视觉方向

读卡器表面与薄标签构成开场。逐渐露出标签的铜螺旋、两个芯片连接端以及相应的读卡线圈。感应、供电和负载开关近看始终保留同一个标签的身份。转折进入电路：标签上的开关改变读卡器测到的电流，不另造一个载波源。最终信号视图跟住同一串 `10110010`，从标签开关走到读卡电流，再走到检出的比特。

桌面给器物与当前仪器足够空间；手机优先呈现本章的因果仪器，同时保留线圈或芯片的身份及一句短解释，不把桌面面板缩小后全部堆叠。旁白只说读卡器、标签、开关、信号等器物名称，不依赖左右位置。主场景、运行时后备图和封面都需要保留线圈连接；实际画面由集成者另行审看。

## 共享影片窗口

两条已合成语言音轨均实测 **168 秒**，采用七个共享的 24 秒章节窗口。场景时长以 `src/data/film-timeline.json` 为准；时长测量不证明试听质量，[NFC 审看记录](../qa-nfc.md)将两类证据分开。

| 共享窗口   | 章节                   | 新的可见观察                                                       |
| ---------- | ---------------------- | ------------------------------------------------------------------ |
| 0–24 秒    | 没有电池，也能回应     | 间隙由 60 降至 8 mm，同一个标签获得足够供电，随后露出内部线圈。    |
| 24–48 秒   | 变化的磁通，感应出电压 | 跟踪穿过标签线圈的交变磁场与对应交流电压，说明载波已经慢放。       |
| 48–72 秒   | 把交流变成芯片电源     | 理想全波整流统一极性，储能电容在峰值之间缓冲输出。                 |
| 72–96 秒   | 读卡器把问题放进包络   | 一小段 Modified Miller 编码安排载波空窗，标签观察包络变化。        |
| 96–120 秒  | 切换负载，就是回答     | 几何与载波不变，接入、断开标签额外电阻，对照读卡电流变化。         |
| 120–144 秒 | 跟住同一串比特         | Manchester 门控的子载波突发控制负载，对应电流变化还原 `10110010`。 |
| 144–168 秒 | 为什么要靠近、对准     | 先增大间隙再恢复，然后倾转标签再恢复，分别观察供电与读回条件。     |

第七章先保持两线圈平行，间隙从 8 增到 60 mm，再回到 8 mm；然后保持标签**最低点净空** 8 mm，倾角从 0° 增到 80° 后恢复。倾转时中心抬升以避免接触，所以第二次比较同时改变朝向与中心间距。不能将其描述为中心固定的旋转，也不能用一条余弦定律概括所有近距离 NFC 布局。

末章内部，间隙在 0.96–4.80 秒增大、7.44–10.08 秒复原；倾角在 10.56–13.44 秒增大、15.36–18.00 秒复原，最后六秒保持恢复后的状态，留给收束说明。对应章节进度分别是 0.04–0.20／0.31–0.42 和 0.44–0.56／0.64–0.75。这是画面时序，不代表录音已经逐词对齐。

## 几何、电路与数值约定

器物的读卡螺旋为三匝，标签为四匝。互感计算分别用平均半径 24 mm 和 16 mm 的等半径多匝圆环等效，按变换后的几何进行 Neumann 积分，再乘匝数。它忽略螺旋节距、引线磁场、铜层高度、导线厚度、铁氧体、金属与电场耦合。

标签实体半宽 22 mm、半厚 0.5 mm，中心相对读卡平面的高度为 `间隙 + 22 mm·sin(倾角) + 0.5 mm·cos(倾角)`。手动范围是 4–60 mm 最低点净空与 0–80° 倾角，默认 8 mm、0°。

电路按 13.56 MHz 的有效值相量求解。读卡端串联调谐，标签线圈连接并联调谐电容、2 kΩ 的芯片射频等效负载，以及可切换的 2.5 kΩ 电阻。读卡／标签电感分别为 1.4／1.7 μH，电阻为 15／2 Ω，源电压为 1 V RMS，未加载调谐电容由 `C = 1/(ω²L)` 得出。它求解耦合电路，不另设任意的信号强弱曲线。标签完整闭合支路阻抗为 `Z₂` 时，反射阻抗为 `(ωM)²/Z₂`。输入功率与读卡损耗、标签线圈损耗及两个电阻的耗散对应。

芯片直流功率**假定**为 2 kΩ 等效电阻射频耗散的 45%。两种负载状态都必须达到教学门槛 0.6 mW，而且读卡器两种有效值电流之差的绝对值必须达到 0.15 mA。这些是教学选择，不是芯片规格或认证指标。默认几何下，额外负载断开／接入的直流功率约为 5.696／3.734 mW，读卡电流差为 8.176 mA。接入额外负载会使读卡电流从约 23.120 增到 31.296 mA，同时让芯片支路的可用功率**下降**，两者不能默认同向变化。平行间隙 60 mm 时，直流功率约为 0.134／0.048 mW，电流差为 0.142 mA；8 mm 净空、80° 倾角时约为 0.161／0.058 mW 与 0.171 mA：即使假定切换得到的信号幅度足够，标签也未必有电执行切换。

标签从 8 移至 15 mm 时，断开额外负载的直流功率会因匹配关系先稍微增加。因此影片可以说耦合减弱、拉远后通信失败，不能声称画面所有电学量都随距离单调下降。

供电近看是**独立的理想教学模型**，不是芯片非线性供电计算。它采用归一化正弦、绝对值全波整流及理想峰值充电电容；电容在峰值之间指数放电。省略二极管压降、源内阻和非线性芯片电流。读卡器真实 ASK 空窗中的储能过程没有与射频链路联合积分。

## 编码与检出

载波为 13.56 MHz。位速率为 `fc/128 = 105937.5 bit/s`，惯称 106 kbit/s；子载波为 `fc/16 = 847.5 kHz`。一位持续约 9.4395 μs，容纳八个子载波周期。回应中的 1 在前半位门控四个周期，0 在后半位门控四个周期，负载开关本身按子载波速度振荡。

读卡器片段采用理想 Modified Miller 空窗：1 在中部暂停，紧接 0 的 0 在开头暂停，紧接 1 的 0 不暂停。四分之一位宽的理想空窗用于展现编码关系，省略实际边沿形状。`10110010` 按画面时间顺序发送，不冒充完整指令或 NDEF 字节。

回传电流曲线取实际求得的两种有效值，以固定的 **10 mA 满量程**绘制，不同几何保持同一放大倍数。独立检出器在已知位时序下比较前后半位的波动，缺失或模糊的符号保持未解码。模型确定、无噪声、采用准静态包络，不求解谐振器建立与衰减、边带传递、接收同步、自动增益、CRC、奇偶校验、帧、选择、抗碰撞或身份认证。读到数据本身不等于验证身份或完成支付。
