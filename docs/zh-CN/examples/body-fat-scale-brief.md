# 体脂秤——先测信号，再作估计

[English](../../examples/body-fat-scale-brief.md) · [制作流程](../creating-a-scene.md)

最初的直觉是“秤看见了脂肪”。全片跟踪同一个虚拟对象、同四片电极和同一次电流/电压测量。转折只改变已经分布于组织的水分，固定真实脂肪质量和干瘦组织，估计脂肪质量仍然移动。总重和真实脂肪百分比的分母也会改变。专题不提供个人测量、诊断或健康处理建议。

视觉从可观察的玻璃秤和赤足出发，分开两条实体链。四角金属框、测力梁、粘接应变片和接触玻璃的支柱承担重量；独立 PCB 上的交流源、电压采样器和实际引脚承担电学测量。暖色电流经前脚电极、腿与下躯干闭合回到交流源；蓝色导线从两个脚跟电极终止于高输入阻抗采样器。后半片分别使用配对波形、组织等效电路、逐步估计链和两组成分质量带，不套用同一舞台加滑块的形式。

## 一手依据与选择边界

- [TI AFE4300](https://www.ti.com/lit/ds/symlink/afe4300.pdf)明确称重与身体组成两条测量链；[SBAA290](https://www.ti.com/document-viewer/lit/html/SBAA290)说明应变与电阻桥原理。没有复制某款秤的刚度或校准。
- [TI SBAA562](https://www.ti.com/document-viewer/lit/html/SBAA562)、[Analog Devices 四线测量原理](https://www.analog.com/en/resources/technical-articles/jack-of-all-trades-in-impedance-measurement.html)及[MAX30009](https://www.analog.com/en/products/max30009.html)支持电流注入与高输入阻抗电压采样分开。四线减少接触影响，不宣称影响完全消失。
- [Analog Devices 的等效 RC 与 I/Q 说明](https://www.analog.com/en/resources/analog-dialogue/articles/adopting-a-better-bioimpedance-afe.html)支持外液电阻，与膜电容和内液电阻串联支路并联。复阻抗相位为负；界面显示正的电压滞后量及负电抗。
- [Lukaski 等 1985 年原始研究](https://pubmed.ncbi.nlm.nih.gov/3984933/)对象为特定成年男性样本。只借用身高平方/电阻的教学关系形式，不移植其群体系数，更不把某种四电极布局的验证当作脚到脚秤的通用精度。
- [Wang、Deurenberg 与 Heymsfield 2000 年研究](https://pubmed.ncbi.nlm.nih.gov/10865761/)讨论去脂体重水化比例约 0.73 及变化。本模型公开固定此假设，不说人人、每刻恒定。
- [Tanita 饮水说明](https://support.tanita.eu/support/solutions/articles/60000690203-how-will-drinking-water-affect-my-body-composition-readings-)区分刚进入胃的水与已分布组织的水。本片不预测饮水后的即时方向或幅度。

## 模型、单位与真实接触

参考对象身高 1.70 m，水分 40.15 L、干瘦组织 14.85 kg、脂肪 15 kg，总重 70 kg；水按约 1 kg/L 换成质量。等效参数为 Rₑ=750 Ω、Rᵢ=1000 Ω、Cₘ=8 nF，两条电阻按参考水量/当前水量缩放，电容固定。独立计算 `Rₑ || (Rᵢ + 1/jωCₘ)`。没有求解异质人体电流密度、电解质浓度变化、温度或组织重建。

50 kHz 参考电阻 444.37 Ω，电抗 −69.49 Ω，阻抗大小 449.77 Ω，相位 −8.89°。250 μA RMS 教学交流源对应 112.44 mV RMS 电压；这不是安全电路制作参数。两周期波形共享时间，各自有标明的量程；探索频率使电压增加时，量程相应扩展。

教学 `k = 40.15 × R参考 / 1.70²`仅匹配此虚拟对象。50 kHz 下，`水分=k h²/R`、`去脂体重=水分/0.73`、`脂肪=总重−去脂体重`。没有人群标定，不能测定个人脂肪。其他频率只显示电学响应；电流接触断开时，测得阻抗和脂肪估计均不可用，但体重仍可显示。去脂体重包含水与干组织，不等于肌肉。

四角反力同时平衡重力和一阶力矩，抬右脚只改变压力中心，不改变质量。称重章另作零至完整重力的加载演示，没有偷偷改水分或体重。应变等于力×3 微应变/N，应变系数 2、电桥激励 1.7 V；近看应变长度放大 1000 倍。两种桥臂电阻与差分输出都由同一载荷求值。玻璃、支柱、梁和接地框保持接触，透明检查没有让载荷悬空。

实体以 10 cm 示意单位建模，共用圆角部件、足部椭球、电极、PCB 端口和导线折线。脚趾与脚跟切点接触相应金属片，引脚进入真实封装。电流最后闭合段位于交流源内部。亮点采用 `fraction−0.016 cos(2π phase)`，沿路径的速度符号与 `I(t)∝sin(2π phase)`共同反转；它们是放慢的信号标记，不是求得的电荷轨迹或传播速度。

## 生命周期、二维状态与证据

`useShowcase`提供唯一演示时钟，每章直接从进度重构，暂停跳转使镜头到达同一状态。共享 Studio 管理离屏、后台、减少动态、WebGL 资源和二维切换。探索初入视图拟合一次，此后输入变化保留用户 Orbit 角度。没有私有计时器、RAF、Worker 或图片请求。运行时渲染器/环境失败进入原生二维等效图，使用同电极端点、显现进度、交流相位和接触状态；不把它混同于站点更早的能力拒绝页面。

SVG 逻辑高度与实际 CSS 高度一致，科学标签至少 16px；长文字用 HTML 换行，主要目标至少 44px。主线程在实际 320px 页面发现共享 Studio 的 180px 最小高度越过 110px 称重画框，专用 CSS 已覆盖此最小值。主线程仍实际测量最终双语完整播放器，并收短共享英文观看标签；不能用 CSS 声明替代实量。

作者三套 22 项检查覆盖独立复导纳、数值波形幅相恢复、总力/力矩、电桥输出、固定脂肪与百分比分母、输入/接触失效、反向跳转、真实装配接触/引脚、实体边界拟合、保留 Orbit、同状态二维图、实际控件与封面真实射线深度。普通 TypeScript 检查没有 owned 文件诊断；三条既有 Astro 导入声明错误由主线程 Astro-aware 检查承接。

`esim_scene`独立审核 672 科学状态：R/X 最大残差 1.71×10⁻¹³/5.69×10⁻¹⁴ Ω，力和力矩残差≤1.14×10⁻¹³；七章双语脚本和两篇文章无科学 P1/P2。`camera_scene`找到玻璃悬离支柱的问题，并复核交流相位、Orbit、接触和二维图修复。这些与作者检查分开记录。

原生封面共享箱体尺寸、引脚、足部和闭合回路。投影眼位确定实际 x−/z−/y+可见面；仅绘制封装外真实露出的引脚表面。PCB 下方平面先画，随后小实体面按视深排序，透明组织和路径为明确的等效教学层。作者通过 Resvg 单独查看 `/tmp/vistep-body-fat-scale-check/cover.png`：60 个路径，原生 SVG 约 18.6 kB。该检查不等于构建后的目录或社交封面检查。
