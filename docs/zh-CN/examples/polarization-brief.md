# 制作说明：偏振

[English](../../examples/polarization-brief.md) · [制作流程](../creating-a-scene.md)

**问题：** 在两片交叉偏振片之间增加一片吸收型偏振片，为什么输出反而变亮？

**追踪对象：** 沿同一条光路传播的电场。传播方向不变，横向电场依次投影到每片透光轴。观察上的转折是：最终输出从零增加，但沿实际的三片光路逐级看，每片后面的光强仍在下降。

## 视觉与手机构图

原创 SVG 空间光学装置包含圆形滤片平面、连续电场波线、迎光投影视图，以及位于同一中心轴末端的接收屏。深蓝底色衬托青色 A、紫色 M 与金色 B；没有装饰光路、悬空器件或伪光子轨迹。

桌面横向展开光路，下方对照电场投影。绘图宽度小于 620px 时重新构成纵向光路，横截面带有斜向投影，使末段电场不会与传播箭头重合。SVG 使用实际测量宽度，标签为 16 CSS px。760px 以下视口的曲线章节使用整行曲线，其他章节保留圆形横截面与公式；不是缩小桌面大图。

## 八章因果演示

集成包计划 **176 秒，8 章，每章 22 秒**。父任务合成并实测两种语言的声音后决定共享时间轴；模型采用章节相对进度，窗口调整不会破坏角度运动。

| 章节                     | 画面变化与观察                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------- |
| 1 · 光去哪里，场朝哪里   | 线偏振波沿中心轴传播，标记横向电场，用迎光视图区分传播方向与振动方向。              |
| 2 · 没有优先的方向       | 换成非偏振示意信号。变化的电场与时间统计圆图区别固定线偏振轴、规则圆偏振。          |
| 3 · 第一片，留下半束     | 放入 A，透光轴从 0° 转到 90° 再返回；输出轴跟着转，平均强度保持 50%。               |
| 4 · 投影，要取平方       | 放入与 A 平行的 B，再转至 60°。横截面投影缩短，马吕斯曲线把振幅与光强区分开。       |
| 5 · 交叉，投影归零       | B 从 60° 转到 90°。末片后的电场消失，而到达它之前仍有光。                           |
| 6 · 在中间，改变方向     | M 初始平行 A，出现后转到 45°。外片保持交叉，三级输出依次为 50%、25%、12.5%。        |
| 7 · 光变亮，能量没有增加 | 固定三片配置，依次突出 A、M、B 的吸收和最终透过，四个份额组成同一份入射能量。       |
| 8 · 找到透光的角度       | M 从 45° 到 0°，经过 90°，返回 45°。`⅛ sin²(2β)` 曲线连接两个黑暗端点和中间最大值。 |

共享播放器提供当前一句静音说明、暂停、重播、章节、拖动时间轴、配音和探索入口。探索提供键盘／指针圆环调角、A/M/B 选择、M/B 放入开关、两个实验预设，以及非偏振／0° 线偏振入射切换。交互全部改变真实模型状态。

## 独立模型与科学边界

`src/models/polarization.ts` 以 x 为传播方向，y、z 为横向电场分量。非偏振输入使用相干矩阵 `C = I₀/2 · 单位矩阵`；线偏振使用 `I₀ uuᵀ`。理想透光轴的投影为 `P = uuᵀ`，经过滤片后的矩阵是 `P C P`，迹给出光强。每片前后之差计入吸收。模型拒绝非有限数值、负强度和位置顺序不正确的滤片。

示意非偏振场在两个横向方向分别采用 3、5 次和 4、7 次谐波：一个公共周期内均方值相等，互相关为零。滤片之后的波线逐级投影同一个信号；测试独立积分波形均方值，与矩阵模型比较。它是确定性的教学表达，不是随机微观光源，也不是光子计数模型。

圆图固定箭头显示均方根振幅，线偏振投影保留正负号。接收屏亮度采用平方根映射，光强数字和能量条保持线性。假定正入射、均匀介质、滤片完全覆盖且理想吸收；省略磁场、分子微观结构、表面反射、散射、衍射、漏光和额外损耗。章节更换配置不模拟横向插片时的部分遮盖；正文明确说明这些边界。

2026-09-05 查阅的主要技术资料：

- [Feynman Lectures I，33–4：Polarizers](https://www.feynmanlectures.caltech.edu/I_33.html)：电场投影、光强平方、吸收，以及三片偏振片的反直觉结果。
- [OpenStax University Physics III，1.7：Polarization](https://openstax.org/books/university-physics-volume-3/pages/1-7-polarization)：横向偏振、非偏振时间平均、理想滤片与马吕斯定律。

原创 400×230 封面直接使用独立模型的轴、波形与 50%／25%／12.5% 数值，接受可选 `color` 参数，输出自包含 SVG。没有复制第三方图像，也没有新增外部资产依赖。

## 集成与生命周期

临时集成交付包仅包含 `topic`、`component`、`cover`、`translations`、`narration`。专题编号由父任务分配；路径相对仓库根目录。界面、元数据、章节标题和字幕均有英文翻译，并保留既有共享译文，例如 `3 分钟` → `3 minutes`。

主组件 `Polarization.tsx` 使用专属 `PolarizationOptics.tsx` 和样式。两种语言正文都含 `understand`、`try`、`deeper` 锚点。共享登记、翻译合并、音频生成、生产／预览构建和发布由父任务处理。

本场景没有私有动画循环或音频元素。所有波形和章节参数来自 `useShowcase()`；暂停拖动立即重建，探索使用固定电场采样。唯一的 `ResizeObserver` 在卸载时释放。SVG 无需 WebGL、Worker、纹理或 GPU 清理路径。

- **集成包：** TypeScript AST 核对实际传入 `t()` 的 39 条文字与全部 62 条集成包译文；占位符一致、共享译文零冲突、路径契约和八个时间窗口全部通过。
