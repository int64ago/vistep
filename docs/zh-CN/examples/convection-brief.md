## 现象与构图

用一格温暖、安静的玻璃容器，区分「热在传递」和「流体把热搬走」。画面主体就是计算场：铜色暖板、蓝灰冷板包围宽高比 1.5 的完整流体区域，温度缓缓铺开，24 个身份不变的示踪点跟随实际速度移动。染料章强调其中一个亮点。没有预设圆形轨迹、装饰涡旋、假流线、外部图片或透视相机；板温、颜色、箭头、染料、点位和读数来自同一独立模型。

桌面比较章并列两格；320px 手机一次只呈现一格，在章节进度 0.52 切换对象，同时保留两项携热读数。不是把两套器物和图表向下堆叠。流体域保持真实宽高比，正文与标签至少 16px，方法细节折叠；探索模式另有手机切换按钮。

## 模型、边界与简化

计算无量纲二维 Boussinesq 涡量和温度，密度变化只保留在浮力项。y 向上，`ω = ∂v/∂x − ∂u/∂y`，`u = ∂ψ/∂y`，`v = −∂ψ/∂x`：

- `ωₜ + u · ∇ω = ν∇²ω + B ∂T/∂x`。
- `−∇²ψ = ω`，由可分离离散正弦变换求解。
- `Tₜ + u · ∇T = κ∇²T`。
- 染料作为被动标量随同一速度输运并扩散，所有壁面无染料通量。

四壁均不穿透且**自由滑移**，壁面流函数和涡量为零。玻璃外观为示意，明确区别于真实玻璃的无滑移边界。侧壁绝热，上下板恒温，扩散通量采用半个单元的板间距离，不包含板自身热容量。默认宽/高为 1.5/1，`B = 1`、`ν = 0.02`、`κ = 0.01`，染料扩散系数 0.0005。它们是作者指定的无量纲参数，不冒充水的物性、摄氏度、瓦数或真实秒数。

初态默认为线性导热温度层加 `−0.02 cos(2πx/1.5) sin(πy)`；没有随机种子。开场改用均匀 0.5、零扰动。完美横向对称时模型保持静止，不能据此声称真实实验没有环境扰动。

面速度由同一流函数的离散旋度导出，单元散度代数抵消。温度和染料采用保守面通量、一阶迎风输运、显式中心扩散；涡量也采用迎风输运。明确说明**数值扩散与额外动量耗散**，不将它们等同于设定的黏性。稳定性检查遇到不安全状态直接停止，不通过裁剪温度/染料掩盖不稳定。

示踪点以中点法积分，速度来自双线性流函数的导数。跨网格面法向速度连续，但切向插值可能跳变，所以除了单元内部局部速度检查，还独立检查跨面轨迹的时间步加密，而不错误要求每次过面都有光滑导数。

存储热量变化与累计板通量闭合，染料总量守恒。显示的携热通量使用与热量更新相同的迎风面温度，向上为正，显式传导另保留符号。染料透明度仅为可见性放大八倍并饱和，账本使用原始浓度。Canvas 插值计算温度颜色，网格章和 SVG 备用视图显露实际单元。模型不测临界 Rayleigh 数，不预测真实三维湍流、沸腾、相变、自由表面或完整物性变化。

## 确定性、探索与资源

`ConvectionRun` 固定初态和每组配置的时间步，检查点有界，可以精确重建向前、向后和重播后的状态。章节映射是纯函数，没有渲染器自己的时间轴或依赖上一帧的随机动画。专用 Worker 求解并忽略过期回复，Worker 失败时由可取消的主线程小批次计算同一个模型。卸载时终止 Worker、清空计时器/检查点并断开 Canvas 的 ResizeObserver。离屏、后台、减少动态效果由既有播放器管理，场景没有绕过它的独立动画循环。

四条滑块都提供明确翻译后的无障碍名称和 44px 目标。完整重置包括：下方加热、B 1、ν 0.02、扰动 0.02、时间零、温度视图、比较关闭、手机显示基准格。Canvas 失败时以相同温度/染料和示踪坐标绘制 SVG。本组件不自行创建音频元素。

## 证据及尚未验证的范围

定向 Vitest 共 **17 项**：制造解的离散 Poisson 方程；不穿透壁面与离散无散；精确导热静止解；均温层扩散；下热增长/上热衰减；对流携热与传导区分；非零热量变化账本及染料守恒；较强驱动下标量有界/CFL；示踪身份、封闭域和局部速度；跨网格面轨迹时间步加密；解析热扩散空间收敛；细网格定性一致性；动能耗散和非瞬停冷却；任意跳转/重置精确一致；旧状态不被修改；非法输入与数值越界拒绝。

代表性独立计算：`t* = 28` 时默认最大流速约 0.29914，向上携热通量 0.032879；无浮力组携热恰为 0、传导为 0.010000；细网格携热为 0.033547。上方加热最大流速约 2.08 × 10⁻⁸。时间 24 将两板设为 0.5 后，时间 52 的动能约 2.26 × 10⁻¹²。这些是本数值模型输出，不是实测值。工作站 Node 中默认重建到时间 52 约 0.48 秒，不能替代浏览器帧率或真机性能证据。

当前视觉证据通过 **CUA** 操作私有 Vite 夹具取得，夹具独立安装依赖并提供最小共用导演上下文。320px 检查了英文八章各进度 0.65 的停帧；去掉重复的观看模式说明后，纯场景高度 616.9–680.7px，没有横向溢出。最终去重与对比度调整前另检查中文染料章和上方加热比较的起止帧；调整后再次检查中文网格停帧，高度 653.9px，可见文字 16/22px，没有溢出。1080px 检查中文暖流与反向加热比较，最终紧凑比较再次检查，桌面两格同时可见、无溢出，高度 807.4px。观看模式不再有重复的大段顶部解释，当前句子由共用 Showcase 展示。审看了读数、完整场域边界、染料可见性、同温板状态与手机对象切换。没有透视投影问题。此前 shell 驱动的浏览器样本已被替代，不作为当前浏览器证据。
