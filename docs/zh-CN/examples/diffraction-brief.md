# 单缝衍射

[English](../../examples/diffraction-brief.md)

## 因果主线

跟踪同一狭缝到同一屏幕位置的电场贡献。关键转折是暗纹来自相消，而不是孔径上没有光。

## 画面与章节

浅色光学图结合孔径路径、复数向量和与接收屏光强曲线。八章展示狭缝、贡献求和、第一暗纹的成对相消、合成场平方、改变缝宽、改变波长、测试距离与零点方程的边界。手机按章节选择需要的孔径或向量图。

## 模型与边界

均匀单色标量 Fraunhofer 模型：E/E₀ = sinc β，β = πa sinθ/λ。有限条带贡献使用精确积分，并与独立数值求积比较。每幅图按自己的中央峰归一化，不能比较总透光量。完整缝宽 Fresnel 数大于 0.1 或缝宽小于 20 个波长时停止预测；这是保守教学边界，不是物理突变。最后的比值实验是代数，不是亚波长电磁场预测。
