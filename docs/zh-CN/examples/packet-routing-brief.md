## 视觉论证

跟随不变的分组编号，观察每一跳如何依据**本地当前信息**决定去向。深蓝网络本身承担主要解释：圆形路由器、终端主机、完整链路、一个带编号的主分组、其他较弱的在途标记、排队数量和紫色拓扑通知。代价文字沿链路外法线放置，避开分组标记。没有装饰性流量粒子或虚构传输速度。

桌面为横向分叉网络，手机重排为纵向菱形：源端在 A 上方，B/C 左右并列，接收端在下方。全程 SVG 同时是完整二维路径。每章只保留当前相关仪器：时延条、本地表、FIFO、TTL、更新安装或接收顺序槽。完整字幕交给共享 Showcase，不在场景顶部重复。现有 network 解释网页加载，本篇聚焦网络内部逐跳转发。

## 事件模型

S/R 为终端，A/B/C 为路由器，S 网关是 A。全部数据包为 1200 B、目的地 R，低于声明的 1500 B 上限。P1 等是教学身份和应用顺序位置，不是 IPv4 分片标识。

| 链路 | 数据速率   | 传播  | 路由代价 |
| ---- | ---------- | ----- | -------- |
| S–A  | 4 Mbit/s   | 2 ms  | 1        |
| A–B  | 2 Mbit/s   | 4 ms  | 1        |
| A–C  | 2 Mbit/s   | 8 ms  | 1.5      |
| B–C  | 2 Mbit/s   | 3 ms  | 1        |
| B–R  | 0.8 Mbit/s | 8 ms  | 1        |
| C–R  | 2 Mbit/s   | 40 ms | 4        |

每方向独立 FIFO 与发送器，等待位不含正在发送的包。串行发送耗时为 `8×字节数/比特率`，最后一比特发出后再经过传播时间，到达下一路由器后处理 1 ms。转发决策时 TTL 减一，到零丢弃；源端与目的端不减。正权重用 Dijkstra 求最短路径，相同结果按字母序稳定决胜；排队不会偷偷修改代价。

事件按时间、明确优先级、插入顺序排序。同刻链路事件先于路由安装、发送完成、到达及源端注入。中断丢弃 B–R 上等待、发送和传播中的包，使旧完成事件失效，不会复活。转发决策使用当时已安装的本地表，哪怕过时。已经进入出口队列的包不重新选路。

初始数据库已同步，只有 B 发布的 B–R 可用状态发生变化；每个路由器保留独立版本，其他边已知且不变。B 立即检测本地事件，更新自己，再向相邻路由器洪泛版本 1。80 B 控制消息使用**每方向独立预留的 64 kbit/s 控制预算**，经历链路传播，再花 40 ms 安装。控制发送队列与数据分开，重复版本不安装、不继续洪泛。此模型不包含完整 OSPF 线格式、确认重传、Hello 检测、老化、邻接、区域、前缀或 ECMP；时间参数是教学选择，不是协议定时器或实测性能。

编号账本始终分为未发、在途、到达、丢弃四类。应用交付是到达的子集，不再重复计数。应用只释放从 P1 开始的连续前缀，没有超时或补包，永久丢失 P1 会让后续包持续暂存。

默认 P1 时延 35.2 ms，其中处理 2、发送 19.2、传播 14。故障中的 P2 实际走 `S–A–B–C–B–C–B–C–R`，142 ms 到达，TTL=1。十包突发在两个等待位时丢六包，八个等待位时完整计算最终全部保留；影片比较窗口截止 180 ms 时仍有部分在途。恢复场景将 C–R 传播明确设为 120 ms，到达顺序为 **4、1、5、2、6、3**；P4 在 131.2 ms 到达，直到 208 ms 才能按序交付。这些均为模型结果，不是网络测量。

不模拟完整 IPv4、ICMP、校验、分片、额外误码、重传、TCP 确认/窗口/拥塞控制或真实路由器 CPU 调度。分组标记代表状态与最后一比特的旅程，不是实际空间尺寸；紫色通知移动含控制发送与传播，目的节点弧线表示安装进度。

## 探索与生命周期

手动范围：1–12 包、间隔 4–80 ms、B–R 0.2–2 Mbit/s、0–10 等待位、TTL 1–16。取样范围至少 300 ms，必要时扩展到计算结束。可切换稳定、故障、恢复场景，跟踪编号和本地路由器，并在相同输入下比较八个等待位。六个滑块都有翻译后的显式 aria-label 与匹配 id/label；重置恢复所有参数、时刻、选择、场景及比较。操作目标至少 44 px，常规标签 16 px，键盘焦点可见。

`useShowcase` 管理章节、进度、离屏、后台及减少动态。专题没有计时器、RAF、Worker、音频或 WebGL 对象，共享紧凑布局钩子释放媒体查询监听。事件历史是一次计算的结果，不是累积播放帧；SVG 无须 WebGL 回退。
