# 拍立得：藏在一张相纸里的暗房

[English](../../examples/instant-camera-brief.md)

## 问题与选定体系

相机在打印照片，还是相纸自己在形成图像？追踪同一张 **Polaroid 彩色 i-Type 积分式相纸**，经过曝光、推纸与排出、药囊破开、试剂铺展、染料迁移和化学等待。末尾的脏／净滚轮是相同曝光输入的受控重演，不表示清洁能够修好一张已损坏的照片。

本篇不混用 Instax、剥离式相纸、黑白银转移或电子热敏打印。建议 10 岁起：主片只要求区分记录光、处理相纸和等待化学过程，微观库存方程按需展开。

## 原创艺术方向与手机构图

奶油色聚合物机身从近侧打开，保留镜头到相纸平面的连续反射光路、装有连续相纸的暗盒、最初接触后边缘的推纸指、与滚轮轴同轴连接的电机和上下金属滚轮。机身是工程示意，不复刻特定型号。曝光时不在相纸上凭空显示完成的照片。

排出后把观察尺度交给相纸：俯视图显示同一 nip 坐标推导的铺展前沿，放大的膜层切片指出染料最终去哪里，分钟时钟陪伴原创红杯图像逐渐形成。受控比较使用相同的可复现杯子输入，一个污点每经过一整圈就再次触纸。

手机将切面放满宽度，滚轮章节有单独声明的近景；后续采用 160 px 纸张俯视、全宽膜层、照片旁的化学时钟及两张 110–118 px 对照图。文字在 CSS 像素中布局，不随着实体一起缩小。艺术区高 318 px，标题与当前状态约增加 100 px；集成人员仍需检查 320/390 px 下的完整双语播放器及透视近角、相切关系。

`InstantCameraDiagram` 与 Three 场景共享纸坐标、nip 中心、药囊压缩和滚轮相位，用于运行时 WebGL 失败与手动二维观察；这不证明启动能力门槛拒绝的浏览器仍能运行专题。没有远程图片、现场化学服务或 Worker。共享 Studio 管理离屏暂停与几何／材质释放，本专题另释放程序生成的相纸纹理。

## 计划共享电影

七章各 24 秒，计划 168 秒，最终时间线由双语录音测量决定。化学时间明确压缩，不等于电影播放秒数。

| 窗口       | 可见因果步骤                                                                  |
| ---------- | ----------------------------------------------------------------------------- |
| 0–24 秒    | 快门打开，折叠光路穿过覆盖片到同一张相纸；关闭后留下尚不可见的潜像。          |
| 24–48 秒   | 推纸指先把前缘送到 nip，滚轮接手，药囊仍封闭并靠近接触区。                    |
| 48–72 秒   | 近景看相反滚轮相位、药囊被几何压缩并破开，同一张纸继续走。                    |
| 72–96 秒   | 药液从药囊边向图像远端铺展，前沿随余下纸张经过 nip 增长。                     |
| 96–120 秒  | 区分透明覆盖片、接收层、试剂和负片 CMY 体系；库存分配到留置、迁入和剩余状态。 |
| 120–144 秒 | 同一红杯图像形成，化学时钟由三分钟走到十五分钟。                              |
| 144–168 秒 | 相同曝光重演有污点的滚轮处理；看周期间隔缺陷，并强调拍摄前清洁、平放避强光。  |

章节间走纸距离连续：0 → 20 → 58 → 130 mm；23 mm 时药囊中心到达 nip 而破开，因此滚轮近景开始时还没破。共享章节进度重建全部状态，无独立计时器；暂停跳转立即收敛到对应镜头。实体镜头根据近侧机身角、完整纸张行程和声明的 nip 近景，求解各屏幕比例下的透视边界。

## 几何与守恒

相纸尺寸采用官方 88.47 × 107.52 mm，图像 76.801 × 78.94 mm。教学参数：前导厚白边 21.4 mm、药囊中心距前缘 9 mm、总厚度 0.32 mm、滚轮半径 8 mm、试剂膜厚 0.08 mm、6% 余量。边缘位置、半径、厚度、余量、机身与推纸结构均是演示约定。

同一纸点为 `x = 起始前缘 + 行程 − u`，`y = 相纸平面`，`z = v − 纸宽/2`。上下转角为 ±`行程/r`，滚轮中心在相纸平面 ±`(r+纸厚/2)`，两面准确相切。有限长药囊位于纸的上面，其截面逐点由上滚轮圆形包络推导。每一顶点取相邻两段最小间隙，保证插值面也不穿入滚轮；形变与中心到 nip 的破开阈值均为教学近似，不是实际材料或破裂压力计算。药囊破开后液体进入铺展前沿和膜层，余量进入尾部陷阱。药囊、液体堆、铺展膜与陷阱之和维持同一试剂总体积，也计入污点导致的未覆盖区。

污点绑定实体滚轮相位：纸上位置 `u = 30 mm + n·2πr`，示意 4 × 4 mm 区域缺少覆盖。这解释周期间隔，不预测所有真实污染。

## 化学模型边界

每个 CMY 通道总量归一为 1，曝光控制留置份额，其余可迁入接收层；80/180 秒指数率、160 秒遮光外观和后期中和指示分别展示功能，维持留置＋接收＋剩余＝1。未铺药区域不会显影。本片没有求解完整反应网络或专有配方，减色混合也只是教学表达；实际温度、光谱、老化、横向扩散与许多子层未模拟。

官方彩色 i-Type 典型成像需 10–15 分钟，压缩等待时必须保留化学时钟。切面把遮光保护画为半透明来解释内部，不表示刚排出的相纸可暴露于强光。不甩、不折、不挤、不剥离；清洁针对下一次曝光，不修复已经出现的照片损坏。
