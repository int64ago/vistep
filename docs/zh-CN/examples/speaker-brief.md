# 扬声器：电流、运动与空气

完整影片为 187.5 秒，并提供按需展开的自由探索。正式讲解在 `src/data/narration.json`，元数据在 `src/data/topics.ts` 登记。交接时冻结双语口播、字幕、八章划分和导演时间。

## 核心观察

扬声器是可以双向转换的电机。电流产生轴向力，线圈速度又产生反电动势。先沿着铜绕组追到相连的振动组件，观察折环、弹波和柔性引线持续连接；再把外加电压归零而保持闭合回路，看到回弹中的反向转换。最后追踪一颗空气质点，分清质点往复与压缩图样向外传播。

## 视觉与手机构图

主要媒介是原创 SVG 轴对称剖面：柔和的钢件、暖色永久磁体、铜绕组、石墨色锥盆、折环、波纹弹波与两根弯曲引线。SVG 本身就是完整的二维表达，不依赖 WebGL 或外部模型。剖面机械行程统一放大八倍，读数仍使用真实单位。

全景朝上展开，标注就近连接部件。磁隙特写显示固定的径向磁场和变化的轴向力。手机的悬挂章节只投影一侧真实连接，保留局部尺寸；后续功率、响应与空气章节直接切换到对应证据，不堆叠全景、图表和重复标题。当前解释紧邻主要视觉，长说明与控件按需展开。

导演只使用 `useShowcase()` 的章节与进度。平滑的章节映射包含观察停留、直流起步、电流换向、悬挂形变、闭路释放、一个功率周期、稳态频率与阻尼对比、一个空气波周期。没有私有动画时钟、帧历史或随机状态。不同物理实验之间是明确的镜头切换，不暗示它们具有连续的初态。

## 独立模型

状态为电流 `i`（A）、位移 `x`（m）和速度 `v`（m/s）。教学参数：`R = 6 Ω`、`L = 0.5 mH`、`Bl = 4 N/A`、`M = 12 g`、`K = 1200 N/m`、`D = 0.8 N·s/m`，不冒充商业扬声器实测值。质量与悬挂参数代表整个振动组件的合成作用。

- 电路：`u = Ri + L di/dt + Blv`。
- 机械：`M dv/dt = Bli − Kx − Dv`，且 `dx/dt = v`。
- 互易转换：`(Blv)i = (Bli)v`。
- 储能：`E = ½Li² + ½Mv² + ½Kx²`。
- 收支：`ui = Ri² + Dv² + dE/dt`。

恒电压瞬态由三阶矩阵指数直接从初态求出，使用缩放、平方和固定 28 项泰勒展开。时间限制为两秒，并检查有限输入及矩阵范数；拖动进度不累计历史积分误差。

正弦输入采用峰值复振幅：`Zₑ = R + jωL`、`Q = K − Mω² + jωD`、`X = BlU / [ZₑQ + jω(Bl)²]`、`I = UQ / [ZₑQ + jω(Bl)²]`。阻抗从单位电压电流计算，因此探索电压归零后仍显示同一个阻抗。周期平均功率采用峰值相量所需的 ½ 系数。频率和阻尼章节比较各自已经稳定的设置，不是参数突变的瞬态。曲线默认采样 161 点，最多 321 点。

无阻尼机械固有频率约 50.3 Hz；电气耦合、阻尼和电感共同决定完整行程峰。力因数归零时仅剩被动 R–L 支路；零输入对应零运动和零储能。

## 连续几何与空气近似

所有移动坐标来自 `speakerGeometry(x)`。线圈骨架、绕组、锥盆和防尘帽共享轴向偏移。弹波从锥盆颈部连到固定支承；折环从锥盆外缘连到固定翻边；柔性引线连接固定端子和移动绕组。背板、中心极柱、环形磁体与上夹板形成闭合磁路。支持的所有行程都保留线圈、骨架与磁隙边缘之间的间隙。绕组截面按组示意，磁通虚线只表示拓扑，不是有限元磁场。

空气图明确是**单向运动学说明**。取 `ξ(s,t) = x(t − s/cₐ)`，`cₐ = 343 m/s`；压缩为 `−∂ξ/∂s = v(t − s/cₐ)/cₐ`。边界与质点共享同一相量解；所有质点保留平衡位置，金色点独立追踪。显示放大倍数有界，保持质点顺序；颜色按压缩相位归一化，不提供 Pa、SPL、辐射效率或距离衰减预测。

声负载没有反馈到驱动器，机械阻尼也不等同于全部辐射声功率。模型省略磁路非线性、线圈升温、随频率变化的损耗电感、锥盆分割振动、箱体及空间声辐射。双语正文、场景折叠说明和空气章节的当前说明都交代相应限制。

## 操作与生命周期

四个原生滑块有明确、可翻译的名称：电压峰值 0–0.4 V、频率 20–400 Hz、相位 0–360°、机械阻尼 0.3–2.5 N·s/m。支持方向键、Home、End；半周期按钮把相位推进 180°。恢复按钮重置全部四个输入和全景观察模式。手动实验是稳态快照，没有隐藏的第二条时间线。

只有一个 `ResizeObserver`，卸载时断开。组件没有音频、WebGL、Worker、RAF 或定时器资源。减少动态效果、后台与离屏暂停、统一运输控件及配音由父任务的 Showcase 整合负责。按钮的轻微反馈过渡在减少动态效果设置下关闭。
