# 挖掘机 — 从油流到闭合连杆

[English](../../examples/excavator-brief.md) · [制作指南](../creating-a-scene.md)

## 问题与导演意图

油缸沿直线推拉，怎样让铲斗举起并收拢？先跟住油缸两端的销轴，再沿着相连的杆件观察。转折是分清两个容易混淆的量：压力提供应对载荷与力臂所需的推力，流量决定能推动载荷以后有多快。

器物是原创教学装配：双动臂缸、斗杆缸和铲斗四杆机构，不复刻 Cat 303.5 或其他具体机型。黄色涂装钢件、裸露金属活塞杆、可见铰座与克制的深色底盘突出连接关系。解释油路时，油缸与回路剖面取代整机。主画面承担一个可见观察，公式与操作按需展开。

## 模型契约

- 长度使用米，角度使用弧度，力为牛顿，压力为帕，总供油流量从 L/min 换算为 m³/s。模型、渲染、后备图与封面共用缸筒、活塞杆、连杆长度和销轴位置。
- 收拢角度表示向内收斗。收斗增加时铲斗缸伸长，两条短连杆长度不变；只证明连杆闭合还不足以证明动作方向正确。
- 对理想单杆双作用缸，取伸出方向为正，净力为 `p无杆 A − p有杆 (A − A杆)`，使用表压并忽略摩擦。两腔有效面积不同，不能一般地套用单个 `Δp A`。
- 举升计算假设两支相同动臂缸均分总流量、忽略损失且回油背压为零：`F总 = 2pA`、`v = Q总/(2A)`。平均分配是本模型的条件，不是所有挖掘机的普遍性质。
- 所需压力由 `2 p所需 A d = Σ(mgx)` 决定。销轴推导的作用线给出力臂 d；器物几何与等效载荷位置给出重力矩。所需压力与按教学上限 24 MPa 截止后的压力是不同的数值。
- 手动姿态用于比较静态几何和载荷，不对操作者的举升指令做时间积分。理想伸出速度由动臂供油计算；积分推进的剖面代表两动臂缸之一，不表示整机动态运动。
- 理想运动阶段，液压功率与两支缸的机械功率相等。油缸停止、泵流量走溢流时，`pQ` 是泵侧输入，执行器机械功率为零；不能把全部泵流量都标成油缸的有效供油。
- 封油保持与再次尝试超载举升是两个阀状态。主供油溢流不能保护已经隔离的油缸腔。理想泵去排量与封油保持简化了真实系统的负载感知、节流、泄漏和专门负载保持硬件。

模型省略惯性、摩擦、油液压缩、泄漏、土壤力、回转与行走、结构变形和整机稳定性。24 MPa 上限与 0–9000 kg 等效载荷输入用于解释边界，不是起重载荷表、额定工作负载或维修原理图。
