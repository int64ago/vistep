## 视觉论证

沿着一个输出节点，看互补晶体管通路怎样搬运电荷。浅暖色电路中，pMOS 用铜色，nMOS 用蓝色，输出电容用紫色。绝缘栅极、导通或断开的沟道、电源、地、电容都保持完整连接，下面一条电压曲线使用同一计算状态。现有 binary-adder 解释布尔进位依赖；本片进入 CMOS 内部，解释电压、时间与能量。

SVG 同时是主要媒介和完整二维路径，无装饰性封装、无粒子冒充电流。实线沟道表示导通，虚线表示断开；支路强调还随实际支路电流变化。电容旁的短柱表示归一化电压。输入栅线与沟道绝缘，需要跨线时使用跳线弧，输出结点用圆点。两级探索只允许反相器，确保电路图与模型拓扑一致。

当前完整字幕由共享 Showcase 在场景下方显示。观看模式只有短标题、输入输出状态、电路、一条曲线和随章节改变的证据；场景顶部不重复完整解释句。长说明与控制放在探索模式。

| 22–44 秒   | 满电容，A=1，放电 600 ps                     | 互补下拉释放已有电荷                       |

600 ps 的慢观察采用 `时间=600 ps×进度²`。电容比较每次从独立的零初值开始，不伪装成更换电容的实际暂态。能量章每半轮采用立方时间映射，保留充放电初段的观察时间。与非、或非的输入在 450、900、1350、1800 ps 改变。所有状态只来自共享章节与进度，没有独立时钟、随机状态或逐帧历史。跳转会直接重建目标时刻。

## 独立模型

每只导通 pMOS/nMOS 是正电阻，断开为开路。三种门有明确节点和边。图遍历保证输出恰好连接一条电源轨；内部节点用 KCL 求电位与输出等效电阻。真正浮空的节点保留 `null`，不会偷偷赋零。支路电流、热耗与显示连接状态来自同一张图。

每个输入事件区间满足 `C dV/dt=(V目标−V)/R等效`，采用精确指数解。下一段初值等于上一段终值，带符号电荷转移为 `CΔV`。电源能量、沟道热与电容能量使用解析积分，瞬时和累计均闭合：`P电源=ΣI²R+d(½CV²)/dt`，`E电源=E热+ΔE电容`。

默认 1.2 V、20 fF，每只导通沟道 5 kΩ。单级时间常数 100 ps，半电压时间 69.3147 ps，充分稳定一轮电源供能 28.8 fJ。完整充电存入 14.4 fJ、产生 14.4 fJ 热，放电再释放所存的一半。能量章每半轮十二个时间常数，保留与极限值的有限时间差异，不把读数强制补齐。

显示将 V≤0.3VDD 标为 0，V≥0.7VDD 标为 1，中间为 X。独立的 0.5VDD 界线产生第二级理想输入切换事件，所以 Y₁ 仍是 X 时，第二级就可能开始动作。未跨过界线的短脉冲不会虚构第二级事件。这些是教学界线，不是通用晶体管阈值、输入输出保证范围或数据手册传播延迟。

模型省略非线性 MOSFET 电流曲线、栅源及体效应、漏电、部分同时导通、沟道与内部节点电容。第一级的输出 C 已含连线与后级栅极等效负载，不重复计数；输入驱动器能耗不在账内。p/n 电阻相等只是比较条件。理想稳态无持续直流耗电，不代表真实芯片没有漏电等损耗。

手动范围：0.8–1.8 V、5–80 fF、两类沟道 2–20 kΩ、0–1200 ps。起始与切换后输入分别选择，时间窗口内未越界会明确标出。重置覆盖门类型、两组输入、电源、电容、两类电阻、取样时间及两级开关。

## 手机、操作与生命周期

桌面电路宽 740 逻辑单位，手机改用 310 单位的独立布局。手机两级反相器沿对角折叠，保持真实连线和两个电容；不是整幅桌面缩小。图内文字为 21–22 单位，常规标签 16 CSS px。曲线尺度说明放在 HTML 中，不随 SVG 缩字。只保留当前章节相关的证据块，不堆叠次要面板，不用过大的最小高度填空。320 px 下主场景目标不超过 900 px，实际每章高度、边界与标签仍待父任务浏览器检查。

四个滑块都有翻译后的显式 aria-label、唯一 id 和对应 label；输入与按钮至少 44 px，键盘焦点可见。与非、或非下禁用两级按钮，切换门类型退出两级视图。重置调用经过测试的完整默认值工厂。

仅使用 `useShowcase` 与共享紧凑布局钩子，没有自建计时器、RAF、音频、WebGL、观察器或 Worker。离屏、后台及减少动态由共享播放器处理，媒体查询监听由共享钩子释放。缓存是有限的编排事件表，与播放历史无关。SVG 不依赖 WebGL 或外部渲染资源。
