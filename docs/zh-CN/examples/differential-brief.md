# 汽车差速器：两条轮迹，一个平均转速

[English](../../examples/differential-brief.md)

## 解释主线与美术方向

先看转弯车轴：同一段时间，外轮沿更大的圆弧走得更远。再剖开机构，分清行星齿轮随壳体公转，以及两侧转速不同时绕十字轴自转。随后把运动约束与扭矩上限分开解释，避免把“转得慢”误当成“扭矩更大”。

装置是一台青灰色、古铜色与冷色钢材组合的开放式台架差速器。两个半轴齿轮与两个行星齿轮使用共顶点的球面渐开线锥齿面。两根半轴在交叉轴之前终止，向外连接两只车轮。四根桥连接壳体端环与中央支承环；空心轴颈装在固定滑动轴承里，轴承座连接底座。行星齿轮带轮毂和后侧支承面。输入直接施加到壳体；主减速齿轮副与商品车桥外壳明确省略。

全部为原创程序化几何，无外部图片、纹理、厂家 CAD 或生成图像。齿面、接触点、相位和车轮标记都来自独立模型。封面将同一个局部锥齿轮模型投影成完整的 400 × 230 SVG，接受可选 color 参数。不是用带装饰齿的圆柱代替锥齿轮。

手机按章节选择主视图：轮迹、平均转速和扭矩上限替换不必要的三维总装；机构章节使用中央齿轮组特写，并说明半轴仍向画面外连接车轮。补充假设保持折叠，避免把总装、图表和重复读数全部纵向堆叠。

## 独立模型与啮合几何

以车轴同一空间方向作为左右轮与壳体的转速正向：`ωL = ωC − Δω`，`ωR = ωC + Δω`。半轴齿轮各 24 齿，行星齿轮各 16 齿，因此各行星齿轮沿向外局部轴的自转为 `−(24/16)Δω`；静止参考系中的总角速度还包含壳体公转。四个齿轮使用右手正交坐标基，先共顶点放置，再共同施加壳体转角。

轮迹模型给定轮距 `b = 1.6 m`、滚动半径 `rw = 0.31 m`。车轴中心转弯半径为 `R` 时，差速比例是 `Δω/ωC = ±b/(2R)`。共同偏航角导出两条轮迹，车轴长度始终等于轮距。下限 `R = 0.8 m` 对应内轮停止，是两轮无侧滑车轴的几何极限，不代表整车转向能力或安全结论。固定车轮、固定壳体属于台架约束，不绘制道路轮迹。

90° 轴交角下，节锥角为 `δS = atan(24/16)`、`δP = atan(16/24)`，两者互余。同一锥距 r 的圆周齿距 `2πr sin(δ)/z` 相同，并随锥距向顶点渐缩。压力角为 25°，基锥满足 `sin(δb) = sin(δ) cos(25°)`。

球面渐开线由单位球上基圆的切向大圆弧展开独立推导。对极角 θ，令 `L = acos(cos θ / cos δb)`，则 `invS(θ) = L/sin δb − atan2(sin L, sin δb cos L)`。单侧齿半厚的方位角为 `π/(2z) + invS(δ) − invS(θ)`。沿锥顶射线缩放到锥距 0.86–1.36，形成齿面实体；这些是展示单位，与轮迹米制分开。缩短齿顶避免接触进入基锥以下，根部采用径向延伸。渲染采样解析曲面，接触求解则直接使用解析齿面。

两只行星齿轮都具有半齿距初相位，再按 24:16 关系自转；偶数齿保证对侧两组啮合也相容。接触点满足相对法向速度为零，并检验另一齿面的空间位置。测试覆盖一个完整齿周期的接触连续性，以及四组啮合的双向采样齿面不侵入检查。这不是商品加工图或完整 CAD 碰撞认证；未包含刀具生成、齿根圆角、侧隙、修形、弹性变形与摩擦。

大多数章节直接由转速和绝对模型时刻求转角。第四章差速是 `Δω = 0.9 × 0.7 sin²(πp)`，转角采用八秒模型时间上的解析积分，不能拿当前转速乘总时刻。跳回任一章节与进度都能重建同一个状态，无独立帧历史或随机输入。

## 扭矩边界与自由探索

载荷计算是理想准静态容量模型，和规定运动明确分开。忽略惯性、摩擦与损耗时，行星齿轮平衡给出相等侧扭矩。非负壳体请求与轮胎反作用上限给出 `Tside = min(Trequest/2, CL, CR)`，`TC,accepted = 2Tside`。400 N·m 请求、弱侧 60 N·m 上限时，两侧各 60 N·m，可维持壳体扭矩 120 N·m。剩余 280 N·m 是未满足请求，不是已经输入后凭空消失的功率。

功率按 `PL = Tside ωL`、`PR = Tside ωR`、`PC = 2Tside ωC` 计算，反转与固定壳体的正负功率也平衡。模型不预测打滑、车轮或整车加速度；轮胎反作用上限是教学输入，不是实测路面系数。不会声称全部扭矩流向弱侧。限滑、锁止与电子制动不在范围内。

探索可改变模型时刻、输入转速、转弯半径和方向、车轮约束、壳体扭矩请求、左右反作用上限。比较保留相同请求、规定转速与时刻。每个滑块用显式 label/id 关联；重置恢复所有输入、约束、视图、方向与时刻。二维退化保留齿轮拓扑、共顶点、轮相位与转速／扭矩解释，明确为运动学示意，而非二维加工齿形。
