# 直升机、AK-47 与地雷审看 — 2026-09-12

[English](../qa-helicopter-ak47-landmine.md) · [检查记录](README.md#检查记录)

本记录对应父提交 `c57baf2` 上新增的三篇：直升机（68）、AK-47（69）和地雷（70）。三个独立负责人分别制作模型、画面、双语文章与脚本，集成人统一负责共享登记、录音和验收。证据分别记录作者检查、独立复核、浏览器观察与录音分析。

## 范围与科学边界

- **直升机：**近悬停状态的通用民用直升机。叶素升力与均匀入流动量理论共用推力状态。总距、周期变距波形、倾斜推力及反扭矩分别用于教学，不是完整飞行动力学模型或飞行训练。
- **AK-47：**详细外形与相连的大部件，运动和能量显示由独立的无量纲教学计算驱动。计算不等于真实枪械动力学，不含武器操作、制造几何、击发或闭锁机构、弹药及性能参数。
- **地雷：**土壤切面中的完整外壳，观察表面磨损、遮挡变化与长期风险。地表外观和季节流逝始终不能判定安全。不包含可工作触发器、制造、布设、灵敏度、伤害半径或排除模型。

## 证据记录

- 三位场景负责人分别制作；交叉审查发现并修复了二维替代视图缺少因果对象、地雷探索控件空转、AK-47 比较中输入功与耗散的区别，以及手机近镜遮挡。作者检查不计作独立复核。
- AK-47 方程通过 Duhamel 卷积和 Simpson 积分独立求解，没有调用生产 RK4 积分器。401 个时刻的最大位置／速度差为 2.61e−13／5.52e−13，能量余差为 2.49e−13。受控比较从 30% 行程开始，保证两种状态的输入都已结束。
- 地雷独立审查扫描了 7,007 个章节状态，物体身份和未知安全状态始终保持。土层接触、遮挡及章节边界分别检查；实际三维与二维画面共用季节覆盖状态，时间不参与安全推断。
- 静态合成得到六条内容哈希录音。两语共用实测时长：直升机 **175.5 秒**、AK-47 **170 秒**、地雷 **168.5 秒**。42 段独立转写的语言、内容和结尾检查全部通过；这是转写证据，不是原声试听。
- 相比父修订，原有 67 篇的 **268 项录音／时间元数据**以及 **134 个 MP3 的 SHA-256**全部保持不变。
- `pnpm scene:check`：**20 项通过**。首轮预览构建与审计通过，覆盖 143 个正式双语页面、内部链接和资源、sitemap、404 与预览索引策略。发布检查也已通过：**125 个文件中的 1,035 项测试**，Astro **0 错误／0 警告**（38 条既有提示），生产构建及资源／链接／索引审计。首轮全套测试中一项几何检查超出五秒预算，改为汇总最大投影值后保留了全部顶点采样，同时去掉数百万次断言对象分配。

## 浏览器证据

环境为 macOS 的 Chrome **152.0.7977.84**，审看实际页面、320／390 px 显式视口和正常桌面视口。早期独立画面用于修正玻璃／蒙皮相交、材质僵硬、土壤接触和多余阴影平面。实际页面中复查了修正后的桨叶剖面定位图、相连的 AK-47 比较部件、地雷与土壤的接触及局部阴影；三张最终目录 PNG 和生成的分享图也已审看。

六段影片均在浏览器中以 1 倍速度运行至实测终点，抽样截图与音频／画面时钟分别记录：直升机 175.5 秒、AK-47 170 秒、地雷 168.5 秒。后两篇的共享导演在准确终点暂停，媒体元素未必先触发 `ended`，不因此判为缺少结尾。已操作暂停、跳转、重播，以及 AK-47 比较位置的 30%／90% 边界。
