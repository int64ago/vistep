# Scene drafts

Run `pnpm scene:new <slug> --medium <three|svg|canvas|audio|hybrid>` at the repository root. This creates an unpublished brief, storyboard, bilingual writing files and a review sheet. It intentionally does not generate a generic experiment UI.

Follow [the scene guide](../docs/creating-a-scene.md). Keep completed briefs and evidence with the contribution when useful. Nothing in this folder is included in the deployed website.
