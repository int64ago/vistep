# LZ77: the decoder's remembered tape

Track the first ABRA and its return in one reproducible message. The indexed paper tape splits history from future; reference numbers carry the causal explanation. The turning point is a distance-2, length-10 overlap: newly produced output really feeds the next copy. Phone reflows indexed cells at readable sizes rather than shrinking the desktop tape. Limit: Unicode teaching symbols and bounded greedy token stream, not DEFLATE bytes or file-size estimation.
