# Huffman: a weighted tree, not a dashboard

Track the A in one fixed message. Opening: repeated A versus rare D. Turning point: merge minima to discover a one-edge A code. Resolution: bit-by-bit decoding reconstructs the exact message. The frequency view, merge forest, geometric tree, decode cursor and payload comparison are separate causal instruments. Phone preserves a legible tree and renders labels in CSS pixels. Teaching limits: Unicode symbols, bounded input, no file-format overhead; universal binary Huffman, not DEFLATE serialization.
