# 氯水光解：从光到读数

本次把必修第一册第 48 页数字化实验改为一条可见的因果论证：三个不同探头为何一起变化，光首先改变了什么，净产物如何进入各自相区，以及“氧气比例较低”是否足以推出“产氧较少”。需要学生认识原子、离子、物质的量与比例；pH 的对数定义在读数镜头中展开。

## 教材窗口与镜头

唯一入口 `chem-required-1-body-p48`，`sceneVariant=photolysis`。原始教材 ID、名称、页码和排序不变；旧 `sensors → illuminate → stoichiometry` 子序列保留，插入 `light-entry`、`headspace-predict`。五章最终窗口为 26 / 32 / 34 / 30 / 34 秒，共 156 秒，起点为 0 / 26 / 58 / 92 / 122 秒。现已逐条读取双语实际词时，以 `chapterTime + locale` 校准内部镜头；模型路径没有按录音时长重新定义反应速率。

1. `sensors`：固定教材观察方向。两支探头在液相，一支在顶空；依次辨认 pH、Cl⁻浓度和 O₂比例，连接可见采集器。
2. `light-entry`：跟随一个被吸收的不可见紫外光子。O—Cl 键的两个选定电子各随一个中性片段，H—O 仍相连；第二份 HOCl 留在同一批样本中。
3. `illuminate`：初始状态逐坐标接续前章六个原子。明确换成合并后续多步反应的净账本，六原子重新分配为两 H⁺、两 Cl⁻和一 O₂，总电荷为零。O₂在液相、过界和顶空之间连续运动；整个图形越过同一液面后才进入气相账本。
4. `stoichiometry`：数出新增 Cl⁻与 O₂的 2:1 物质的量关系，分别看 pH 对数刻度、Cl⁻浓度刻度，以及新增 O₂同时进入比例的分子、分母。
5. `headspace-predict`：A/B 是两份独立样品，液体量和净分解量相同，B 初始顶空加倍。答案先隐藏，再揭晓较小的 B 氧气比例与相同的液相读数；前后对象身份保持连续。

桌面把器皿、原子与账本留在宽而安静的画面中；手机按对象重新构图，A/B 缩短器皿高度但保持相同比例与独立身份。净反应的相区账本始终可见，未以缩小字体或隐藏证据换取短屏高度。自动导演只读取共享时钟；探索事件、进程、暗对照、顶空和揭晓状态与影片隔离。

## 证据、模型和边界

- 教材：必修第一册第 46—48 页（PDF 51—53），相关全文与第 48 页图 2-16 原图已读。只保留观察方向，没有伪造教材数值、噪声或 0—150 秒曲线。
- [Watts 与 Linden 2007](https://doi.org/10.1016/j.watres.2007.03.032)：读取出版方可访问的摘要与引言节选，支持水中紫外光解和羟基自由基层级；未移植定量产率。
- [Yin 等 2018](https://doi.org/10.1016/j.watres.2018.06.018)：读取出版方索引摘要、部分结果和结论，支持光谱/pH 依赖；其短紫外条件不冒充教材光源。
- [Shiraishi 等 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10207101/)：相关全文 XML 与公开 API 提供的原式 8 图片均已核对，净式为 HClO → ½O₂ + H⁺ + Cl⁻。未使用未独立查看的 S24 数值。净式不是基元反应，也不能独立证明微观机理。

微观镜头选择一次 254 nm 吸收并解离事件，不构成吸收概率、量子产率、反应速率或完整机制。只追踪选定 O—Cl 键的两个电子；转入净镜头后停止展开电子网络，六原子仍保留。显示的缓慢路径是可追踪的净分配，不是实测分子轨迹。H⁺表示水合酸性氢离子；光晕不是精确水合结构。

宏观教学算例为 100 mL 液体，HOCl 初始 0.018 mol/L，H⁺、Cl⁻各 0.008 mol/L；初始理想气体为 298.15 K、1 atm、18% O₂。每净分解 1 mol HOCl 增加 1 mol H⁺、1 mol Cl⁻与 0.5 mol O₂。pH 采用浓度近似；终态全部生成 O₂进入顶空，忽略溶解、活度、平衡、竞争反应与传质。独立算例终态为 1.8 mmol 分解、0.9 mmol O₂、pH 约 1.585、Cl⁻约 921.7 mg/L；500/1000 mL 顶空的氧气比例约 21.459%/19.767%。模型容许有限边界计算，实际器皿探索将 B 顶空限定为 500—1000 mL，保证同一尺度的气相对象可读。
