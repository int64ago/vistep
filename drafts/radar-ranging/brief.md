# Pulsed radar

Track a finite pulse envelope through outward and return path arclength. Opening: finite spatial length. Turn: received leading edge means round-trip delay, hence divide by two. Result separates fixed target identities under pulse-width resolution comparison, transmitter blanking and PRI ambiguity. Eight 20s chapters.

SI model uses c=299792458m/s. Display propagation is slowed but readouts retain physical time. Pulse segments use exact interval intersections and conserve spatial envelope length through reflection. Receiver is blanked during emission; near-target chapter explicitly describes partial loss rather than claiming an entirely absent return. Normalized positive envelopes omit carrier interference, power, noise and detection. Phone uses the same two physical travel legs and one compact time axis with CSS-pixel type.

Primary sources actually opened 2026-10-17: MathWorks radar receiver simulation and Pulse Waveform Analyzer. This is ordinary unmodulated pulse timing, not FMCW or pulse compression. Model tests are separate from pending visual and listening evidence.
