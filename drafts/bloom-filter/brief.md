# Bloom filter: a finite field of shared marks

Track apple through actual deterministic hash addresses. Opening is an empty addressable array. The turning point is a searched absent key with every bit already set. Then a deliberate invalid deletion shows the no-false-negative guarantee's precondition. Different chapters change inserted set, query witness, deletion state and occupancy. Phone uses eight columns of CSS-pixel addressed cells, no scaled SVG text. Fixed hashes and independence approximation are clearly qualified.

Primary sources

- [Bloom, Space/time trade-offs in hash coding with allowable errors (1970)](https://pages.cs.wisc.edu/~markhill/restricted/cacm70_bloom.pdf)
