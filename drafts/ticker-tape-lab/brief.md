# Ticker-tape laboratory

Four textbook paths, five continuous chapters: timer / average velocity / instantaneous limit / accelerating cart / free-fall tape. Each variant is an acquisition-and-analysis argument, not a card with a formula. Tracked object is the same physical strip, and dots are generated at actual sample times. The apparatus records a moving strip; the removed strip is reoriented early-to-late for analysis. Both views use the same data.

Separate phone composition uses CSS16px labels outside SVG; no tiny plotted text. A vertical frame replaces the horizontal rail for free fall. Film-clock seeking reconstructs all sample positions. The independent model tests50Hz interval counting,1m freefall-derived motion, constant-acceleration finite differences and the nonlinear-velocity counterexample. Conventional50Hz is an explicit teaching parameter, not a universal instrument property.

References: OpenStax University Physics1 §§3.2–3.3 (definitions and limits). Textbook required1 §§1.2,1.3,2.1,2.4. Synthesis and rendered/browser review belong to integration; local numerical tests alone do not establish visual or spoken acceptance.
