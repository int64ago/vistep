<a id="understand"></a>

## 每个感光位置只留下一项

RGGB阵列每四格有一红、两绿、一蓝。理想模型中，每格只保留参考图相应的一个线性RGB通道。彩色马赛克是通道可视化，原始数据仍是一格一个数。影片始终保留同一张参考图，跟踪同一个红格：红值实测，绿色取四个十字邻居平均，蓝色取四个对角邻居平均。

对所有位置应用邻域规则，得到完整颜色图像。细密的无彩色条纹则揭示推断的局限：不同颜色在不同位置采样，重建可能出现原图没有的假色。

<a id="try"></a>

## 让图案相对滤片移动

自由探索提供彩色测试图和无彩色条纹。增加空间频率，或只移动不到一个像素，比较画幅中原图与重建的两半。滑块支持键盘；暂停和章节跳转可以停在绿色与蓝色插值的局部视图。

<a id="deeper"></a>

## 双线性插值保留实测值

<div className="formula">
  G红格 = (G上 + G下 + G左 + G右) / 4<br />
  B红格 = (B左上 + B右上 + B左下 + B右下) / 4
</div>

在绿色位置，红色与蓝色按RGGB行列选择水平或竖直邻居；在蓝色位置使用对称规则。画幅边缘只平均有效邻居。所有实测通道原样保留，插值不偷看参考图被遮住的通道。图像尺寸为24×24个教学采样点，显示前使用标准sRGB分段编码。

真实滤片的光谱响应不是互不重叠的理想RGB，真实图像处理还包括黑电平、白平衡、颜色矩阵、噪声处理与更复杂的边缘判断。本演示有意省略这些过程与光学低通，便于看清采样本身的限制；没有实现Malvar等人的改进滤波器。
