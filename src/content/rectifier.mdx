<h2 id="understand">交流反过来，负载里的电流为什么没有反过来？</h2>

这个单相整流桥有四只二极管。D1 从交流端 A 指向正输出，D2 从 B 指向正输出；D3 从负输出指向 A，D4 从负输出指向 B。负载始终接在正、负输出之间。

A 端较高且电压足够时，电流依次经过 **A → D1 → 负载 → D4 → B**。交流反转后，路径变为 **B → D2 → 负载 → D3 → A**。二极管换了一对，电流仍从负载上端流入、下端流出。每条亮起的路径都通过交流源闭合。

不接电容时，输出每个交流周期出现两个正向脉冲，在过零附近仍会降到零。因此 50 Hz 交流产生 100 Hz 脉动；**极性统一和平滑输出是两件事**。

在负载两端并联电容后，它可以暂时储存电荷。只有源电压幅值超过电容电压加两只二极管压降，桥才有正向电流。桥导通时，电流先满足负载；超过负载需求的部分才使电容净充电。其余时间电容放电供给负载，输出留下较小的纹波。

场景默认使用峰值 **12 V**、频率 **50 Hz** 的教学交流源。这里的 12 V 是峰值，不是有效值。实际计算保持物理时间，影片只把过程放慢。它不是市电接线、元件选型或安全搭建指南。

<h2 id="try">跟住充电窗口，而不只是电压峰值</h2>

- 进入自由探索，先移除平滑电容。拖动取样时间，核对正半周的 D1、D4 和负半周的 D2、D3。
- 接入电容，查看电压曲线中的导通门槛，再切换到桥电流脉冲。电容已经有电时，桥电流不会覆盖整个半周。
- 增大电容，比较同一电压刻度下的纹波。更平滑的输出仍由脉冲式桥电流补充电荷。
- 降低负载电阻，再提高交流频率。前者加大电流需求，后者缩短两次补充之间的时间。影片的频率比较始终使用同一个 20 ms 窗口。
- 选择“在交流峰值接入”，让空电容从交流峰值开始充电。把源串联电阻从 0.5 Ω 调大，检查电流峰值和充电速度。
- 把交流峰值降到两只二极管总压降以下。稳态时桥不导通，输出为零；模型不会凭空产生电荷。

所有范围输入都有明确标签并支持键盘方向键。手动取样时间保持静止，直到再次拖动。移除电容会关闭空电容启动，相关操作同时禁用。“重置整流实验”恢复电压、频率、电容、负载、源电阻、初相位、启动状态、观察项和取样时间。影片的播放、暂停、章节、重播和声音由共享播放器控制。

<h2 id="deeper">一个连续储能状态，三种导通状态</h2>

<details>
<summary>桥电流和电容微分方程</summary>

计算使用 SI 单位，电容电压 `vC` 是唯一储能状态。源电压为 `vs = Vp sin(2πft + φ)`。每只二极管使用固定压降 `VF` 加串联动态电阻 `rD`；源电阻为 `Rs`，负载为 `R`。

<div className="formula">iB = max(0, (|vs| − 2VF − vC) / (Rs + 2rD))</div>

<div className="formula">iR = vC / R；iC = iB − iR；C dvC/dt = iC</div>

`iB` 是桥输出的非负电流。源电流的符号随交流电压改变，所以源功率仍为正。只有对应半周的两只二极管承载 `iB`；截止二极管电流精确为零。`iB > 0` 并不一定意味着净充电，还需要 `iB > iR`。

桥截止时：

<div className="formula">vC(t + Δt) = vC(t) exp(−Δt / RC)</div>

导通时的方程是由正弦源驱动的一阶线性方程。求解器在导通区间使用其解析解，在截止区间使用上面的指数解，并在 `|vs| = vC + 2VF` 处定位事件。电容电压不会在事件处跳变，也不会被强行设置为源峰值。

移除电容时没有储能状态，电路改为代数解：

<div className="formula">iB = max(0, (|vs| − 2VF) / (Rs + 2rD + R))；vout = R iB</div>

默认值为 1000 µF、100 Ω、源电阻 2 Ω，每只二极管 `VF = 0.65 V`、`rD = 0.08 Ω`。这是明确选择的线性分段教学模型，不是某种器件的实测曲线。

</details>

<details>
<summary>纹波、浪涌和源电阻</summary>

默认稳态计算约得到平均输出 **9.54 V**、峰峰纹波 **0.70 V**，桥的导通时间约占交流周期 **28%**。电流并非连续地从源流入电容。

较大电容在失去同样电荷时，电压下降较少：

<div className="formula">ΔvC = ΔQ / C</div>

常见近似 `Δv ≈ Iload / (2fC)` 假设较小纹波和短充电时间。场景并不使用它生成波形，而是连续求解含源电阻和二极管压降的电路。负载不是恒流源，电容较小时尤其不能强套这个近似。

在源峰值接入空电容，最初的桥电流为：

<div className="formula">iB(0) = max(0, (Vp − 2VF) / (Rs + 2rD))</div>

影片比较 0.5 Ω 与 5 Ω 源电阻，计算出的初始峰值分别约为 **16.21 A** 和 **2.07 A**。这说明有限电阻怎样限制模型中的浪涌，不是实际硬件的电流额定值预测。更大源电阻同时增加压降、耗热并改变充电过程。

</details>

<details>
<summary>电荷与能量都要对得上</summary>

<div className="formula">∫ iB dt − ∫ iR dt = C ΔvC</div>

<div className="formula">Esource = Eload + Ediodes + ERs + Δ(C vC² / 2)</div>

负载功率为 `vC²/R`；二极管总热耗为 `2VF iB + 2rD iB²`；源电阻热耗为 `Rs iB²`。周期稳态的首尾电荷与储能一致；空电容启动时，必须保留储能增加项。

源波形按四分之一周期分段，二极管事件在步内二分定位。记录步长默认不超过周期的 1/512；导通时还按充电时间常数细分，电荷与功率用同一解析状态进行 Simpson 积分。周期稳态通过积分周期映射的不动点求得。时间拖动从已计算状态和解析传播重建，不依赖先前播放过哪些帧。

模型不含电容 ESR、变压器漏感、二极管反向恢复、结电容、温度、保护或调压电路，也不预测电磁干扰和器件可靠性。电容旁的紫色填充表示相对于当前源峰值的电容电压；它不是电解液液位或独立动画。
