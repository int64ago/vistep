<h2 id="understand">一个不肯落在预测位置上的星点</h2>

把某一天对准很容易。困难的是：同一个轨道，能否解释不同日期的方向，还能否预测尚未拿来比较的记录？第谷的观测给开普勒提出了这样的约束。这里用一张**预先固定的合成表**展示检验方法，金色记录不会随候选轨道改变；它不是第谷的原始数据，也不复现历史八角分。

圆轨道和指定椭圆使用同样的前五条记录、同样的初相位搜索规则。圆轨道留下随日期改变的系统偏差。椭圆接近这些记录，但我们仍把另两条记录保留到参数锁定以后才揭晓。新记录支持候选，是因为它没有参与这次选择；这并不等于从七个点唯一推导出开普勒定律。

天王星的偏差提出另一种问题：引力模型是否漏掉了一个天体？额外行星同时吸引天王星和太阳，改变日心相对运动的是**两者加速度之差**。合成示例在固定其他初始条件后比较12组质量与相位候选，再检查未用于比较的后三条记录。模型能够解释偏差，仍需要独立的天空观测。

<h2 id="try">先保留证据，再检验判断</h2>

在第谷视图中，选择圆或椭圆，改变初相位。金色方向记录保持原位。用“只用前5次拟合”恢复公平比较，然后锁定预测，先判断后两条记录应落在哪里，再揭晓。改变候选会重新隐藏保留记录，避免把已经看过的答案当成新预测。

在海王星视图中，把额外质量设为零，检查模型曲线是否回到近零偏差；固定的记录不会跟着消失。在同一刻度上比较其他候选。“引力原因”把太阳和天王星所受的吸引与相对摄动分开，两种箭头使用固定的加速度比例。

“历史三夜”换用真实的1846年坐标。先看两夜，再锁定课堂中的直线外推，最后揭晓第三夜。这是用原始资料做的**事后检验练习**，不是勒维耶的原始反演算法。看到新光点还不够：它与星图是否一致、下一晚是否移动，都要继续检验。

<summary>合成轨道表与候选比较</summary>

火星记录采用地球视方向：先算地球与火星的位置，再对两者的位置差求方向。地球是1 AU、365.25 d的圆轨道；火星取a=1.5237 AU、e=0.0934、T=686.98 d，生成时初相位0.12 rad，并加入预先指定的−0.3′至+0.4′微小偏移。下表冻结在模型中，候选不能重新生成它。

| ---------- | ------------ | -------- |
| −80        | 2.635681     | 比较     |
| −40        | 22.495716    | 比较     |
| 0          | 28.538932    | 比较     |
| 40         | 18.916408    | 比较     |
| 80         | 21.786018    | 比较     |
| 120        | 38.756507    | 保留检验 |
| 160        | 61.138696    | 保留检验 |

两个候选只在−0.08至0.32 rad间以0.0005 rad步长调整初相位，比较前五次的角差均方根。圆候选的最优值约252.72′，指定椭圆约0.23′；后两次分别约387.73′和0.29′。这些数值属于本合成示例，**不是历史上的8′**。画面的坐标轴在候选间保持一致，不用自动缩放制造改善。

天王星示例采用AU和年，太阳引力参数为4π² AU³/yr²。初始天王星半径19.2 AU，额外天体半径30.1 AU，示例质量为太阳质量的5.15×10⁻⁵。天王星轨迹用RK4积分；额外天体使用规定圆轨道。日心摄动包含间接项：

固定表在10至80模型年每10年取一次方向差，附加不超过0.2″的指定偏移。前五次比较、后三次保留。质量倍数只比较0、0.5、1、1.5，初相位只比较−0.4、0.6、1.6 rad，其他条件固定。因此得到的是**给定候选和先验条件下的比较**，不是完整反演，更不能声称唯一发现海王星。方向差是日心角差，不是地面观测黄经。

<summary>1846年原始记录与独立的第三夜</summary>

恩克1846年9月26日的报告列出三夜坐标。时间保留原文“柏林平时”，赤经在此以角度表示；不默认为UTC或J2000坐标。

| 1846年日期 | 柏林平时   | 赤经         | 赤纬         |
| ---------- | ---------- | ------------ | ------------ |
| 9月23日    | 12:00:14.6 | 328°19′16.0″ | −13°24′8.2″  |
| 9月24日    | 08:54:40.9 | 328°18′14.3″ | −13°24′29.7″ |
| 9月25日    | 09:44:45.0 | 328°16′59.8″ | −13°24′55.4″ |

前两夜赤经变化−61.7″，赤纬变化−21.5″。局部天图横向采用赤经差乘平均赤纬的余弦，横纵角尺度一致，避免把赤经角差直接当成天球上的横向距离。第三夜课堂预测只使用前两夜坐标和时间间隔；揭晓后赤经误差约−1.21″，赤纬误差约−0.16″。这是短时直线近似的回顾性练习，三夜不足以确定完整轨道。

报告还给出同一历元1846年9月23.5日的**地心黄经**比较：计算324°58′，观测325°52.75′，相差54.75′。这是该报告的具体比较值，不能与1847年1月1日的日心轨道要素、发现夜赤经或其他文献的误差数字混算。画面在两种坐标之间切换时清空原来的轴。

<summary>保留的望远镜、木星卫星与哈雷模型</summary>

伽利略式望远镜为正物镜、负目镜的理想5倍近轴系统。卫星采用近圆共面轨道、沿轨道平面观察，周期为1.769、3.551、7.155、16.689 d；初相位是教学选值，忽略光行时、互掩和木星扁率。它不是伽利略原始观测复原。

五条教学记录固定在经过0、1、2、3、4天的位置。观察推进只让新记录出现，已经记下的位置不会改变；上方实时视图与读数使用同一时刻。回退只重新隐藏后来的记录，不重算它们的日期。

哈雷模型取e=0.967、T=75.3 yr、a=T^(2/3) AU。位置由开普勒方程决定，不能沿椭圆匀速画点。彗尾仅提示背日方向，不计算气体和尘埃；1531、1607、1682、1758是历史年份，不由固定75.3年周期拟合。
