## 两条路，构成同一次充放电

这篇观察的是明确限定的石墨 / 磷酸铁锂电芯，也就是 graphite / LFP 体系。放电时，锂从石墨宿主中迁出，经电解液走向正极；电子则通过导电固体、集流体和外部负载到达正极。湿润的隔膜允许离子传输，同时避免两极直接形成电子导通。

正极嵌入锂时，伴随来自外部的电子转移。充电把整体过程反过来：外部电源做功，让锂返回石墨。正常的石墨储锂是嵌入宿主，不是把负极当成一块金属锂。[DOE 解释了这两条不同的路径](https://www.energy.gov/science/doe-explainsbatteries)，[Sandia 的研究说明了 LFP 颗粒的嵌锂过程](https://newsreleases.sandia.gov/popcorn_batteries/)。

金色与蓝色示踪点的身份保持不变，充电时沿原路返回。它们表示选出的电荷转移路径，数量、相对速度和同步运动都**不是单个粒子的动力学计算**。电解液中的锂、盐阴离子运动与局部电中性采取平均处理，没有展开为分子动画。

## 只改一个条件，再看结果

- 从同一初态以不同电流放电，比较立刻出现的内阻压降、随后变化的极化，以及内部热功率。
- 选择“负载后休息”。模型先放电 120 秒，再断开外部电流。休息阶段端电压回升，但 SOC 和锂的库存不增加。
- 切换到“充电”，观察原来的路径反向。充入的能量既要增加储能，也要支付内部损耗。
- 在容量端点附近查看能量账目。触及模型边界后电流停止，继续增加时间也不会让 SOC 超出可用范围。

原生滑块均有明确名称，支持方向键、Home 与 End。复位会恢复初始 SOC、电流、时间、过程、视图、镜头与二维模式。每次改动从所选初态重建，不偷偷继承上一次实验的状态。WebGL 不可用时，二维画面仍保留内部离子与外部电子的不同路径。

## 化学计量与守恒的电荷

记可用荷电状态为 `z`。两个电极宿主用平均组成 LiₓC₆ 与 LiᵧFePO₄ 表示：

<div className="formula">
  x = 0.05 + 0.9z
  <br />
  y = 0.95 − 0.9z
  <br />x + y = 1
</div>

模型使两个宿主的容量匹配。取 `Q = 3600 C`，法拉第常数为 `F`，每个宿主的位点量为 `Q/(0.9F)` 摩尔。因此，石墨一侧减少的锂等于正极增加的锂；转移的摩尔数等于外部通过的电荷除以 `F`。

零点与满点限定的是**可用窗口**，不是有没有锂。SOC 为零时，石墨仍有 `x = 0.05`，正极则有 `y = 0.95`。平均组成不求解石墨分阶、LFP 两相共存或不同颗粒的差异。嵌入关系 LiFePO₄ ⇌ FePO₄ + Li⁺ + e⁻ 给出一份锂对应一个电子的记账方式；引用的 [LFP 原始实验](https://www.nature.com/articles/ncomms2705) 还研究了额外容量机制，本场景没有采用那些机制。

## 明确声明的电压近似

这里的开路曲线是作者选定的 LFP 平台状教学近似，没有拟合某款商用电芯。令 `w = 2z − 1`：

<div className="formula">U(z) = 3.30 + 0.08w + 0.14w⁹ 伏</div>

串联内阻取 `R₀ = 0.04 Ω`；另有一个被动极化支路，`Rₚ = 0.03 Ω`、`Cₚ = 1500 F`，时间常数为 `RₚCₚ = 45 s`。这是[电池等效电路](https://www.mathworks.com/help/simscape-battery/ref/batteryequivalentcircuit.html)的模型结构。等效电容表示一个状态，不是说电芯里真的藏着一只电容器。

约定放电电流 `I` 为正：

<div className="formula">
  dz/dt = −I/Q
  <br />
  dp/dt = (I − p/Rₚ)/Cₚ
  <br />V = U(z) − IR₀ − p
</div>

`IR₀` 随电流立刻改变。极化 `p` 则按指数规律松弛，所以断流以后电压能够回升，而 SOC 保持不变。这里没有计算空间扩散或浓度场，不能把 RC 状态当作已解析的微观输运过程。

## 功率、可逆储能与热

把开路电压对电荷积分，得到模型中可逆电功的储库；能量零点选在可用窗口的下端：

<div className="formula">
  Echem(z) = Q ∫₀ᶻ U(s) ds
  <br />
  Epol = Cₚp²/2
  <br />
  Pheat = I²R₀ + p²/Rₚ
  <br />
  Pterminal = VI
</div>

<div className="formula">d(Echem + Epol)/dt + Pterminal + Pheat = 0</div>

休息时 `I = 0`：可逆化学功储库不会增加，极化暂存能量的减少转化为热。充电时，按“放电为正”的约定，端口功率为负，表示能量进入电芯。账目分别记录充入能量、已输出能量、仍然储存的能量与内部累计放热。Ah 表示电荷容量，Wh 表示能量，不能把它们互换。

每个恒流段采用解析推进。到达可用 SOC 端点，或示例的 2.8/3.6 V 边界时，控制器把电流关断，随后让 RC 状态在这一段剩余时间内松弛。这里的边界与电流属于教学模型，不是实际充电建议；没有模拟真实恒流恒压控制策略。

模型保持温度不变，把不可逆热记入环境。熵热、老化、副反应、锂析出、相变与空间输运都省略，所以能量恒等式属于已声明的等效模型，不是对真实电芯完整量热结果的预测。厚度、孔道和粒子被放大以便观看；结构依据可见 [DOE 电芯组成概述](https://www.energy.gov/sites/default/files/2023-07/doe-critical-material-assessment_07312023.pdf)与[集流体、隔膜说明](https://www.energy.gov/eere/vehicles/articles/propulsion-materials-rd-2010-annual-progress-report)。
