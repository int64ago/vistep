<h2 id="understand">没有跨过去的电线，仍有完整的电流回路</h2>

发送线圈和接收线圈分别有自己的闭合电路，中间没有导线。发送电流变化时，部分磁通与接收绕组交链，形成变化的共享磁链。接收端的感应电动势取决于磁链的变化速度：磁链达到极值时，瞬时感应电压为零；过四分之一个周期，磁链变化最快，电压幅值最大。

接收开关没有闭合时，感应电压可以存在，负载功率却为零。接通以后，接收电流流过电阻负载；它的作用也通过互感反映回发送侧，所以发送电流随之改变。电能最终来自发送电路的电源，磁场参与传递与暂时储能。

本片把外壳剖开，露出两条各有八匝的连续螺旋铜线。内端通过另一绝缘层跨到外侧，避免与其余线匝短接。深灰色铁氧体磁片位于线圈背面，帮助形成磁路；接收侧磁片半透明是剖视表达，不表示实际材料透明。

<h2 id="try">一次只改变一个条件</h2>

- 把间距从 20 mm 减到 3 mm，保持中心对齐。本片参数范围内，互感与交流负载功率都上升。
- 保持 4 mm 间距，逐渐增加横向偏移。发送端仍可能有很大电流，接收负载功率却明显下降。
- 固定摆放，断开接收负载。比较“观察磁链”里的非零感应电压和归零的输出功率。
- 在“观察调谐”里，把频率从 85 kHz 改为 150 kHz。补偿电容抵消线圈感抗，改变电流与传输功率。曲线上的最高点不应仅凭单个线圈的自谐振公式猜测。
- 移除磁片，比较新的电路。这里的等效电感降低，固定电容对应的自谐振频率升高；磁片重新装回后恢复原参数。
- 在“观察功率”里增加线圈电阻倍率，检查交流负载、两只线圈铜耗和源电阻损耗之和。

六个滑块都支持方向键，有明确的可访问名称；按钮支持 Tab、Enter 和空格。“重置”恢复间距、偏移、频率、电阻负载、铜阻倍率、取样相位、开关、磁片和当前观察模式。主播放器统一管理影片暂停、跳转和重播，探索不运行另一套动画时钟。

<h2 id="deeper">准确的电路解，明确的耦合近似</h2>

<details>
<summary>符号、相位与双线圈方程</summary>

两只线圈的内端都是同名端。正电流从内端沿螺旋流向外端，对应绕组法线 +y。所有电路相量采用有效值，时间约定为 Re(√2 I exp(jωt))。Rₛ 是源串联电阻，R₁、R₂ 是线圈等效电阻，Rᴸ 是交流负载。

<div className="formula">Vₛ = Z₁I₁ + jωMI₂；0 = jωMI₁ + Z₂I₂</div>

<div className="formula">Z₁ = Rₛ + R₁ + j(ωL₁ − 1/ωC₁)；Z₂ = R₂ + Rᴸ + j(ωL₂ − 1/ωC₂)</div>

接收支路闭合时，反射阻抗 Z反射 = (ωM)²/Z₂。于是 I₁ = Vₛ/(Z₁+Z反射)，I₂ = −jωMI₁/Z₂。开路时 I₂ = 0，但来自发送端的共享磁链 λ₂←₁ = MI₁ 仍可变化，感应电动势 e₂ = −dλ₂←₁/dt 仍可存在。磁链单位是 Wb·turn，不应把它直接当成单匝磁通或磁感应强度。

</details>

<details>
<summary>几何与耦合如何连接</summary>

每只螺旋线圈为 8 匝，内半径 8.5 mm，径向节距 1.6 mm，外端半径 21.3 mm，导线半径 0.45 mm。内端跨线中心与绕组平面相隔 1.5 mm，并有绝缘包覆。

耦合系数采用作者明确指定的近似：

<div className="formula">k(d,x) = k₀ [1+(d/15 mm)²]⁻³ᐟ² exp[−(x/22 mm)²]；M = k√(L₁L₂)</div>

它用轴向衰减形状和侧向高斯衰减来表达趋势，不是对这两条螺旋做磁场积分得到的结果，也没有拟合 Qi 产品实测值。带磁片时 k₀ = 0.22、L₁ = L₂ = 6.8 µH；无磁片时 k₀ = 0.1364、L₁ = L₂ = 4.2 µH。磁片影响同样是教学参数，不是材料磁导率仿真。磁路曲线只示意闭合的返回路径；线条位置和透明度不能当作空间场强测量。

手机画面把横向偏移改为沿画面深度方向展示，欧氏偏移距离和电路参数保持相同。这是针对旋转对称线圈重新构图，不是缩小整张桌面图。

</details>

<details>
<summary>谐振、无源性与每一瓦的去向</summary>

默认参数为有效值电压 2 V、源电阻 0.5 Ω、线圈电阻 0.25 Ω 与 0.28 Ω、负载 3 Ω。两只补偿电容均约 165.56 nF，与带磁片的 6.8 µH 线圈在 150 kHz 自谐振。移除磁片但不换电容，自谐振频率约为 190.86 kHz。耦合与负载会影响完整系统的功率峰值，不能把自谐振频率等同于所有工况的最佳传能点。

<div className="formula">P输入 = Re(VₛI₁*) = |I₁|²Rₛ + |I₁|²R₁ + |I₂|²R₂ + |I₂|²Rᴸ</div>

电感矩阵满足 M² ≤ L₁L₂，各个电阻为正，因此模型没有主动增益。谐振时电容和电感交换储能，电压或循环电流可以增大，平均输出功率仍不会超过源输入。瞬时源功率可能反向，因为储能会返回电源；那也不是凭空发电。

模型是线性正弦稳态解，忽略开关波形、铁氧体磁滞与涡流损耗、邻近效应、集肤效应的频率变化、温升、金属异物和快速参数变化暂态。磁片切换和接收开关切换展示切换前后两个稳定电路。接收负载只是一只交流电阻；实际无线充电还需要整流、稳压、电池管理、通信和保护。本片数字不是手机或 Qi 产品的充电效率。

</details>
