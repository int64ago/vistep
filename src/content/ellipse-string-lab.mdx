---
name: 细绳绘制椭圆
title: 为什么拉紧一根绳，就能画出椭圆？
---

<section id="understand">

必修第二册第七章第1节（45页）的“做一做”用两枚图钉、一根细绳和铅笔绘制椭圆。细绳的两端分别系在图钉上，铅笔撑紧细绳后滑动，留下椭圆轨迹。

两枚图钉是焦点。绳长不变，所以笔尖到两个焦点的距离之和始终不变。焦点的中点是中心；焦点通常并不位于中心。

</section>
<section id="try">

观察两段绳长：一段变长时另一段相应变短。走完整条轨迹，确认它们的和始终是1米，长轴长度也等于1米。

保持绳长不变，把两个焦点移近。短轴逐渐变长，最后焦点重合，椭圆成为圆。圆半径等于绳长的一半，也就是原来的半长轴。

</section>
<section id="deeper">

<details>

<summary>几何模型与作图条件</summary>

半长轴 a = L/2，半焦距 c = d/2，半短轴 b = √(a²−c²)。轨迹参数为 x = acosθ，y = bsinθ。每一点满足到两焦点距离之和为 L。有效条件为 0 ≤ d &lt; L；两图钉间距等于绳长时曲线退化为线段，本片不把退化线段当作正常椭圆。

绘图中图钉和铅笔接触点按理想点处理，绳不可伸长且始终张紧。细绳只有两个固定端，不额外加入两焦点之间的底边。铅笔参数变化仅用于显示几何轨迹，不代表行星等时运动，也不能据此验证开普勒面积定律。真实作图中笔杆、图钉半径和绳的松弛会产生误差。

</details>

</section>
