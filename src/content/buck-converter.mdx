<h2 id="understand">开关断开了，电流为什么还在？</h2>

降压变换器没有把多余电压全部交给一个串联电阻。它高速接通、断开输入，让电感和电容在周期内储存、释放能量。这里的输入是 **12 V**，开关频率默认 **20 kHz**，一个真实周期只有 **50 µs**；影片大幅放慢了这个过程。

接通时，电流从电源经过开关 S、电感 L 和负载 R 回到电源。电感两端的正电压使电流上升。断开时，电流不能跳变，续流二极管 D 接通另一条回路：公共回线、二极管、电感、负载、公共回线。电感电压变为负值，电流沿原方向逐渐下降。

电容 C 并联在输出端。电感电流比负载需要的多，它就充电；电感电流不足，它就补上差额。电感电流、电容电压和负载并不是三张各自播放的动画，而是同一个开关电路的状态。

光点是**能量示意**，位置按当前导通区间累计传递的能量前进。它不是电子、实际漂移速度或一份量子化的能量。续流时输入端不供能；零电流区间则由电容供能。

<h2 id="try">把电流追到零线</h2>

- 进入自由探索，拖动“电路取样时间”。接通与断开交界处，开关节点电压可以突变，电感电流保持连续。
- 保持默认参数，把负载电阻调大。负载变轻，电感电流逐渐碰到零。异步电路的二极管阻止反向电流，因而出现第三段空闲区间。
- 比较 47 µF 和 220 µF 电容。影片使用相同的电压窗口，较小纹波会真正画得更小。自由探索超出这个窗口时，纵轴按标出的范围扩展。
- 施加 **8 Ω → 3 Ω** 负载阶跃。电容先弥补电流缺口，电压下陷；电感电流随后调整。启用阶跃会覆盖手动负载值，关闭后恢复原值。
- 加入导通损耗，再查看能量分配。同一占空比下，输出会降低。图中只核算明确建模的损耗，不能当成某款真实电源的效率指标。

所有滑块都支持键盘方向键。时间是手动取样，不另设独立动画时钟。“重置全部实验参数”会恢复所有元件参数、理想器件、取样位置、观察项并关闭负载阶跃。自动影片的暂停、章节、重播和声音由播放器统一控制。

<h2 id="deeper">实际求解了什么？</h2>

<details>
<summary>两个状态、三种导通区间</summary>

计算使用 SI 单位。状态是电感电流 `i` 和理想电容内部电压 `vC`。`R` 是负载，`rC` 是电容等效串联电阻，`vO` 是真正的输出端电压。电容支路电流向下流入正端为正：

<div className="formula">iC = (R i − vC) / (R + rC)；vO = vC + rC iC；C dvC/dt = iC</div>

开关闭合：

<div className="formula">L di/dt = Vin − (rS + rL)i − vO</div>

开关断开、二极管续流：

<div className="formula">L di/dt = −VF − (rD + rL)i − vO</div>

二极管电流到零时，求解器定位真实的零交叉时刻，随后进入 `i = 0`、`di/dt = 0` 的空闲区间。电容继续通过负载放电。此时开关节点理想地浮到输出电压，电感电压为零；没有模拟寄生谐振。

非理想参数为：开关导通电阻 **0.12 Ω**，电感绕组电阻 **0.15 Ω**，二极管压降 **0.45 V** 加上 **0.05 Ω** 动态电阻，电容 ESR **0.04 Ω**。这些是明确选择的教学参数，不是产品拟合。理想模式把它们全部设为零。

使用分段四阶 Runge–Kutta 积分，默认每周期 128 个最大步长；步长在开关边沿截断。二极管截止事件在步内二分定位。周期稳态通过积分后的周期映射求不动点，轻阻尼时以数值雅可比加速；没有把输出强行设为占空比乘输入。负载阶跃从求得的初始周期稳态出发，连续积分 24 周期，第 5 周期后改变负载。

</details>

<details>
<summary>伏秒平衡与电荷平衡</summary>

重复周期的首尾状态相同，因此：

<div className="formula">∫ vL dt = L Δi = 0；∫ iC dt = C ΔvC = 0</div>

只有在**理想、连续导通的周期稳态**，才得到：

<div className="formula">平均输出电压 = D Vin</div>

默认理想电路的计算结果约为 5.40 V，电感电流最低约 0.85 A，输出峰峰纹波约 62 mV。这些读数来自微分方程。二极管续流与零电流区间的边界也由电路决定；断续导通时不能继续套用同一个变换比。

影片的占空比、电容、轻载和损耗比较，分别展示已经求得的稳态。只有负载阶跃章节展示两个状态之间的真实暂态。电容的内部电压连续；带 ESR 的输出端电压可以在负载切换时立刻跳变一个小量。

</details>

<details>
<summary>输入能量没有被隐藏</summary>

储能为：

<div className="formula">EL = L i² / 2；EC = C vC² / 2</div>

开关接通时输入功率为 `Vin i`，其他区间为零。负载功率为 `vO²/R`。损耗分别为开关导通时的 `rS i²`、续流时的 `VF i + rD i²`、绕组的 `rL i²` 和电容 ESR 的 `rC iC²`。求解器以同一组积分采样累计它们：

<div className="formula">输入能量 = 负载能量 + 热耗 + ΔEL + ΔEC</div>

稳定周期中储能变化趋近于零，才可以把输入能量条带分成负载和热耗。暂态也核对同一等式，保留储能变化项。

这是开环、固定占空比、正向供电范围内的集中参数电路，不含反馈调节、启动保护、限流、磁饱和、磁芯损耗、开关边沿损耗、二极管反向恢复、驱动功耗或寄生振铃。它用于理解机制，不能替代硬件设计验证。
