<h2 id="understand">先相加，再谈分布形状</h2>

这里每次试验只有 0 或 1，成功概率固定为 p。独立重复 N 次，相加得到成功次数 S，精确服从二项分布。两次公平试验的四种等可能结果里，`01` 和 `10` 都给出 S=1，因此中间概率为一半，不是把三个柱子画成一样高。

中央极限定理讨论的是适当中心化、缩放后的和。独立同分布、有限且非零方差的条件下，`(S−Np)/√(Np(1−p))` 的分布随 N 增大趋近标准正态。它不声称原始 0/1 数据会变成正态，也不让有限 N 的离散分布突然变成连续分布。

<h2 id="try">和变宽，均值却更集中</h2>

本例可分别查看成功次数、标准化的和和样本均值 S/N。相加次数从 8 增至 32，公平试验中，和的方差从 2 增至 8；但样本均值方差从 0.03125 降至 0.0078125，标准差减半。不能把这两种横轴混为一谈。

柱子由精确概率卷积计算，换横轴时按格宽调整高度，确保柱面积表示概率。棕色曲线是相同均值与方差的正态近似密度，不能把曲线某一点的高度当成该点概率。

<h2 id="deeper">更多并不自动足够</h2>

<details>
<summary>稀少事件、相关复制与零方差</summary>

p=0.05、N=8 时，零次成功概率约为 66.3%，分布明显偏斜。标准化只能改变位置和尺度，不能立刻消除这种形状。正态近似精度还与单次分布、样本量及所求事件位置有关，没有“达到某个固定次数就永远足够”的保证。

若只做一次 0/1 试验，再把同一次结果复制 N 份，和只有 0 与 N 两种可能。变量完全相关，并非独立抽样；样本均值仍等于那一次结果，方差保持 p(1−p)，不会除以 N。数量增加没有提供更多独立信息。

自由探索能改变 N、p、横轴以及独立或复制模式。p=0 或 1 时方差为零，不执行标准化除法，明确退回原始和坐标。本片不是对所有相依或重尾分布的极限定理，也没有使用“生成一个正态随机数”来替代真实求和。

</details>
