## 共同的是还原，方法取决于体系

金属冶炼将化合物中的金属还原为单质。热分解、还原剂还原和电解是教材归纳的主要路线；选择还与原料、温度、热力学、产物分离和工艺成本有关，不能把活泼性顺序当作不允许任何例外的操作表。

演示依次比较氧化汞分解、CO 还原氧化铁、铝还原氧化铁，以及熔融氯化钠、氯化镁和氧化铝体系的电解。每条路线同时核算元素与电子。

</section>

<section id="try">

## 条件改变，反应账本也改变

选择路线并拖动进度，追踪同一编号原子的去向。电解视图可关闭电源或关闭熔融条件，所选理想电解路线随即停止；热反应可关闭供热条件。这些开关表示必要条件是否满足，不预测真实阈值温度、速率或电极过电位。

氯化钠水溶液不能替代本片的熔盐来获得钠。视图中的液相与界面是机制示意，并非可照着搭建的工业装置。它也不提供铝热反应或汞实验的操作流程。

</section>

<section id="deeper">

<details>
<summary>守恒、价态与工业限定</summary>

热分解：`2HgO → 2Hg + O₂`。两个 Hg(+II) 共接受四个电子，两个 O(−II) 共失去四个电子。

CO 还原：`Fe₂O₃ + 3CO → 2Fe + 3CO₂`。两个 Fe(+III) 接受六个电子，三个 C(+II) 升到 +IV 共失去六个电子。这是高炉还原的净式，省略中间氧化物、焦炭反应与炉渣。

铝还原：`Fe₂O₃ + 2Al → 2Fe + Al₂O₃`。两边电子转移均为六个。氧化物小圆组表示计量单元，不能据此认为固体氧化物由这些离散小分子组成；原子移动是可追踪的账本动画，非反应轨迹。

电解：`2NaCl(l) → 2Na(l) + Cl₂(g)` 与 `MgCl₂(l) → Mg(l) + Cl₂(g)` 分别对应两个 Na⁺ 或一个 Mg²⁺ 接受两个电子。熔盐中迁移的是离子，电极与外电路承担电子交换。视图中的离子与气泡是示意标记，不用数目表示实际浓度。

铝工业路线采用碳阳极时，常用净式为 `2Al₂O₃ + 3C → 4Al + 3CO₂`，电子转移数为十二；冰晶石是电解质体系组成，不在此净式中被净消耗。画面省略实际含铝氟络离子的复杂组成、CO 等副产物与工况影响，不把“只生成 O₂”当作工业事实。

</details>
