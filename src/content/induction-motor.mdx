<h2 id="understand">不接电的转子，怎样得到转矩？</h2>

先把外壳和一部分定子铁芯剖开。三组绕组固定在定子槽里，它们的电流在时间上错开三分之一个周期。把各组绕组的磁场作用相加，会得到一个持续旋转的主磁场。本片的绿色箭头来自等效磁化电流的矢量和，包含转子电流对主磁场的反作用。

转子没有接到电源的电线，也没有永磁体。它是一叠铁芯，周围埋着铜条，每根铜条都连接前、后两只完整端环。转子相对主磁场运动时，导条和端环组成的闭合回路感应出电流。电流与磁场相互作用，产生让转子追赶磁场的转矩。铜条颜色表示相对电流的方向和强弱，圆点、叉号与箭头表示传统电流方向；没有把电子画成高速飞奔的粒子。

关键恰恰在于“追赶”。当转子完全跟上磁场，在转子坐标系里，主磁通不再变化。这个模型中的转子感应电流和电磁转矩都会归零。稳定带负载运行需要一点转差：转子稍慢，才能继续感应出电流。

<h2 id="try">先看完，再改变一个条件</h2>

- 选择“稳定负载”，把负载从 1 N·m 增加到 4 N·m。观察稳定交点向低转速移动，转差与转矩一起增加。
- 选择“指定转差”，先设为 100%。转子堵转，但转矩并不为零；转子的机械功率为零，气隙功率全部变成转子铜耗。
- 再把转差降到 0%。转子达到 3000 rpm，转子电流与转矩为零；定子仍有磁化电流和相应铜耗。
- 停在同一个电源相位，切换 A → B → C 与 A → C → B。比较相序改变后磁场方向和稳态转子方向的关系。
- 切换到“观察功率”。电气输入始终等于机械功率、转子铜耗与定子铜耗之和。

滑块支持键盘方向键；按钮可通过 Tab、Enter 或空格操作。“重置”恢复初始探索条件。影片暂停、章节跳转、重播由同一播放器管理，探索没有额外自动推进的时钟。

<h2 id="deeper">转差把电路、速度与功率连起来</h2>

<details>
<summary>电气频率与机械转速</summary>

本片是一对磁极的两极电机。电源频率 f₁ = 50 Hz，极对数 p = 1，同步机械转速 nₛ = 60f₁/p = 3000 rpm。一般的四极电机有两对磁极，相同频率下的同步转速为 1500 rpm；那需要另一种绕组空间分布，不能只改变本片的数字。

以相序规定的磁场方向为正运行方向，转差 s = (ωₛ − ωᵣ)/ωₛ。这里的运行域为 0 ≤ s ≤ 1，转子电气频率 f₂ = sf₁。它不同于转子每秒实际旋转的圈数。正向与反向的转矩和角速度都带符号，但正常电动运行的机械功率始终为正。

</details>

<details>
<summary>每相等效电路与能量收支</summary>

模型用定子串联阻抗 R₁ + jX₁，连接励磁支路 jXₘ 与转子支路 R₂′/s + jX₂′ 的并联。所有电路电流均为有效值，转子量折算到定子侧。相电压为 120 V，R₁ = 0.65 Ω，X₁ = X₂′ = 0.9 Ω，Xₘ = 30 Ω，R₂′ = 0.5 Ω；电抗均指 50 Hz 下的值。这组参数用于解释原理，不对应某一款商品电机。

<div className="formula">P气隙 = 3I₂′²R₂′/s；P转子铜耗 = sP气隙；P机械 = (1−s)P气隙</div>

<div className="formula">τ = P气隙/ωₛ；P输入 = 3I₁²R₁ + P转子铜耗 + P机械</div>

实现使用在 s = 0 连续的导纳形式，因此没有用很小的假转差代替同步状态。端环电流由每个节点的电流守恒求得；图中的导条电流经过归一化，不能当作单根实物铜条的安培数。

</details>

<details>
<summary>启动、稳定支与教学边界</summary>

启动轨迹从静止出发，按 J dω/dt = τ − τ负载 积分，J = 0.025 kg·m²，负载为 1 N·m。采用准稳态电路得到加速包络，忽略合闸瞬间的快速电磁暂态。机械转换功率在启动时分为负载做功与转子动能增加。反向启动同样从静止开始；没有计算运转中突然换相的反接制动。

负载实验解的是接近同步速度的稳定平衡点，允许 0–6 N·m。在这组参数下，最大转矩约为 25.90 N·m，对应转差约为 26.47%；超过最大转矩的稳态请求会被模型拒绝。完整转矩曲线同时展示稳定支以外的形状，但不会把所有交点都当成稳定运行。

物体转角统一慢放，启动曲线保留模型物理秒数；电源相位和转子转角都是独立模型的确定性取样。全片按章节和进度重建状态，没有累积动画历史。磁场只保留空间基波，几何槽数与可见绕组用于结构教学，不是精确的电磁有限元网格。模型忽略铁耗、风摩耗、饱和、集肤效应及温升引起的电阻变化，因此效率不应当作实物预测。

</details>
