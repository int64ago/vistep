<h2 id="understand">看懂原理</h2>

人教版选择性必修 3 印刷第 69–70 页的实验 3-7 与 3-8，用两种弱氧化剂检验乙醛。关键区别在于还原产物的价态与形态：银离子还原成金属银，铜(II) 则还原成氧化亚铜中的铜(I)。

银氨试剂制备时，初生氧化银沉淀随氨配位而溶解，得到含 [Ag(NH₃)₂]⁺ 的澄清溶液；此时未生成银镜。加入乙醛、热水浴温热后，银可沉积在洁净内壁。RCHO + 2 [Ag(NH₃)₂]⁺ + 3 OH⁻ → RCOO⁻ + 2 Ag + 4 NH₃ + 2 H₂O。

第二个实验采用新制 Cu(OH)₂ 与过量碱，并非把斐林试剂的配方直接代入。CH₃CHO + 2 Cu(OH)₂ + OH⁻ → CH₃COO⁻ + Cu₂O↓ + 3 H₂O。蓝色悬浊物逐渐形成砖红色固体；铜只从 +2 降到 +1，而不是还原为铜单质。

<h2 id="try">自己试试看</h2>

换成丙酮，在所示温和氧化检验条件下不发生同样的还原。再改变氧化态金属的相对量：每份乙醛至多转移两份电子，金属不足时反应程度受限。每份氧化的乙醛对应两份 Ag 或一份 Cu₂O。

标记只跟踪代表性金属原子，少量图形不表示真实浓度。银标记抵达与内壁几何一致的位置；两两铜标记进入同一个计量单位。氧化态和官能团图示比较净变化，不将其当成真实基元反应或原子轨迹。碱性条件下的有机产物表示为羧酸根。

<h2 id="deeper">再深一层</h2>

乙醛羰基碳的氧化态由 +1 升到 +3，因此两个电子同时解释银与铜两种实验的计量。银镜质量还依赖玻璃洁净程度、成核和表面沉积，实际也可能形成暗色银沉积；动画不承诺任意条件都得到完美镜面。
