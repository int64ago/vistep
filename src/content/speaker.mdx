## 锥盆为什么会跟着电信号动？

永久磁体本身固定不动。导磁轭、中心极柱和上夹板把磁通引向狭窄的磁隙。音圈处在磁隙中，通电后受到轴向力；电流反向，力也反向。

音圈不是悬空推一下锥盆。绕组固定在线圈骨架上，骨架与锥盆、防尘帽连在一起，作为一个振动组件移动。折环和弹波把它连接到固定盆架，既允许轴向运动，也提供回到平衡位置的弹性支承。柔性引线保持电路连续。

能量转换也会反过来发生：线圈在磁场中运动时产生反电动势。因此，电流不只由电阻决定，还取决于线圈正在怎样运动。影片把时间放慢，让电流、推力、弹性回复与运动之间的关系可追踪。

## 看一处连接，再改变一个输入

- 进入“磁隙近看”，用相位滑块来回推进。磁场方向固定，电流和推力一起换向。
- 在“悬挂连接”观察折环、弹波和引线。它们的移动端跟随同一个位移，固定端留在盆架。
- 在“稳态响应”保持峰值电压不变，改变频率。比较的是各频率下已经稳定的最大行程，不是实时扫频。
- 增加机械阻尼，观察行程峰变低。回到“功率收支”，看损耗和储能变化怎样满足同一能量平衡。

所有滑块都有明确名称，支持方向键、Home 和 End。恢复按钮同时重置电压、频率、相位、阻尼和观察部位。组件不播放测试音；不听声音也能理解整段演示。

## 同一个力因数连接两个方向

采用恒参数、小信号集总模型：

<div className="formula">
  u = Ri + L di/dt + Blv
  <br />M dv/dt = Bli − Kx − Dv
  <br />
  dx/dt = v
</div>

默认值为 `R = 6 Ω`、`L = 0.5 mH`、`Bl = 4 N/A`、`M = 12 g`、`K = 1200 N/m`、`D = 0.8 N·s/m`。这是一组教学参数，不是某个品牌的测量数据。折环和弹波的合成作用包含在 `K, D` 中，移动组件的合成质量包含在 `M` 中。

电动势 `Blv` 与电磁力 `Bli` 采用同一个力因数，因此

<div className="formula">(Blv)i = (Bli)v</div>

两边都是电机端口转换的瞬时功率。储能为

<div className="formula">
  E = ½Li² + ½Mv² + ½Kx²
  <br />
  ui = Ri² + Dv² + dE/dt
</div>

电阻发热与机械耗散非负，储能变化率可正可负。关掉驱动电压后，储能还会继续转化并耗散。影片的释放实验把理想电压源设为零，电路通过线圈电阻保持闭合；它不是把引线断开，也没有声称电能被回收到电池。

对于角频率 `ω` 的正弦输入，用峰值复振幅求解：

<div className="formula">
  Zₑ = R + jωL
  <br />Q = K − Mω² + jωD
</div>

<div className="formula">
  X = BlU / [ZₑQ + jω(Bl)²]
  <br />I = UQ / [ZₑQ + jω(Bl)²]
</div>

画出的行程、阻抗、电流和功率都来自这组解。无阻尼机械固有频率约为 50.3 Hz；电气耦合、阻尼和电感会改变完整响应，不能把这一频率简单当成行程曲线的峰值位置。行程曲线也不是声压频响。

## 空气图究竟表示什么？

最后一章是**单向驱动的一维平面波运动学示意**。把锥盆的位移作为边界运动，空气质点的位移写成 `ξ(s,t) = x(t − s/cₐ)`，这里 `cₐ = 343 m/s`。质点围绕自己的平衡位置往复；压缩满足 `−∂ξ/∂s = v(t − s/cₐ)/cₐ`，图样向外传播。

此图没有把空气负载反馈到扬声器，也没有模拟真实有限锥盆周围的三维声场。质点位移另外放大，颜色按压缩相位归一化；不能把它读作 CFD、声压级、辐射效率或距离衰减。图中的机械耗散也不等于全部辐射声功率。

## 几何与近似

剖面展示轴对称结构的一道切片；手机重新投影并按章节选择磁隙或一侧悬挂。行程统一放大 8 倍，所有连接仍从同一个位移推导。磁通虚线只示意闭合磁路，不是有限元磁场；绕组截面按组绘制。真实数值始终使用实际单位。

模型只覆盖小信号活塞式工作区，忽略磁路非线性、随频率变化的损耗电感、线圈升温、锥盆分割振动、箱体和声场耦合。实际扬声器的完整设计需要更丰富的模型和测量。
