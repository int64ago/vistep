## 一小段空气，带动一腔压缩

在尺寸远小于声波波长的刚性腔体中，腔内压力变化可以近似看作处处同相。颈部空气有惯性，腔内空气的压缩提供恢复作用，两者组成亥姆霍兹振子。它与需要沿管长形成明显压力分布的风琴管不同。

颈部空气向外偏移，腔内空气稍微膨胀、压力降低，恢复力将它拉回。经过平衡位置时速度最大，继续向内后，腔内压力升高并使它折返。画面的压力和能量来自这一个周期的同一状态。

<a id="try"></a>

## 一次只改变一个几何量

升高水面，空气体积减小，压缩恢复作用变强，音调升高。伸长颈部，参与运动的质量增加，音调降低。加宽颈部则同时增加质量、单位位移扫过的体积和压力作用面积，不能只用“空气更重”判断结果。

自由探索可固定相位再改变尺寸。金色虚框标记有效空气柱：颈部两端附近的空气也参与运动。它不是实体活塞，不能将框外的空气理解成完全不动。

## 有效颈长与近似边界

<div className="formula">
  S = πr²，L_eff = L + 1.6r
  <br />m = ρSL_eff，k = γP₀S² / V<br />f = c / (2π) × √[S / (VL_eff)]
</div>

这里取声速343 m/s、绝热指数1.4、环境压强101325 Pa，并用c² = γP₀/ρ确定一致的密度。以向外为正，压力变化p = −γP₀Sx/V。颈部动能与腔体压缩能相互转换，理想无损模型中总和不变。

两端修正取外端约0.6r、内端约1r，来自低频近似，真实开口、凸缘与附近物体会改变它。容器画成固定半径5.5 cm的圆柱腔，最大容积1.5 L；静止水面仅设置剩余空气体积，不模拟水或壁面的振动。局部圆角是剖面的示意，不参与体积计算。

位移放大80倍、相位慢放，频率读数保持物理值。忽略粘滞、湍流和声辐射损耗，也不模拟吹气如何维持振荡。大振幅、柔性瓶壁、多个开口或腔内明显驻波需要更完整模型；把任何瓶声都代入同一个公式并不可靠。
